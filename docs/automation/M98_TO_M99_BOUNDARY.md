# M98 to M99 Boundary

M98 implements Scoped Recurring Low-Risk Automation contracts for low-risk
read-only recurrence review. It requires strict cadence, approval renewal
required, renewal expiry, stop conditions required, audit trail, revocation,
kill switch, no secret access, safe refs only, and evaluator boundaries
revalidate safety-critical fields.

M99 is Autonomy v1 Safety Freeze and remains future. M98 does not perform the
M99 full freeze review and does not add new capability beyond scoped recurring
low-risk automation contracts.

M98 adds no scheduler, no background worker, no recurring execution runtime, no
mutating tasks, no credential or account actions, no shell write, no network
write, no browser write, no silent background collection, no backend route, no
dependency, no broad autonomy, and no production authority.

M99 remains future.
