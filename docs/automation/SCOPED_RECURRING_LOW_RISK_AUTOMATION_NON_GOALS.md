# Scoped Recurring Low-Risk Automation Non-Goals

M98 does not implement a scheduler, background worker, cron daemon, recurrence
runtime, recurring execution runtime, background collection, mutating tasks,
credential or account actions, shell write, network write, browser write,
browser forms, account changes, downloads, external plugins, mobile sensors,
memory writes, context injection, export, backend routes, Control Center
controls, dependency changes, broad autonomy, or production authority.

M98 remains scoped to low-risk read-only recurrence contracts with strict
cadence, approval renewal required, renewal expiry, stop conditions required,
audit trail, revocation, kill switch, and no secret access.

M99 remains future.
