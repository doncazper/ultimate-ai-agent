# Recurring Automation Non-Goals

M97 does not implement recurring execution. It does not implement recurrence
runtime, background execution, cron, daemon behavior, scheduler behavior,
trusted recurring automation runtime, mutating tasks, credential or account
actions, shell execution, network mutation, browser writes, external plugin
execution, silent background collection, memory writes, context injection,
backend routes, Control Center controls, dependency changes, production
authority, broad autonomy, or M98 work.

M97 is contract-only and disabled by default.

M98 remains future.
