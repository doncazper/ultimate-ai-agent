# M97 to M98 Boundary

M97 is Recurring Automation Contracts. It defines disabled-by-default,
contract-only metadata for cadence, approval renewal, expiration, stop
conditions, audit, revocation, and receipt plans.

M98 is Scoped Recurring Low-Risk Automation and remains future. M97 does not
start recurrence runtime, background execution, cron, daemon, scheduler, or any
recurring task. It does not add side effects, shell/network/browser/plugin
authority, memory write, context injection, backend route, Control Center
control, dependency, production authority, or broad autonomy.

M98 remains future.
