# Autonomous Tool Execution Non-Goals

M91 does not implement real tool execution, autonomous tool execution,
autonomous session start, background workers, command execution, shell
execution, subprocess execution, filesystem mutation, network access, browser
automation, plugin execution, remote execution, model call, memory write,
context injection, backend routes, Control Center controls, dependencies, M92
work, or production authority.

M91 does not store raw tool payloads, raw provider payloads, raw prompts, or
secret-like content. It does not make approval refs authority. It does not turn
M90 shell/subprocess hardening into execution authority.

M92 remains future.
