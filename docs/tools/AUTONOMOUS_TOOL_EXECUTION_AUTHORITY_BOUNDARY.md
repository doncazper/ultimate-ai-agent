# Autonomous Tool Execution Authority Boundary

M91 does not grant execution authority. The autonomous tool execution contract
is review-only metadata over exact M90 Shell/Subprocess Hardening Freeze output.
Approval refs are identifiers only, and no approval ref can authorize real tool
execution, autonomous execution, session start, command execution, shell
execution, subprocess execution, network access, memory write, context
injection, or production authority.

The contract can explain future safe-scope requirements with safe refs only. It
cannot start an autonomy session, run a tool, call a model, mutate files, open a
network capability, enable a plugin, perform browser automation, start a
background worker, add a backend route, add a Control Center control, add a
dependency, or create production authority.

Evaluator boundaries revalidate safety-critical fields and deny model-copy
mutated authority flags. M92 remains future.
