# FCC-DOGFOOD-001 Fourteen-Day Private Operator Harness

Status: Implemented as a local/private safe-ref-only harness contract and
repo-local JSON artifact. No dogfood findings are accepted yet.
Baseline: v0.104.0 / 0.104.0.

## Purpose

FCC-DOGFOOD-001 gives the Founder Command Center a bounded 14-day private
operator harness before any beta-readiness or execution claim changes. The
harness is for manual use only: record redacted summaries, safe refs, metric
buckets, skipped states, blocked states, missing-source refs, and manual review
statuses.

The artifact is:

```text
docs/macos/private_operator_14_day_dogfood_harness_v1.json
```

It is generated by `build_private_dogfood_harness()` in
`src/ultimate_ai_agent/core/readiness/private_operator_trial.py`.

## Current Truth

The current artifact defines 14 explicit day slots with `not_run` capture
state and `pending_operator_review` review status. It includes metric bucket
refs for morning briefing open, useful briefing signals, irrelevant briefing
signals, Action Inbox decisions, memory decisions, follow-ups caught, drafts,
recommendations, terminal-needed moments, and UI friction.

Accepted and revised finding refs are intentionally empty until a real
local/private manual review records them. Pending finding refs are present so
the next operator can decide what to accept, revise, skip, block, or carry
forward.

## Safety Boundary

This lane adds no telemetry upload, no background monitoring, no account
capture, no raw prompts, no raw logs, no raw paths, no screenshots with private
data, no provider/model calls, no connector writes, no public beta, no public
distribution, no production-readiness claim, no production authority, no memory
write, no action execution, and no backend route.

Skipped, blocked, missing-source, not-run, pending-review, accepted, and
revised states are distinct so the repo never needs to pretend that an
unreviewed dogfood finding is evidence.
