# OpenWebUI Non-Goals

Status: Active M21 contract documentation for v0.25.0. Contract-only.

M21 does not implement OpenWebUI integration.

M21 does not add:

- OpenWebUI deployment.
- Docker Compose.
- OpenWebUI admin config.
- OpenWebUI config directory.
- OpenWebUI plugins.
- OpenWebUI functions.
- OpenWebUI pipelines.
- OpenWebUI tools.
- OpenWebUI admin workflows.
- OpenWebUI authentication.
- OpenWebUI cookies.
- OpenWebUI API keys.
- OpenWebUI admin tokens.
- OpenWebUI session scraping.
- browser profile access.
- live OpenWebUI connection.
- bridge runtime.
- chat execution.
- model call.
- provider call.
- local model runtime activation.
- Ollama, llama.cpp, MLX, vLLM, LM Studio, or OpenAI-compatible runtime calls.
- tool call.
- memory write.
- file write.
- backend API route.
- OpenAPI path.
- network call.
- remote execution.
- browser automation.
- Computer Use.
- mobile app code.
- mobile sensor API.
- plugin enablement.
- dependency.
- production authority.

M22 remains the future Local Model Runtime Activation Contract. M23 remains the future First Real Local LLM Call, Non-Tool, Non-Authoritative.
