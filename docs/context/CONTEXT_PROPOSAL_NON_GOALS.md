# Context Proposal Non-Goals

Status: active M38 non-goals documentation.
Release: v0.42.0 / M38 - Safe Context Proposal From Approved Review.

M38 does not add:

- context injection
- context handoff approval
- OpenWebUI handoff
- OpenWebUI runtime integration
- model/provider calls
- no model calls
- LLM summarization
- memory writes
- raw file reads
- raw file output or storage
- full-file reads
- no full-file reads
- unredacted preview
- arbitrary filesystem reads
- caller-selected roots
- directory traversal or listing
- symlink following
- file mutation
- export or download
- tool/action/task execution
- shell or subprocess execution
- network calls
- mobile/native work
- plugin enablement
- backend context injection/model/OpenWebUI routes
- Control Center context proposal surface
- production authority

The proposal is non-authoritative and not context injection. It does not write
memory. It does not export. It does not execute. M39 remains
planned/provisional.
