# Memory Recall Planning

M24 includes planning metadata for future recall review: `context_pack_eligible`, `injection_priority`, `recall_budget_tokens`, `importance_score`, `last_referenced_at`, and `retrieval_hint`.

These fields are metadata only. There is no context injection in M24. There is no prompt alteration runtime, no Fabric/plugin bridge, no OpenWebUI memory bridge, no automatic context pack runtime, no RAG ingestion, no semantic search, no vector DB, and no embeddings.

Memory is recall, not authority. Memory is not ground truth. Canonical files, evidence manifests, receipts, Event Ledger records, and user-reviewed sources outrank memory.
