# MemoryOS Review Incorporation

M24 borrows safe MemoryOS-inspired concepts as metadata only:

- taxonomy.
- source hierarchy.
- metadata discipline.
- source-linked structured facts.
- review and provenance metadata.
- confidence and trust metadata.
- dedup and decay planning.
- archive planning.
- surgical-recall vocabulary.
- future context-pack eligibility metadata.

M24 rejects or defers operational concepts:

- authoritative memory.
- Qdrant or other vector DB.
- embeddings.
- Redis, ARQ, Docker, cron, or background workers.
- automatic extraction.
- post-LLM learning.
- session-end learning.
- provider calls.
- wiki curation.
- raw conversation or session-history storage.
- context injection.

UAA adaptation: memory is high-salience recall, never authority. Memory is not ground truth. Canonical files, evidence manifests, receipts, Event Ledger records, and user-reviewed sources outrank memory.
