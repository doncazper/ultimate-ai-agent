# Memory Conflict And Staleness

Memory can be stale, conflicting, superseded, corrected, revoked, or deleted. M24 adds conflict and staleness metadata so recall records can be reviewed safely.

Memory does not overwrite canonical truth. Memory does not bypass evidence, receipts, Event Ledger records, user-reviewed sources, Approval Authority, Consent Ledger, Tool Broker, Secret Broker, Redaction, Foundation Gate, or verifier scripts.

Memory is recall, not authority. Memory is not ground truth. Canonical files, evidence manifests, receipts, Event Ledger records, and user-reviewed sources outrank memory.
