# Memory Non Goals

M24 does not implement:

- cloud memory.
- vector DB.
- embeddings.
- semantic search.
- RAG ingestion.
- automatic memory.
- automatic extraction.
- model write.
- local LLM write.
- OpenWebUI chat memory write.
- Control Center memory mutation.
- mobile capture ingestion.
- tool output write.
- raw session history.
- auto-curated wiki.
- Redis, Qdrant, ARQ, Docker, cron, or background worker.
- production persistence.
- UI mutation.
- backend memory mutation API.
- context injection.
- M25 truth source router or evidence claim checker.

Memory is recall, not authority. Memory is not ground truth.
