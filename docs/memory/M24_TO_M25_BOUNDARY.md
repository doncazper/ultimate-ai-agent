# M24 To M25 Boundary

M24 adds Memory Provider Abstraction + Local Memory Store. It provides reviewed-write-only memory contracts, local store support, source priority, provenance, retention/delete/export, conflict/staleness, dedup/decay/archive planning, and recall planning metadata.

M24 does not make memory truth. M24 does not verify claims. M24 does not implement retrieval/RAG, semantic search, vector DB, embeddings, external source ingestion, web search, context injection, tool execution, model/provider calls, OpenWebUI runtime bridge behavior, mobile capture ingestion, Control Center mutation, or backend mutation routes.

M25 is now implemented/released as the Truth Source Router + Evidence Claim
Checker milestone. M25 checks provided claim/evidence/source refs
deterministically and locally, but it still does not make memory authority,
does not write memory, does not mutate evidence, does not inject context, does
not fetch sources, does not run web search, and does not call models/providers.
M26 remains future as Grounded Recall Router + Evidence-Linked Context Pack
Builder.

Memory is recall, not authority. Memory is not ground truth. Canonical files, evidence manifests, receipts, Event Ledger records, and user-reviewed sources outrank memory.
