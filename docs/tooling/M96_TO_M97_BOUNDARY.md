# M96 to M97 Boundary

M96 is Plugin Execution Sandbox, No External Plugins. It allows only a built-in test plugin sandbox contract with exact safe refs, manifest permission checks, audit receipt, revocation, and deterministic safe output.

M97 is Recurring Automation Contracts and remains future. M96 does not add recurring automation contracts, recurring execution, background workers, cron, daemon behavior, renewal, or cadence runtime.

The M96 boundary denies external plugin loading, marketplace plugin use, arbitrary plugin code, runtime import, networked plugin fetch, plugin secret access, raw plugin payload, shell execution, network access, browser automation, filesystem mutation, model provider call, memory write, context injection, backend route, Control Center control, dependency, production authority, and M97 work.
