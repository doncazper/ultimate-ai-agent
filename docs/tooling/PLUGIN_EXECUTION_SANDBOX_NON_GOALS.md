# M96 Plugin Execution Sandbox Non-Goals

M96 does not implement external plugin loading. It does not implement marketplace plugins, arbitrary plugin code, runtime imports, networked plugin fetch, plugin secret access, raw plugin payloads, shell execution, network access, browser automation, filesystem mutation, model provider calls, memory writes, context injection, backend routes, Control Center controls, dependency changes, production authority, recurring automation, or M97.

M96 is intentionally small: a deterministic built-in test plugin sandbox with manifest permission checks and audit receipt only.

M97 remains future.
