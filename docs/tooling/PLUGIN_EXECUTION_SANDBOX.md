# M96 Plugin Execution Sandbox, No External Plugins

v1.0.0 / M96 adds the first plugin execution sandbox contract for a built-in test plugin only. The only allowed invocation is a deterministic built-in no-op/test plugin selected by exact safe refs.

The sandbox enforces manifest permission checks, exact plugin/action/permission refs, prior plugin install-review binding, audit receipt creation, revocation binding, deterministic output refs, safe refs only, and evaluator boundaries revalidate safety-critical fields.

M96 adds no external plugin loading, no marketplace plugin, no arbitrary plugin code, no runtime import, no networked plugin fetch, no plugin secret access, no raw plugin payload, no shell execution, no network access, no browser automation, no filesystem mutation, no model provider call, no memory write, no context injection, no backend route, no Control Center control, no dependency, no production authority, and no M97 work.

M97 remains future.
