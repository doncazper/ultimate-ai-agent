# Governed Self-Improvement Recovery Contract

Status: triage-ready recovery source. It grants no self-modification,
automatic training, hidden memory update, or automatic merge authority.

Detailed recovered plan:
`docs/implementation/UAA_GOVERNED_SELF_IMPROVEMENT_IMPLEMENTATION_PLAN.md`.

Vision status: high-confidence archive recovery. The preserved product loop is
observe, classify, propose, review, separately implement, test/evaluate, return
for PR review, and learn from the reviewed outcome. No phase implies
self-granted implementation, Git, merge, release, or deployment authority.

## Outcome

Create a review-as-you-go improvement loop that turns redacted outcomes,
evaluation gaps, correction decisions, and operator feedback into explainable
proposals and verified changes.

## In Scope

- Raw fact to candidate to proposal to human decision to verified result flow.
- Provenance, uncertainty, exception, rejection, and unknown handling.
- Bounded evaluation and regression evidence for accepted improvements.

## Out Of Scope

- Autonomous code changes, automatic fine-tuning, raw sensitive-content
  training, hidden context injection, self-granted authority, or auto-merge.

## Acceptance

- Source-specific rights and evidence are required before any reuse claim.
- Learning proposals cannot rewrite historical facts or approval records.
- Every accepted improvement is independently reviewed, reversible, and
  regression-tested.
