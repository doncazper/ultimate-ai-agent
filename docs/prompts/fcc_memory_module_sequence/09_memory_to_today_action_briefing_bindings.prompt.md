# Memory To Today, Action, And Briefing Bindings

Goal: bind governed Memory to operator surfaces without execution authority.

Today:
- Show memory hints only when they affect a current priority, blocker,
  follow-up, or decision.
- Each hint needs why shown, source refs, stale/conflict posture, and next safe
  action.

Actions:
- Memory-derived follow-ups/promises become Action Inbox proposals only.
- Action cards show which memory refs caused the proposal.
- No execution.

Morning Briefing:
- Add briefing-safe memory hints for commitments, stale promises,
  missing-evidence follow-ups, and recently corrected preferences.
- Keep hints bounded and reviewable.

Verification:
- Tests for Today hints, Action proposals, Briefing hints, and no execution.
