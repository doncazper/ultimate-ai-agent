# Contract Versioning Eval

Status: Draft foundation eval, v0.5.3.

## Purpose

Checks M1 contracts are provisional pre-gate and compatibility-protected post-gate.

## Required checks

```text
input fixtures exist
expected pass and fail cases exist
event receipts contain required references
failures are explicit and actionable
```

## Blocking

This eval must pass before Foundation Gate if it protects a foundation module.
