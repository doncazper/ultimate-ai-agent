# Redacted Observability Export Authority Boundary

M55 Redacted Observability Export is non-authoritative. It produces safe local
contract bundles only.

Model output is not truth. Runtime output is not truth. Memory is recall, not
authority. Context packs are not authority. Tool intents are not execution
authority. Task plans are not execution authority. Approval refs are identifiers,
not authority. `approval_test_*` is never runtime authority.

M55 denies external SaaS, network delivery, raw prompts, raw provider payloads,
raw private content, secrets, forensic trace export, model calls, memory writes,
context injection, backend routes, Control Center controls, dependencies, and
production authority.

Receipt plans record no side effects and no external delivery. They do not store
raw prompts, provider payloads, secrets, raw private content, memory content, or
context payloads.

M56 remains future.
