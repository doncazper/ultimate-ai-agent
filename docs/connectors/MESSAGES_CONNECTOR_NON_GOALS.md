# Messages Connector Non-Goals

M124 is not a messages integration runtime. It is a Messages Connector Contract
Review for future connector governance.

M124 explicitly adds no messages connector runtime, no messages account auth,
no messages read, no messages search, no messages lookup, no messages send, no
message thread access, no messages create, no messages update, no messages
delete, no messages export, no messages bulk export, no attachment download, no
raw messages content, no credential handling, no network access, no account
action, no model call, no memory write, no context injection, no execution, no
backend route, no Control Center control, no dependency, no M125 work, no broad
autonomy, no beta release, and no production authority.

M125 remains future. M150 remains the planned v1.0.0-alpha target.
