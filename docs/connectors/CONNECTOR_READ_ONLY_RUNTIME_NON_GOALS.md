# Connector Read-Only Runtime Non-Goals

M125 does not implement live connector runtime, account auth, network access,
credential handling, raw connector content, full content read, connector write,
connector send, connector delete, connector export, connector bulk export,
attachment download, model call, memory write, context injection, execution,
backend route, Control Center control, dependency, M126 work, beta release, or
production authority.

M125 safe metadata preview refs are not a source of account authority, connector
write authority, export authority, model authority, memory authority, context
authority, execution authority, backend route authority, or production
authority.

M126 remains future. M150 remains the planned v1.2.0-alpha target.
