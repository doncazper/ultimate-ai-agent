calendar scope refs, calendar boundary refs, event boundary refs, consent
boundary refs, data classification refs, retention boundary refs,
source-email-connector-contract-refresh-bound refs, audit refs, replay refs,

contacts connector contracts, calendar connector runtime, calendar account
auth, calendar read, calendar search, calendar event create, calendar event
update, calendar event delete, calendar invite send, attachment download, raw
calendar content, credential handling, network access, account action, model
call, memory write, context injection, execution, backend route, Control
