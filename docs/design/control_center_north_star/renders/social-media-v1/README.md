# Social Media Intelligence Render Pack V1

Status: accepted planning-only concept direction
Accepted: 2026-07-13
Scope: four desktop visual targets; no implementation evidence

This render pack records the accepted product composition for UAA Social Media
Intelligence and its projections into existing owner applications. The images
contain illustrative mock data. They do not prove a route, backend read model,
connector, account access, publishing, reply, external scheduling, provider
call, background sync, public release, or production authority.

## Ownership Rule

Social owns interpretation. Calendar owns time. Work Board owns production.
Communications owns conversations. CRM owns relationships. Studio owns assets.
Evidence owns proof.

The accepted layout keeps Social as a command-and-interpretation layer rather
than duplicating the Calendar, Kanban board, inbox, CRM, or asset studio. The
primary command view leads with the creator's most decision-useful signals,
then routes the operator into the canonical app where work belongs.
