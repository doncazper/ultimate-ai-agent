# Control Center Draft Renders

Status: draft design exploration only.

Files in this directory are not accepted north-star baselines, shipped UI
screenshots, runtime evidence, or product-truth proof. Visible records, counts,
timestamps, readiness states, receipts, and controls are illustrative mock data.
They do not demonstrate a wired backend contract or grant authority.

A draft may move into the accepted render set only after its route, data-state,
blocked-state, authority, and product-language claims are reviewed and the
canonical render manifest and surface coverage are updated.
