# M150 Ultimate AI Agent Alpha Authority Boundary

M150 records the local `v1.0.0-alpha` target only. It is not a public release
mechanism and not a distribution mechanism.

Allowed scope:

- safe refs for accepted M101-M149 checkpoints
- safe alpha target refs
- safe M149 release candidate freeze refs
- safe alpha readiness, evidence, blocker, signoff, and beta promotion gate refs
- audit, replay, revocation, kill-switch, and no-effect receipt refs

Denied scope:

- no release publication
- no release tag
- no tag creation
- no artifact build
- no artifact upload
- no artifact export
- no external distribution
- no App Store submission
- no TestFlight submission
- no beta release
- no release automation
- no backend route
- no Control Center control
- no dependency
- no production authority

Beta remains future and requires separate reviewed promotion.
