# M144 Non-Goals

M144 does not implement a plugin marketplace runtime.

It does not add plugin install, plugin enablement, plugin execution, external
plugin loading, marketplace publishing, listing mutation, package import,
runtime import, network plugin fetch, package download, artifact upload,
signature runtime verification, credential handling, backend routes, Control
Center controls, dependencies, alpha release, beta release, or production
authority.

M145 remains future Enterprise/Pro Safety Modes work.
