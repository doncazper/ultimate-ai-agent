# M144 Authority Boundary

M144 is policy draft authority only. It can validate safe refs and record a
no-effect policy draft record for review.

M144 must not install plugins, enable plugins, execute plugins, publish
marketplace listings, mutate marketplace listings, import plugin packages,
import runtime code, fetch plugin packages from the network, download packages,
upload artifacts, verify signatures at runtime, handle credentials, add backend
routes, add Control Center controls, add dependencies, start alpha release,
start beta release, or grant production authority.

Marketplace approval refs remain policy refs only. They do not grant plugin
install, plugin enablement, plugin execution, publishing, external plugin
authority, or production authority.
