# M94 to M95 Boundary

M94 implements Autonomous Browser Clicks, Low-Risk Only. It permits only a
low-risk click in a scoped session on an allowlisted page and allowlisted action
with exact M93 binding, exact click approval, audit, revocation, injected
transport, safe refs only, and safe summary only receipt data.

M95 remains future as Network Tool Expansion, Authless Only. M94 does not start
M95 and does not add unrestricted network tools, authenticated network actions,
POST/PUT/PATCH/DELETE mutation tools, credential headers, cookies, account
actions, private network access, or raw network output.

M94 continues to deny no form submission, no typing, no purchase, no download,
no upload, no authentication, no account change, no destructive action, no
credential or cookie access, no raw DOM, no screenshot, no broad navigation, no
external network, no shell execution, no plugin execution, no model call, no
memory write, no context injection, no backend route, no Control Center control,
no dependency, and no production authority. Evaluator boundaries revalidate all
safety-critical fields.
