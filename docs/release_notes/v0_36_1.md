# v0.36.1 Release Notes

Status: active release notes.

Current active baseline: **v0.36.1**

v0.36.1 hardens M32 - Safe Tool Runtime Expansion, Filesystem Metadata Path
Safety.

Implemented:

- stronger normalization for filesystem metadata relative paths.
- denial of encoded traversal such as `%2e%2e`.
- denial of home-directory paths, Windows drive paths, doubled separators, and
  unsafe separators.
- denial of hidden and private-key-like path segments.
- evaluator denial for model_copy-mutated root/path/tool_ref fields.
- evaluator denial for metadata alias flags that attempt to enable raw content,
  text previews, content hashes, directory listing, recursion, symlink
  following, caller-selected roots, or mutation.
- static verifier and Foundation Gate probes for the hardening cases.
- active docs, release notes, and release archive packet.

Safety boundaries:

- no arbitrary tool execution.
- no raw file content read.
- no text preview.
- no content hash.
- no directory listing.
- no recursive traversal.
- no symlink following.
- no file mutation.
- no shell/subprocess execution.
- no memory writes.
- no network calls.
- no model/provider calls.
- no browser/mobile/remote/plugin tools.
- no backend execution or raw-file routes.
- no Control Center execute or raw-preview controls.
- no dependencies.
- no M33 work.
- no production authority.

OpenAPI path count remains `74`.

M33-M40 remain planned/provisional.
