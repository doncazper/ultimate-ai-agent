# Release Notes v0.10.0

v0.10.0 implements Milestone M6 (Contract Tests, Shadow Replay, and Foundation Gate evaluation).

## Added

- Typed Foundation Gate criteria, results, reports, status enums, validation helpers, and static evaluators.
- M5 shadow replay for the Minimum Lovable Kernel local/dev trace, including ordered event capture, receipt reference, memory source refs, world-state event refs, rollback verification, and denial-path no-write verification.
- Contract compatibility tests across envelopes, hygiene, execution/context contracts, ledger, world state, runtime, adapters, consent, tools, secrets, providers, memory, files, truth/evidence, and kernel request/result models.
- Validation-only API routes for gate reports and shadow replay scenarios.
- Local runner script: `scripts/run_foundation_gate.py`.
- Sample safe reports under `reports/foundation_gate/`.

## Still blocked

M6 does not implement scanners, companion proactivity, Skill Factory, self-improving code, autopilot workflows, real provider integrations, web fetching, real model calls, real tools/external actions, production memory storage, pgvector, embeddings, browser automation, real SDK/A2A runtime delegation, OAuth flows, production secret vaults, production truth connectors, or high-autonomy execution.
