# Release Notes v0.11.2

v0.11.2 stabilizes the M7.5 API boundary contract.

## Added

- Typed `/api/manifest` metadata with route inventory, route groups, side-effect classes, declared capabilities, and blocked capabilities.
- Deterministic OpenAPI operation IDs and route tags.
- `scripts/export_openapi.py` for stdout-first schema export.
- `scripts/verify_openapi_contract.py` and `verify_all.py` integration.
- AGENTS.md workspace standards and API boundary documentation.
- Foundation Gate criteria for API manifest presence, OpenAPI validity, operation ID uniqueness, forbidden runtime route absence, AGENTS guidance, and runtime agent config loading absence.
- CI coverage for OpenAPI contract verification.

## Still blocked

v0.11.2 does not implement real model calls, provider API calls, tokenizer API calls, billing API calls, network calls, scanners, companion proactivity, Skill Factory, self-improving code, autopilot workflows, web fetching, real tools/external actions, production memory storage, pgvector, embeddings, browser automation, real SDK/A2A runtime delegation, runtime agent config loading, OAuth flows, production secret vaults, production truth connectors, or high-autonomy execution.
