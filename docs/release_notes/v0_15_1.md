# Release Notes v0.15.1

Status: Active clarification release baseline.

v0.15.1 clarifies M11 runtime readiness taxonomy on top of accepted v0.15.0.

Changed:

- `local_loopback_policy` remains `supported`, but is now explicitly described as a validation-only contract.
- real local loopback smoke execution remains manual-only, approval-gated, fixed-prompt-only, and non-authoritative.
- `fake_manual_loopback_smoke` is explicitly documented as a fake/test report origin only.
- manual smoke report validation rejects production runtime, production readiness, production evidence, real runtime origin, and real model output claims.
- focused tests cover the clarified local loopback policy wording and fake/test smoke origin boundary.

Not added:

- no runtime execution.
- no cloud/provider/model calls.
- no provider SDKs.
- no tokenizer or billing integrations.
- no remote execution.
- no live private mesh/tailnet, Headscale, Tailscale, or WireGuard calls.
- no mobile sensor access.
- no plugin/tool enablement.
- no native builds.
- no dependencies.
- no API routes.
- no production persistence.
- no production readiness claim.

Manual smoke reports remain validation artifacts only. Model output remains non-authoritative.
