# Release Notes v0.30.1

Status: Current release notes.

## Summary

v0.30.1 hardens M26: Grounded Recall Router + Evidence-Linked Context Pack
Builder by enforcing recall source_ref/source_kind consistency.

## Changed

- Denies candidates whose recognized source_ref prefix does not match declared
  source_kind before recall selection or context-pack planning.
- Denies memory/model/runtime/OpenWebUI refs even when a caller declares them as
  canonical, evidence, receipt, event, or user-reviewed source kinds.
- Prevents caller-declared source_kind from upgrading source priority.
- Adds regression tests, static verifier probes, and Foundation Gate coverage
  for source identity mismatch bypasses.
- Updates M26 hardening docs, archive packets, and version files to v0.30.1.

## Safety

v0.30.1 adds no backend routes, frontend features, vector search, embeddings,
semantic search, RAG ingestion, web search, external retrieval, source crawling,
arbitrary file reads, model/provider calls, local LLM calls, memory writes,
evidence mutation, Event Ledger mutation, context injection runtime, OpenWebUI
runtime bridge, dependencies, or production authority. OpenAPI path count
remains `74`. M27 remains planned/provisional.
