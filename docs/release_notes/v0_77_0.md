# Release Notes v0.77.0

v0.77.0 implements M73 Browser Automation Contract Review.

This release adds contract-only, review-only browser automation contract review
models, validation helpers, decision envelopes, receipt plans, tests, static
verification, documentation-integrity checks, and Foundation Gate coverage.

M73 keeps browser automation disabled by default. It allows only safe review of
future browser capability categories and treats the observe-only browser adapter
as an M74 candidate only.

This release adds no browser automation, no browser observe, no browser
navigation, no browser click, no form fill, no screenshot, no raw DOM, no
authenticated browser profile, no cookies or credentials, no download or
upload, no remote browser, no network interception, no network call, no model
call, no tool execution, no memory write, no context injection, no backend
route, no Control Center control, no dependency, no M74 work, and no production
authority.

M74 remains future.
