# Release Notes v0.24.0

Status: Current release notes for v0.24.0 / M20.

v0.24.0 implements M20 Device Capability Broker Contract.

Added:

- contract-only `src/ultimate_ai_agent/core/device_capabilities/` models,
  enums, manifest builders, validation helpers, policy helpers, and receipt
  plan helpers.
- default Device Capability Broker manifest for CCC iOS, CCC Android, CCC
  macOS, and mobile web/PWA planning surfaces.
- tests for contract-only manifests, planned-disabled capabilities, no sensor
  access, no OS permission integration, no silent capture, no background
  capture, no automatic memory write, no external send, no raw payloads, no
  background services, no runtime pairing, no device authority, and secret-free
  metadata.
- Device Capability Broker contract docs under `docs/device_capabilities/`.
- Foundation Gate and verifier coverage for the M20 safety boundary.

Safety boundary:

- no mobile app.
- no Android app.
- no iOS app.
- no macOS app.
- no native build workflow.
- no OS permission runtime.
- no sensor access.
- no push notification runtime.
- no background service runtime.
- no device pairing runtime.
- no backend API route.
- no runtime execution.
- no model/provider call.
- no remote execution.
- no plugin enablement.
- no dependency.
- no production authority.

OpenAPI path count remains `74`. M21 remains planned/provisional.
