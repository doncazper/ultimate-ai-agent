# Release Notes v0.13.0

## M9 Local Loopback Model Runtime Adapter

v0.13.0 adds the first constrained local model runtime milestone.

Added:

- loopback-only endpoint validation
- dev-only execution policy with explicit opt-in
- local runtime execution decisions
- fake transport for deterministic tests and Foundation Gate
- disabled network transport as the default no-send transport
- simulated fallback for blocked local execution
- approval validation requirement for real local/dev execution
- API routes for endpoint validation, execution validation, and simulated fallback
- Foundation Gate criteria for M9 no-remote/no-cloud/no-provider behavior

Guardrails:

- no cloud model calls
- no provider SDKs
- no API keys or secret reads
- no non-loopback hosts
- no tokenizers or billing APIs
- no real network/model calls in tests, CI, `verify_all.py`, or Foundation Gate
- no production auth, OAuth, persistence, scanners, browser automation, SDK/A2A runtime delegation, or external actions

The model remains non-authoritative. Local loopback responses and simulated fallback responses are marked as not truth authority.
