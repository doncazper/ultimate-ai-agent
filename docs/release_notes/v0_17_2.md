# Release Notes v0.17.2

Status: Historical release notes for the Web Control Center CI, static safety, and local browser smoke readiness hardening patch.

v0.17.2 hardens the M13 Web Control Center read-only frontend shell verification path.

Added:

- frontend CI coverage for `npm ci`, typecheck, lint, tests, and build inside `apps/control-center`.
- `docs/control_center/LOCAL_BROWSER_SMOKE.md` for manual local-only browser smoke readiness.
- `scripts/verify_control_center_browser_smoke_readiness.py`.
- `scripts/verify_all.py` integration for browser smoke readiness verification.
- Foundation Gate criteria for frontend CI and browser smoke readiness.
- regression tests for the browser smoke readiness verifier, strengthened frontend safety verifier behavior, and M13 gate integration.

Strengthened:

- static frontend safety checks reject analytics and external SDK dependency markers.
- local browser smoke remains manual, local-only, unauthenticated-profile-free, non-authoritative, and outside CI browser execution.

Unchanged:

- backend OpenAPI path count remains `74`.
- Control Center backend routes remain read-only/preview-only.
- Web Control Center remains a local shell with no production authority.
- Python Agent Core remains the brain.

Not added:

- production Control Center authority.
- public execution API.
- runtime/model/provider calls.
- remote dispatch.
- mobile/native app or sensor access.
- plugin enablement.
- Chrome authenticated profile control.
- Computer Use automation.
- iOS/macOS build workflow.
- analytics/auth/payment/SaaS SDKs.
- production persistence.
