# Release Notes v0.18.2

Status: Current release notes for Open Design System and UI Design Governance.

v0.18.2 defines the repo-owned Open Design System and Control Center UI Design Governance foundation before M15 approval, receipt, and event viewer UI expansion.

Changed:

- active version metadata now points to `0.18.2`.
- README, documentation index, canonical map, import docs, master plan, and Foundation Gate plan point to v0.18.2.
- `docs/design/OPEN_DESIGN_SYSTEM.md` defines repo-owned design source of truth.
- `docs/design/CONTROL_CENTER_DESIGN_LANGUAGE.md` defines dense operational Control Center design principles.
- `docs/design/STATUS_AND_RISK_VISUAL_LANGUAGE.md` defines textual risk and status treatment.
- `docs/design/ACCESSIBILITY_BASELINE.md` defines accessibility rules for future UI work.
- `docs/design/DESIGN_TOOLING_POLICY.md` keeps design tools disabled and non-authoritative.
- `docs/design/DESIGN_TOKEN_ROADMAP.md` records future token groups without implementation.
- `docs/design/UI_COPY_AND_ACTION_LANGUAGE.md` governs preview-only action language.
- `docs/design/DESIGN_ARTIFACT_GOVERNANCE.md` governs screenshots, mockups, exports, and visual artifacts.
- `docs/design/COMPONENT_TAXONOMY.md` names current and future component classes.
- `docs/design/RESPONSIVE_LAYOUT_BASELINE.md` defines desktop/tablet/narrow expectations.
- documentation integrity and Foundation Gate checks now cover design governance.

Unchanged:

- backend OpenAPI path count remains `74`.
- Control Center backend routes remain read-only/preview-only.
- the frontend still declares exactly one POST target: `/control-center/actions/preview`.
- Python Agent Core remains the brain.
- local browser smoke remains manual, local-only, unauthenticated-profile-free, and non-authoritative.
- M15 Approval Queue + Receipt/Event Viewer UI remains future work.
