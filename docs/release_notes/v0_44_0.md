# v0.44.0 Release Notes

Status: historical release notes.
Release: **v0.44.0 / M40 - Context Handoff Approval, No Injection**.

v0.44.0 implements M40. It adds contract-only Context Handoff Approval over M38
safe context proposals and M39 display boundaries. The contracts enforce exact
proposal binding, approval_ref and approval_test_ denial, expired/revoked/replay
denial, review-only decisions, no-injection invariants, receipt plans, tests,
static safety verification, documentation-integrity checks, and Foundation Gate
coverage.

## Added

- `src/ultimate_ai_agent/core/context_handoff/` contracts, validation, workflow,
  policy helper, and receipt-plan helper.
- Tests for approval contracts, exact binding, no-injection denial,
  evaluator revalidation, receipt plans, and Foundation Gate coverage.
- M40 docs, release packet, static verifier checks, documentation-integrity
  checks, and Foundation Gate criteria.

## Preserved Boundaries

M40 adds no automatic context injection, OpenWebUI handoff execution,
OpenWebUI runtime integration, model/provider calls, LLM summarization, memory
writes, export/download/copy-raw controls, execution/tool/action/task controls,
approval mutation controls, backend routes, raw file reads, raw file content
display/storage, full-file content display, unredacted preview display, raw
absolute path display, arbitrary file reads, file picker/browser/upload/root
selector controls, directory traversal/listing, file mutation, shell/subprocess,
network calls, mobile/native work, plugins, dependencies, M41 work, or
production authority.

M41 remains future.
