# Checkpoint M116 Release Notes

Checkpoint M116 implements Role-Based Authority Model while the product
baseline remains v1.7.2. It uses the checkpoint-m116 tag and keeps M150 as the
planned v1.0.0-alpha target.

## Added

- Contract-only, review-only role-based authority model records.
- Safe role refs, authority scope refs, permission boundary refs,
  separation-of-duty refs, and break-glass boundary refs.
- Exact binding to M115 Production Audit Retention Policy.
- No-effect receipt planning, static verifier checks, documentation integrity
  checks, and Foundation Gate coverage.
