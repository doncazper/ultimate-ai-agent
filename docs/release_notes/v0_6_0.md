# Release Notes v0.6.0

Status: Released

v0.6.0 implements Milestone M2 (Event Ledger, Deterministic Run State, Receipts, and Observability Standards Mapping).

## What's New

* **M1 Hygiene Versioning**: Moved project release numbers away from Pydantic schema version defaults, introducing stable schema version tags (e.g., `execution_contract.v0` and `context_pack.v0`).
* **Event Ledger Event Model**: Built the `EventLedgerEvent` schema incorporating trace propagation, causation/correlation mapping, cost attributes, and data classification fields.
* **Deterministic Run State Machine**: Defined transition matrices checking execution paths for runs and verifying that invalid states or terminal mutations raise `InvalidStateTransitionError`.
* **Append-Only Immutable Ledger**: Implemented `EventLedger` providing validation checks rejecting duplicate event IDs, duplicate idempotency keys, and scanning payloads to reject raw secrets.
* **Trace Propagation**: Standardized W3C Trace Context validation utilities.
* **OTel and CloudEvents Mapping**: Coded metadata-level converters translating internal events to OpenTelemetry GenAI span semantics and CloudEvents format envelopes.
* **Redacted User-Safe Receipts**: Coded deterministic receipt generators compiling cost summaries, actions taken, file changes, and redactions applied without logging raw details.
* **FastAPI Validation Routes**: Exposed `/events/validate`, `/runs/state/transition/validate`, and `/receipts/preview` return schemas.
* **Testing Coverage**: Added 20 new test assertions across 6 test modules, bringing the total passing tests count to 50.

## Known Non-Goals

* External telemetry export streams (to OTel collectors or message brokers) and DB mutations remain stubs or document-only. No real tools, models, or provider integrations are implemented in M2.
