# v0.43.0 Release Notes

Status: historical release notes.
Release: **v0.43.0 / M39 - CCC Context Proposal Surface**.

v0.43.0 implements M39. It adds a read-only Control Center surface for M38 Safe
Context Proposal objects, including safe mock data, proposal-only status,
approved-review provenance, exact binding refs, redaction verification, safe
proposal section display, receipt-plan metadata, frontend tests, documentation,
static safety verification, and Foundation Gate coverage.

## Added

- `/context/proposals` frontend route.
- `ContextProposalSurfacePanel` read-only CCC component.
- Safe mock context proposal data with redacted sections and exact binding refs.
- Frontend tests for M39 route rendering, binding display, and absence of
  handoff/injection/mutation controls.
- M39 docs, static verifier checks, documentation-integrity checks, and
  Foundation Gate criteria.

## Preserved Boundaries

M39 adds no context handoff approval, context injection, OpenWebUI handoff,
OpenWebUI runtime integration, model/provider calls, LLM summarization, memory
writes, export/download/copy-raw controls, execution/tool/action/task controls,
approval mutation controls, backend routes, raw file reads, raw file content
display/storage, full-file content display, unredacted preview display, raw
absolute path display, arbitrary file reads, file picker/browser/upload/root
selector controls, directory traversal/listing, file mutation, shell/subprocess,
network calls, mobile/native work, plugins, dependencies, M40 work, or
production authority.

M40 remains future.
