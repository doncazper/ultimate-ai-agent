# Release Notes v0.27.0

Status: Historical release notes for v0.27.0 / M23 First Real Local LLM Call,
Non-Tool, Non-Authoritative. Superseded by v0.27.1.

v0.27.0 implements the first bounded local model call path while keeping the
result manual, local-only, non-tool, and non-authoritative.

Changed:

- added M23 local model call contracts for fixed prompt requests, decisions,
  transport results, receipts, and safe result summaries.
- added loopback-only endpoint validation for manual local calls.
- added fixed prompt `m23_fixed_local_model_smoke_v1`.
- added a fake transport for tests and Foundation Gate coverage.
- added a manual stdlib loopback transport for CLI-only use.
- added `scripts/manual_local_model_call.py` with dry-run default and explicit
  `--execute-local-call`.
- added local approval validation for actual execution attempts.
- added response redaction and secret-like response blocking.
- added M23 tests, static verifier coverage, and Foundation Gate criteria.
- updated active docs, version files, roadmap status, and release materials for
  v0.27.0.

Safety boundary:

- dry-run is default.
- real local execution requires `--execute-local-call`.
- execution requires validated local approval.
- endpoint policy is loopback-only HTTP.
- prompt is fixed and non-sensitive.
- no arbitrary prompt, stdin prompt, file prompt, clipboard prompt, memory
  prompt, OpenWebUI transcript prompt, or user content is accepted.
- response text is capped, redacted, and never stored as raw response.
- model output is non-authoritative and not trusted control input.
- tests and Foundation Gate use fake transport only.
- a real manual local call was not run for release validation.

This release adds no backend API route, no OpenAPI path count change, no runtime
activation, no endpoint probe, no provider SDK, no runtime package, no tokenizer,
no billing API, no OpenWebUI runtime bridge, no Control Center execution
control, no tool execution, no memory write, no file write, no remote execution,
no mobile sensor access, no plugin enablement, no dependency, and no production
authority.

OpenAPI path count remains `74`. M24-M40 remain planned/provisional.
