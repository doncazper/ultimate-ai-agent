# Release Notes v0.30.0

Status: Current release notes.

## Summary

v0.30.0 implements M26: Grounded Recall Router + Evidence-Linked Context Pack
Builder.

## Changed

- Adds `ultimate_ai_agent.core.recall` contract models, deterministic source
  priority, safe recall candidate routing, and evidence-linked context-pack
  building.
- Adds tests for recall contracts, source priority, safe exclusions, context
  pack building, no context injection, no raw content, no vector/embedding
  runtime, and no memory writes.
- Adds M26 documentation, static verifier checks, and Foundation Gate criteria.
- Updates roadmap, release docs, archive packets, and version files to v0.30.0.

## Safety

M26 adds no backend routes, frontend features, vector search, embeddings,
semantic search, RAG ingestion, web search, external retrieval, source crawling,
arbitrary file reads, model/provider calls, local LLM calls, memory writes,
evidence mutation, Event Ledger mutation, context injection runtime, OpenWebUI
runtime bridge, dependencies, or production authority. OpenAPI path count
remains `74`. M27 remains planned/provisional.
