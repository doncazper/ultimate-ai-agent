# Release Notes v0.12.2

v0.12.2 implements M8.5 Approval Authority + Runtime Authorization Bridge.

## Added

- `src/ultimate_ai_agent/core/approvals/` with typed approval requests, grants, validation decisions, receipts, policy helpers, and a local in-memory `LocalApprovalAuthority`.
- Validation-only approval API endpoints:
  - `POST /approvals/requests/validate`
  - `POST /approvals/grants/validate`
  - `POST /approvals/validate`
  - `POST /approvals/receipts/validate`
- Model Router integration for sensitive cloud route approval validation.
- Model Runtime request factory checks for validated non-test approval refs.
- Tool Broker integration for high-risk and external mutation approval validation.
- Kernel local/dev mutation integration through Tool Broker approval validation.
- Foundation Gate M8.5 criteria proving arbitrary approval refs are not authority.

## Preserved

- M8 remains simulated/dry-run only.
- `approval_test_` compatibility remains local/test-only and is not production authority.
- API validation errors remain sanitized and do not echo secret-like invalid input.

## Still Blocked

v0.12.2 does not implement real model calls, provider SDK calls, OpenAI-compatible endpoint calls, local runtime calls, tokenizer integrations, billing APIs, network calls, scanners, companion proactivity, Skill Factory, self-improving code, autopilot workflows, browser automation, production auth, OAuth, production persistence, real SDK/A2A runtime delegation, production secret vaults, production truth connectors, or high-autonomy execution.
