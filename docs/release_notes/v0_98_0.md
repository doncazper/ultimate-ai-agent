# Release Notes - v0.98.0

v0.98.0 implements M94 Autonomous Browser Clicks, Low-Risk Only.

It adds low-risk click contracts that require a scoped session, allowlisted
page, allowlisted action, exact M93 binding, exact click approval, audit,
revocation, injected transport, safe refs only, safe summary only receipt plans,
evaluator revalidation, static verification, documentation-integrity checks,
tests, and Foundation Gate coverage.

It adds no form submission, typing, purchase, download, upload,
authentication, account change, destructive action, credential or cookie
access, raw DOM, screenshot, broad navigation, unrestricted external network
authority, shell execution, plugin execution, model call, memory write, context
injection, backend route, Control Center control, dependency, M95 work, broad
autonomy, or production authority.
