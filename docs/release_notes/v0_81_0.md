# v0.81.0 Release Notes

v0.81.0 implements M77 - OpenWebUI Safe Handoff Execution.

It adds exact-bound Agent Core safe handoff result contracts, approval binding
validation, receipt plans, documentation, static verification, and Foundation
Gate coverage.

It adds no live OpenWebUI connection, OpenWebUI runtime call, provider call,
model call, model authority, tool execution, memory write, context injection,
network call, credentials or cookies, raw prompt, raw provider payload, raw
content, backend route, Control Center control, dependency, M78 work, or
production authority.
