# Release Notes v0.5.8

Status: Released

v0.5.8 marks the completion of Milestones M0 (Repository Scaffolding) and M0.5 (Runtime Hygiene Primitives).

## What's New

* **Python Scaffolding**: Setup `pyproject.toml`, `.env.example`, and directory structure under `src/ultimate_ai_agent/`.
* **FastAPI App Stub**: Initialized minimal FastAPI app with `/health` and `/version` endpoints.
* **Pydantic Validation Models**: Mapped and implemented core hygiene models directly from JSON schemas:
  * `ActorContext`
  * `TemporalContext`
  * `ErrorEnvelope`
  * `ResultEnvelope`
  * `IdempotencyPolicy`, `DataClassification`, `RedactionPolicy`, and `CapabilityFlag`
* **Test Suite**: Created full suite of tests in `tests/test_hygiene.py` and `tests/test_api.py` validating correct compilation, serialization, and validation properties.
* **Secret Hygiene Scanner Compatibility**: Adapted class properties to prevent false positives in regex-based secret scanning.
