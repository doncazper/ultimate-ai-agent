# Checkpoint M124 Release Notes

Checkpoint M124 adds Messages Connector Contract Review while the current
product baseline remains v1.7.2. It uses the checkpoint-m124 tag and keeps
M150 as the planned v1.0.0-alpha target.

The checkpoint adds contract-only, review-only messages connector review
records bound to the M123 Contacts Connector Contract Refresh. The records use
safe refs for messages scope refs, messages boundary refs, message thread boundary
refs, consent boundary refs, data classification refs, retention boundary
refs, audit, replay, accepted checkpoints, and no-effect receipt plans.

M124 adds no messages connector runtime, no messages account auth, no messages
read, no messages search, no messages lookup, no messages send, no message
thread access, no messages create, no messages update, no messages delete, no
messages export, no messages bulk export, no attachment download, no raw
messages content, no credential handling, no network access, no account action,
no model call, no memory write, no context injection, no execution, no backend
routes, no Control Center controls, no dependencies, no M125 work, no beta
release, and no production authority.

M125 remains future. M150 remains the planned v1.0.0-alpha target.
