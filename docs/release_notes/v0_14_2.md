# Release Notes v0.14.2

## M10.5 Remote Worker Policy Contract Hardening

v0.14.2 hardens the accepted v0.14.1 M10.5 remote-worker foundation. This is a foundation-only patch release, not a new milestone.

Changed:

- `remote_tailnet_enabled=true` is rejected as unsupported/planned in M10.5.
- `remote_personal_data_enabled=true` is rejected as unsupported/planned in M10.5.
- remote-worker API wrapper models reject unexpected top-level fields.
- secret-like top-level extras remain sanitized in API validation responses.
- Foundation Gate now covers these remote-worker policy-contract cases.

No live networking exists in this patch.
No job dispatch exists in this patch.
No remote approvals exist in this patch.

No Tailscale calls, remote execution, remote subagents, remote Tool Broker execution, personal-data access, write/send actions, background services, production persistence, provider SDKs, tokenizers, billing APIs, or safety bypasses were added.
