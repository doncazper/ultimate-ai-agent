# v0.101.0 Release Notes

v0.101.0 is the active Operator Runtime Excellence P1 durable run spine
baseline. It adds contract-level durable run records, state transitions,
idempotency/replay guards, rollback refs, restart recovery refs, and checksum
snapshot validation without granting execution authority.

Evidence-backed scope:

- Active baseline and package version are v0.101.0 / `0.101.0`.
- Latest accepted repository checkpoint tag remains `checkpoint-m168`.
- Latest accepted local model lane checkpoint tags remain `checkpoint-m166` and
  `checkpoint-m167`.
- Current API boundary remains the FastAPI route contract with 93 OpenAPI
  paths.
- Operator Runtime Excellence P0 work through UAA-P0-017 remains accepted
  currentness, security, evidence, performance, packaging, tuning, and
  operational-readiness scaffolding.
- UAA-P1-010 is shipped as a contract spine with tests and documentation.
- Append-first local storage, task decomposition binding, backup/restore
  operation, and product-loop execution remain blocked for later scoped tasks.

Non-goals:

- no public release or public distribution claim
- no beta release claim
- no production authority claim
- no broad autonomy or autonomous background execution
- no new shell/subprocess authority
- no unrestricted network or browser automation
- no connector writes
- no plugin runtime import
- no mobile control
- no provider/model output as authority

v0.101.0 adds no dependency, backend route, Control Center control,
provider/model call, network access, browser automation, shell/subprocess
execution, runtime tool authority, memory write, context injection, beta
release, public distribution, or production authority.
