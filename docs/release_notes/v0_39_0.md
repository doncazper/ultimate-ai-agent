# v0.39.0 Release Notes

Status: current release notes.
Release: **v0.39.0 / M35 - Safe File Review Workflow Contracts**.

v0.39.0 implements M35 Safe File Review Workflow Contracts. It adds
contract-only file review workflow models, redacted review packet validation,
redaction verification, exact approval binding evaluation, review-only decision
envelopes, no-raw receipt plans, evaluator revalidation, documentation
integrity coverage, static verification, and Foundation Gate coverage.

## Added

- `FileReviewWorkflowPolicy`.
- `FileReviewRequest`.
- `FileReviewPacket`.
- `FileReviewPacketSource`.
- `FileReviewRedactionVerification`.
- `UserFileReviewApproval`.
- `FileReviewGate`.
- `FileReviewDecision`.
- `FileReviewReceiptPlan`.
- model-copy revalidation coverage for raw content and future authority flags.
- OpenAPI route guard coverage for M35.
- active M35 documentation and release packet metadata.

## Preserved Boundaries

M35 is review-only and non-authoritative. It adds no raw file access, raw
content, full-file reads, unredacted preview, approval capture, approval
persistence, context proposal, context injection, memory writes, export,
execution, file mutation, backend routes, Control Center file review UI,
dependencies, M36 work, M37 work, M38 work, or production authority.

M36 remains planned/provisional. M37 remains planned/provisional. M38 remains
planned/provisional.
