# Checkpoint M140 Release Notes

Checkpoint M140 implements Higher-Autonomy Red-Team Freeze.

It adds:

- contract-only freeze report models for accepted M131-M139 checkpoint refs
- red-team checklist, audit, replay, revocation, kill-switch, and no-effect receipt refs
- validators that deny red-team runtime, harness execution, adversarial test execution, autonomous execution, broad autonomy, execution, routes, dependencies, alpha/beta release, and production authority
- Foundation Gate, documentation-integrity, verify_all, and focused pytest coverage

It does not add runtime red-team execution, autonomous actions, browser or
connector actions, tool/shell/network/plugin execution, model calls, memory
writes, context injection, backend routes, Control Center controls,
dependencies, alpha release, beta release, or production authority.
