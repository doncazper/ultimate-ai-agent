# v0.54.0 Release Notes

v0.54.0 implements M50 Mobile Approval Audit Hardening.

## Added

- Deterministic safe-ref-only mobile approval audit contracts.
- Audit report coverage for status/decision consistency, duplicate
  idempotency mismatches, raw/secret/path mutations, and authority-field
  mutations.
- Tests, documentation, documentation-integrity checks, static verification,
  and Foundation Gate criteria for M50.

## Safety

M50 adds no raw file access, raw content output, full-file read output,
unredacted preview, context proposal, context injection, memory write, export,
approval execution, tool/action/task execution, mobile sensor access,
background collection, backend mobile audit route, native audit UI, dependency,
M51 implementation, or production authority.
