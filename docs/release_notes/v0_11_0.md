# Release Notes v0.11.0

v0.11.0 implements Milestone M7: Model Router and Cost/Resource Governor policy foundation.

## Added

- Model Router contracts for model capability profiles, routing policies, route requests, and deterministic route decisions.
- Privacy-aware routing enforcement for local-only, sensitive, regulated, TCB-protected, and credential-secret data classifications.
- Capability-aware and context-aware profile filtering.
- Credential availability metadata checks without resolving raw credentials.
- Cost/resource budget, estimate, and decision contracts.
- Cost Governor estimate/evaluate logic for token costs, hard limits, warning thresholds, unknown paid costs, and local resource budgets.
- Non-executing API endpoints for model profile validation, route previews, budget validation, cost estimates, and cost evaluation.
- Foundation Gate checks for M7 module presence, model-router decision-only behavior, and cost-governor over-budget blocking.

## Still blocked

v0.11.0 does not implement real model calls, provider API calls, tokenizer API calls, billing API calls, scanners, companion proactivity, Skill Factory, self-improving code, autopilot workflows, web fetching, real tools/external actions, production memory storage, pgvector, embeddings, browser automation, real SDK/A2A runtime delegation, OAuth flows, production secret vaults, production truth connectors, or high-autonomy execution.
