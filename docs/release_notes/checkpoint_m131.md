# Checkpoint M131 - Autonomy Mode 4 Scoped Work Session

Checkpoint M131 implements Autonomy Mode 4, Scoped Work Session while the
product baseline remains v1.7.2.

Included:

- Mode 4 scoped work-session request, decision, policy, and no-effect receipt
  contracts
- exact scope, actor, user, workspace, resource, capability, allowlist, policy,
  approval bundle, risk, audit, replay, revocation, and kill-switch refs
- safe-ref-only and safe-summary-only validation
- documentation, archive packet, verifier coverage, and Foundation Gate criteria

Not included:

- session start or active scoped autonomy window
- autonomous actions or execution
- tool, shell, command, subprocess, filesystem, network, browser, plugin,
  connector, mobile, remote, model, memory, or context runtime authority
- background workers, schedulers, backend routes, Control Center controls,
  dependencies, beta release, production authority, or M132 implementation

M132 remains planned/provisional.
