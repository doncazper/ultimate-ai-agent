# Release Notes v0.79.0

v0.79.0 implements M75 Browser Action Dry-Run Planner.

This release adds deterministic reviewable browser action dry-run planning
contracts over safe refs only. It adds policy validation, request validation,
step validation, receipt plans, stable reason codes, tests, static verification,
documentation-integrity checks, and Foundation Gate coverage.

The planner is not a browser runtime. It performs no browser action execution,
starts no browser session, performs no browser navigation execution, browser
click execution, form fill execution, screenshot, raw DOM read, authenticated
browser profile access, cookie or credential handling, download or upload,
remote browser control, network interception, network call, model call, tool
execution, memory write, context injection, backend route, Control Center
control, dependency, M76 work, or production authority.

M76 remains future.
