# v0.102.1 Release Notes

Status: current release notes.

v0.102.1 is an incremental Mattermost Agent Rooms module baseline. It keeps the
repo local-first, disabled-by-default, review-gated, and non-production by
default while adding a central UAA Mattermost bridge module and in-repo plugin
scaffold.

## Scope

- Add UAA Mattermost bridge contracts, predefined speak-only role catalog,
  role bindings, trigger policies, message event decisions, receipts, audit
  events, latency fields, and redacted local bridge storage.
- Add `/integrations/mattermost` API routes for status, catalog, role
  suggestion, role bind/unbind, message events, audit inspection, and receipt
  inspection.
- Add an in-repo Mattermost plugin scaffold with `/uaa` command registration,
  committed-post observation, bounded event forwarding, channel allowlist,
  local post dedupe, configured role-bot reply posting, and secret redaction.
- Update OpenAPI, API manifest, Foundation Gate route normalization, route
  currentness docs, and Control Center route-count currentness for the Mattermost
  baseline. Active API docs remain the source of truth for later path-count
  increments.
- Harden the first slice with constant-time bridge bearer comparison, atomic
  local binding writes, bounded audit/receipt query limits, protected role
  catalog access, cooldown enforcement, and hash-based custom role refs.

## Non-Goals

v0.102.1 does not fork Mattermost or OpenWebUI, does not add production
authority, public distribution, public beta, arbitrary plugin execution,
unrestricted network/browser automation, connector writes outside exact reviewed
scopes, shell/subprocess execution, model/provider output authority, memory
write, context injection, raw transcript persistence, raw prompt export, raw
provider payload export, credential/cookie handling, or automatic Mattermost bot
account lifecycle management.

## Verification Notes

This baseline should be verified with the version truth checker, current
baseline verifier, documentation-integrity verifier, OpenAPI verifier,
Foundation Gate report-only mode, Ruff, focused Mattermost tests, and the full
pytest suite. Go plugin tests require a local Go toolchain.
