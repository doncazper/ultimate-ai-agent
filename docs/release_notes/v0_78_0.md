# Release Notes v0.78.0

v0.78.0 implements M74 Browser Observe-Only Adapter.

This release adds a local observe-only browser adapter contract that converts
explicit injected observation records into redacted visible text preview
outputs with safe refs only. It adds policy validation, request validation,
result contracts, redaction summaries, stable reason codes, tests, static
verification, documentation-integrity checks, and Foundation Gate coverage.

The adapter is not a browser runtime. It starts no browser session and performs
no browser automation, browser navigation, browser click, form fill,
screenshot, raw DOM read, authenticated browser profile access, cookie or
credential handling, download or upload, remote browser control, network
interception, network call, model call, tool execution, memory write, context
injection, backend route, Control Center control, dependency, M75 work, or
production authority.

M75 remains future.
