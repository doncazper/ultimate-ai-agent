# Release Notes v0.5.5

## Summary

Adds Local Runtime, Context Survival, Structured World State, and Agent SDK/A2A Adapter Strategy.

## Highlights

- World State becomes first-class structured run state.
- Context Budget Manager subtracts fixed costs before history budget.
- Token accounting and calibration are added.
- Tool-result trimming and retention policy is documented.
- Prompt/tool prefix cache policy is added.
- Local runtime manifests, model profiles, runtime health, resource budgets, and privacy routing are added.
- OpenAI Agents SDK, Claude Agent SDK, MCP, and A2A are defined as adapter layers, not core authorities.
