# Release Notes v0.12.1

v0.12.1 hardens M8 API validation redaction.

## Fixed

- FastAPI/Pydantic 422 validation errors no longer echo raw invalid input values.
- Secret-like invalid payload values are suppressed from API validation responses.
- Sensitive validation field names such as API key fields are redacted from sanitized validation locations.
- Model runtime manifest validation failures are handled with safe `ResultEnvelope` responses.
- Model runtime request-validation and simulate endpoints no longer allow nested manifest parsing to fall through to FastAPI's raw 422 response body.
- Unquoted secret assignment patterns such as `api_key=...` are detected by the shared secret scanner.

## Added

- Focused API regression tests proving M8 invalid manifest/request/simulate payloads do not leak secret-like values.
- A global API validation redaction regression test using a non-M8 typed endpoint.
- Foundation Gate coverage for M8 API validation secret-echo regressions.

## Still Blocked

v0.12.1 does not implement real model calls, provider SDK calls, OpenAI-compatible endpoint calls, local runtime calls, tokenizer integrations, billing APIs, network calls, scanners, companion proactivity, Skill Factory, self-improving code, autopilot workflows, browser automation, production persistence, real SDK/A2A runtime delegation, production secret vaults, production truth connectors, or high-autonomy execution.
