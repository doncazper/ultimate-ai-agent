# Release Notes v0.16.0

Status: Active M12 release baseline.

v0.16.0 implements M12 Control Center Contract and Read-Only Dashboard API Foundation on top of accepted v0.15.1.

Added:

- `src/ultimate_ai_agent/core/control_center/` with side-effect-free Pydantic contracts and pure builders.
- Control Center manifest, dashboard snapshot, summary, and action preview contracts.
- eight read-only/preview-only API routes under `/control-center`.
- OpenAPI route grouping and forbidden route checks for Control Center execution paths.
- Foundation Gate M12 criteria for read-only manifest, safe dashboard, no-execution action preview, read-only API, no frontend dependencies, and no runtime/network/mobile/plugin expansion.
- docs for Control Center contract, dashboard snapshot, and action preview policy.
- focused tests for contracts, API routes, no-execution scans, and gate integration.

Not added:

- no frontend app.
- no TypeScript UI.
- no React, Next.js, Vite, shadcn, Tailwind, package manager, or node build files.
- no Browser, Chrome, Computer Use, iOS, or macOS build workflow.
- no runtime execution.
- no model/provider calls.
- no provider SDKs.
- no network calls.
- no remote execution or remote dispatch.
- no mobile sensor access.
- no plugin/tool enablement.
- no native builds.
- no dependencies.
- no production persistence.
- no production Control Center.

Action previews are policy decisions only. They do not approve, consent, execute, mutate, resolve credentials, call tools, dispatch workers, start runtimes, call providers, enable plugins, access sensors, or create evidence authority.
