# Release Notes - v0.47.0

Status: Current active release.

v0.47.0 implements M43 Mobile API Boundary, Read-Only.

## Added

- M43 read-only mobile API boundary contracts for planned endpoint refs.
- GET-only, redacted summary only endpoint validation.
- M43 documentation for the read-only mobile API boundary and M43-to-M44
  boundary.
- M43 tests covering unsafe model_copy mutations, non-GET methods, raw route
  refs, raw payload/path exposure, and authority flags.
- Static verifier, documentation-integrity, and Foundation Gate coverage for
  M43.
- Release archive packet and active roadmap/currentness updates.

## Safety

M43 is contract-only. It adds no backend route, mobile API route runtime, mobile
mutation, approval capture, approval execution, sensor access, OS permission
integration, background collection, raw data, raw payload exposure, raw absolute
path exposure, credential handling, cookie handling, context injection, memory
write, export, file mutation, network/provider/model call, browser automation
execution, remote execution, plugin enablement, dependency, M44 implementation,
or production authority.

M44 remains planned/provisional as CCC iOS Skeleton, No Authority.
