# v0.60.0 Release Notes

v0.60.0 implements M56 Agent Eval Regression Harness.

Added:

- deterministic local agent eval regression harness contracts.
- eval policy, case, suite, observation, result, report, and receipt-plan
  models.
- validation for model call, provider call, tool execution, shell execution,
  browser automation, network access, memory write, context injection, raw
  prompt capture, raw provider payload capture, external dataset fetch, score
  authority, dependency, route, and production authority denial.
- tests, documentation-integrity checks, static verification, and Foundation
  Gate coverage.

Not added:

- model/provider calls.
- tool execution.
- shell execution.
- browser automation.
- network access.
- memory writes.
- context injection.
- raw prompt capture.
- raw provider payload capture.
- external dataset fetch.
- backend routes.
- Control Center controls.
- dependencies.
- production authority.
- M57 implementation.

M57 remains future.
