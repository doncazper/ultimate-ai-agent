# Release Notes v0.5.9

Status: Released

v0.5.9 marks the completion of Milestone M1 (Execution Contract and Context Pack schemas/validators).

## What's New

* **Milestone M1 Contract Models**: Implemented Pydantic v2 schemas for `ExecutionContract` and `ContextPack`.
* **Governance Enums**: Defined core enums for risk levels, agent modes, task classes, status states, and data sources.
* **Validation Policies**: Added validation checks in `validation.py` to block unauthorized skills/scanners/self-improving engines, enforce autonomy rules (e.g., blocking high-risk tasks from standing approvals), mandate grounding for high-stakes research, and scan context inputs for secret keys.
* **API Validation Endpoints**: Wired FastAPI routes `POST /contracts/validate` and `POST /context-packs/validate` returning a `ResultEnvelope`.
* **Unit Test Coverage**: Wrote new test assertions across `test_execution_contract.py`, `test_context_pack.py`, and `test_contract_validation.py` reaching 30 passing tests in total.
* **Linting & Code Quality**: Configured Ruff project exclusions for legacy verification scripts and verified all codebase code compiles with zero warnings or lint errors.

## Known Non-Goals

* No real model execution, tool broker calls, provider integrations, database mutations, or file-writing logic are implemented in M1. All actions remain mocked or validation-only.
