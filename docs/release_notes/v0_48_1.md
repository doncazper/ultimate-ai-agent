# v0.48.1 Release Notes

M44 hardening: CCC iOS Skeleton Verifier Allowance.

v0.48.1 repairs the M44 release verifier boundary after the pushed v0.48.0
review found that the historical M13 frontend artifact guard rejected the
reviewed source-only `apps/ccc-ios/` skeleton path. The patch adds a narrow
allowance for the committed M44 source-only files while keeping native build,
signing, store, sensor, permission, runtime, and authority artifacts blocked.

This patch adds no Xcode project, Swift package, Info.plist, entitlements,
native build workflow, signing/store workflow, TestFlight pipeline, backend
route, mobile API route runtime, network call, mobile sensor access, OS
permission integration, background collection, approval capture, approval
execution, context injection, memory write, file mutation, raw data, credential
handling, execution, dependencies, M45 implementation, or production authority.
