# Release Notes v0.37.0

Status: active release notes.
Current active baseline: **v0.37.0**

v0.37.0 implements M33 First Safe Local File Read Proposal, Redacted Preview
Only.

## Added

- `tool:filesystem.redacted_preview.v1` as the only new governed runtime tool.
- `RedactedFilePreviewPolicy`, request, result, redaction summary, and receipt
  plan coverage.
- Safe-root and relative-path reuse from M32.
- Bounded UTF-8 preview reads inside the redaction boundary only.
- Redaction-before-return for secret-like assignments, bearer tokens, private
  key markers, and high-entropy-looking tokens.
- Regression tests for safe preview, path denial, redaction, no raw content,
  authority boundaries, and Gate integration.
- Documentation, documentation-integrity checks, static verification, and
  Foundation Gate coverage.

## Safety Boundaries

M33 returns no raw file content, stores no raw file content, exposes no raw
absolute path, computes no content hash, lists no directories, follows no
symlinks, mutates no files, performs no context injection, and adds no backend
raw-file/execute routes or Control Center raw-preview/execute controls.

M34 remains planned/provisional.
