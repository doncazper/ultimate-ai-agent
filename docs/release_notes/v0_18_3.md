# Release Notes v0.18.3

Status: Historical release notes for OpenWebUI and CCC Client Strategy clarification.

v0.18.3 documents OpenWebUI as the preferred conversational web shell and CCC as the Control Center Clients family across web, iOS, Android, and macOS planning.

Changed:

- active version metadata now points to `0.18.3`.
- README, documentation index, canonical map, import docs, master plan, and Foundation Gate plan point to v0.18.3.
- `docs/ui/OPENWEBUI_AND_CCC_STRATEGY.md` defines OpenWebUI and CCC authority boundaries.
- `docs/ui/CLIENT_SURFACE_ROLES.md` defines Python Agent Core, OpenWebUI, CCC Web, CCC iOS, CCC Android, CCC macOS, Mobile Companion, and Open Design roles.
- `docs/ui/OPENWEBUI_INTEGRATION_ROADMAP.md` defines future OpenWebUI integration stages without implementation.
- `docs/ui/CCC_NATIVE_CLIENT_STRATEGY.md` defines shared CCC principles and native iOS, Android, and macOS planning constraints.
- documentation integrity and Foundation Gate checks now cover OpenWebUI/CCC strategy docs.

Unchanged:

- backend OpenAPI path count remains `74`.
- Control Center backend routes remain read-only/preview-only.
- CCC Web remains the existing TypeScript web Control Center.
- Python Agent Core remains the brain and authority layer.
- Open Design remains design governance for custom CCC surfaces.
- M15 Approval Queue + Receipt/Event Viewer UI remains future work.
