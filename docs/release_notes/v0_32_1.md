# v0.32.1 Release Notes

Status: active release note
Current through: v0.32.1
Purpose: Summarize M28 evaluator revalidation hardening.

## Summary

v0.32.1 hardens M28 Approval Authority v2 + Action Policy Expansion. It adds
evaluator-side revalidation before any policy-only allow decision so mutated
`ActionIntent`, `ApprovalGrant`, or `ActionPolicy` objects cannot bypass
constructor validation.

## Hardened

- raw prompt/model/file/transcript flags are rechecked at evaluator time.
- secret-like safe summaries, metadata, and metadata refs are denied.
- `approval_test_` grant refs are denied as runtime authority.
- expired, revoked, replayed, wildcard, and mismatched grant bindings remain
  denied after revalidation.
- safe no-effect/read-metadata policy decisions still return
  `execution_authorized=False` and `execution_performed=False`.
- regression tests cover `model_copy(update=...)` mutation bypasses.
- Foundation Gate and `scripts/verify_all.py` include mutated-object probes.

## Safety

v0.32.1 adds no action execution, tool execution, shell/subprocess execution,
file mutation, memory writes, network calls, model/provider calls, browser
automation, mobile/device access, remote execution, plugin enablement, backend
execution routes, frontend execute controls, dependencies, production
authority, or M29 work.

OpenAPI path count remains `74`.

M29-M40 remain planned/provisional.
