# v0.42.0 Release Notes

Status: current release notes.
Release: **v0.42.0 / M38 - Safe Context Proposal From Approved Review**.

v0.42.0 implements M38. It adds safe, non-authoritative context proposal
contracts built from exact-scope approved redacted file review records,
including proposal policy, source binding, redaction verification, safe proposal
sections, receipt plans, tests, static verification, documentation-integrity
checks, and Foundation Gate coverage.

## Added

- `SafeContextProposalPolicy`, request, source, binding, redaction
  verification, section, proposal, decision, and receipt-plan contracts.
- Exact approved-review binding across approval, review packet, preview result,
  redaction summary, file, safe path/path, and actor refs.
- Evaluator revalidation for model_copy-mutated raw, unredacted, injection,
  OpenWebUI, model, memory, export, execution, and binding fields.
- M38 documentation, tests, static verifier checks, and Foundation Gate
  criteria.

## Preserved Boundaries

M38 adds no context injection, OpenWebUI handoff, model/provider calls, memory
writes, raw file reads, raw file output/storage, full-file reads, unredacted
preview, export/download, tool/action/task execution, backend context/model/
OpenWebUI routes, Control Center context proposal surface, dependencies, M39
work, M40 work, or production authority.

M39 remains planned/provisional.
