# Release Notes v0.7.0

Milestone M3 (Consent Ledger + Tool Broker) is fully implemented, verified, and tested.

## Key Changes

### 1. Consent Ledger
- Pydantic models for consent (`ConsentGrant`, `ConsentConstraint`, `ConsentDecision`, `ConsentQuery`).
- In-memory `ConsentLedger` checking system with deny-overrides-allow rules, validation logic, expiration checking, and purpose/boundary filtering.
- Prevent standing approvals for high-risk actions.
- Clear reason codes and explanation outputs in `ConsentDecision`.

### 2. Tool Broker Policy Engine
- In-memory mock Tool Registry for registering tool manifests.
- Evaluates incoming tool requests and applies strict governance rules.
- Computes risk levels and required approvals without executing actual tools.
- Supports Dry-Run requests, returning a safe execution plan with zero side effects.

### 3. Capability Firewall
- Firewall policies controlling allowed network domains, filesystem roots, requested credentials, and allowed actions.
- Watchlist system for external, untrusted tools, MCP servers, and skill packages.
- Blocks execution in production mode for un-validated/un-mocked tools.

### 4. Foundation Gate Integration
- Strictly blocks any MCP, A2A, skill package, or SDK adapter tool category from claiming core authority.
- Rejects tool requests requiring credentials since Secret Broker is out of scope.

### 5. API Validation Endpoints
- `POST /consent/grants/validate`
- `POST /consent/evaluate`
- `POST /tools/manifests/validate`
- `POST /tools/requests/evaluate`
- `POST /tools/requests/dry-run`
