# Release Notes v0.24.1

Status: Historical release notes for v0.24.1 / M20 hardening.

v0.24.1 hardens M20 Device Capability Broker Contract safety.

Added:

- validator checks for OS permission runtime claims, notification push runtime
  claims, background service runtime claims, validation decision allow claims,
  non-redacted receipt plans, non-contract revocation plans, raw
  payload-like metadata, geolocation coordinates, private local paths, and
  secret-like device contract values.
- tests covering every major device capability rejecting `allowed_now=true`
  and `implemented_now=true`.
- expanded static frontend verifier denylist coverage for device capability
  routes, mobile permission/background-service routes, browser/native sensor
  API fragments, and native/mobile frontend dependencies.
- strengthened Foundation Gate M20 pass condition, route guards, capability
  coverage, and scanner exclusions for safety tests.
- documentation hardening for M20 contract-only status, user-gesture metadata,
  redacted receipts, blocked raw payloads, blocked notification/background
  runtime claims, future device pairing runtime, and M21 planned/provisional
  status.

Safety boundary:

- no M21 OpenWebUI Bridge.
- no Device Capability Broker runtime implementation.
- no mobile app.
- no Android app.
- no iOS app.
- no macOS app.
- no native build workflow.
- no OS permission runtime.
- no sensor access.
- no push notification runtime.
- no background service runtime.
- no device pairing runtime.
- no backend API route.
- no runtime execution.
- no model/provider call.
- no remote execution.
- no plugin enablement.
- no dependency.
- no architecture behavior change.
- no production authority.
