# Release Notes v0.9.0

v0.9.0 implements Milestone M5 (Minimum Lovable Kernel foundation).

## M5 Minimum Lovable Kernel

- Added `MinimumKernelRunner` and boundary contracts for local/dev kernel tasks.
- Added governed `create_dev_file`, `update_dev_file`, `rollback_dev_file`, and `validate_only` task types.
- Added a non-production API route: `POST /kernel/tasks/run`.

## End-to-End Governance Slice

- Creates an Execution Contract and Context Pack for the run.
- Loads supplied Consent Grants into the Consent Ledger.
- Registers and evaluates the inert `file.write.local_dev` ToolManifest through Tool Broker.
- Records meaningful Event Ledger events and generates redaction-safe receipts.
- Uses LocalFileManager proposal/diff/apply for the only allowed side effect.
- Produces Structured World State with artifact, event, evidence, and rollback refs.
- Optionally writes a source-linked Memory record that explicitly says memory is recall only, not authority.
- Supports in-memory rollback for local/dev workspaces.

## Explicitly Not Implemented

No model calls, provider calls, scanners, web fetching, external actions, browser automation, SDK/A2A runtime delegation, production persistence, production memory database, pgvector, embeddings, production truth connectors, production secret stores, companion proactivity, Skill Factory, self-improving code, or autopilot workflows were added.
