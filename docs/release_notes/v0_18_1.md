# Release Notes v0.18.1

Status: Historical release notes for M14 Web Control Center Local Backend Connection Safety hardening.

v0.18.1 hardens M14 inside the existing Web Control Center shell. It keeps local backend connection behavior frontend-only, local-only, read-only/preview-only, and non-authoritative when mock fallback data is shown.

Changed:

- active version metadata now points to `0.18.1`.
- README, documentation index, canonical map, import docs, master plan, and Foundation Gate plan point to v0.18.1.
- API base URL tests now cover public IPs, private LAN IPs, non-loopback hostnames, URL credentials, and broader secret-like query parameter names.
- API base URL redaction rejects `auth`, `credential`, and `key` query-style secret markers in addition to existing secret-like names.
- loading copy now explicitly says the shell is checking local backend connection state.
- frontend connection state typing now includes `unknown` and `checking` alongside `online`, `degraded`, `offline`, and `mock_fallback`.
- static frontend verification now rejects Vite proxy URL credentials, external proxy targets, and secret-like API base env examples.
- Foundation Gate M14 checks enforce the new connection-state and unsafe URL fixture coverage.

Unchanged:

- backend OpenAPI path count remains `74`.
- Control Center backend routes remain read-only/preview-only.
- the frontend still declares exactly one POST target: `/control-center/actions/preview`.
- Python Agent Core remains the brain.
- local browser smoke remains manual, local-only, unauthenticated-profile-free, and non-authoritative.
- M15 Approval Queue + Receipt/Event Viewer UI remains future work.

Not added:

- backend API route.
- approval queue UI.
- receipt/event viewer UI.
- production Control Center authority.
- public execution API.
- runtime/model/provider calls.
- remote dispatch.
- mobile/native app or sensor access.
- plugin enablement.
- Chrome authenticated profile control.
- Computer Use automation.
- iOS/macOS build workflow.
- auth, credentials, cookies, Authorization headers, or API keys.
- analytics/auth/payment/SaaS SDKs.
- external API host support.
- production persistence.
- dependency.
- external action.
