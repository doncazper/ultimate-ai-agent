# v1.7.2 Release Notes

v1.7.2 repairs post-M103 roadmap versioning/currentness only.

It preserves already-pushed tags as immutable historical internal milestone
tags, replaces future M104-M149 product-version rows with checkpoint labels,
and reserves M150 as the next product release target: v1.0.0-alpha.
Beta begins only after the alpha UI and supporting safety/product work are
reviewed, accepted, and explicitly promoted by a later roadmap patch.

It strengthens documentation-integrity checks, static verification, Foundation
Gate coverage, tests, active roadmap docs, and release metadata so future
M104-M149 milestones do not consume product SemVer versions.

It adds no capability implementation, M104 work, backend route, Control Center
control, dependency, execution, tool execution, shell execution, browser
automation, plugin execution, mobile sensor runtime, memory write, context
injection, model/provider call, broad autonomy, production authority, or M151
work.
