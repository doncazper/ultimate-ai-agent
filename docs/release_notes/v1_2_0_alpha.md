# v1.2.0-alpha Release Notes

v1.2.0-alpha aligns the active package baseline and the M150 alpha target while
adding the contract-only Orchestration Efficiency Layer.

It adds strict no-effect contracts for orchestration efficiency policies,
weighted route score breakdowns, cacheability plans, fallback plans,
orchestration preview decisions, and redacted optimization metric summaries. It
extends existing model route and cost preview metadata with cost mode, fallback,
verification, trace/correlation, cache, runtime, and observability estimates.

It adds no dependency, backend route, Control Center control, provider/model
call, network access, browser automation, shell/subprocess execution, runtime
tool authority, memory write, context injection, beta release, or production
authority.
