# v0.59.0 Release Notes

v0.59.0 implements M55 Redacted Observability Export.

Added:

- deterministic local redacted observability export contracts.
- redacted export policy, request, bundle, item, and receipt-plan models.
- validation for raw prompt, provider payload, private content, secret, SaaS,
  network, model call, memory write, context injection, dependency, route, and
  production authority denial.
- tests, documentation-integrity checks, static verification, and Foundation
  Gate coverage.

Not added:

- external SaaS or analytics SDKs.
- network delivery.
- raw prompt export.
- raw provider payload export.
- raw private content export.
- secret export.
- forensic trace export.
- model/provider calls.
- memory writes.
- context injection.
- backend routes.
- Control Center controls.
- dependencies.
- production authority.
- M56 implementation.

M56 remains future.
