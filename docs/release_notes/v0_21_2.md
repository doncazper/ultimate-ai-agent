# Release Notes v0.21.2

Status: Historical release notes for Developer Environment Command Normalization.

v0.21.2 normalizes developer verification commands so Codex and local shells use `.venv/bin/python` or repo-local Makefile targets instead of relying on a bare `python` binary on PATH.

Added:

- `scripts/verify_dev_environment.py`.
- repo-local `Makefile` targets: `doctor`, `test`, `verify`, `frontend-check`, `openapi`, and `ruff`.
- tests for the dev-environment verifier and Makefile command policy.
- docs updates explaining `.venv/bin/python`, Makefile targets, shell alias unreliability, and no global Python alias requirement.

Safety:

- the verifier prints clear remediation but does not call pip automatically.
- remediation text uses `python3 -m venv .venv` and `.venv/bin/python -m pip install -e ".[dev]"`.
- npm absence is warning-only for the environment verifier.
- no global tools are installed.

Backend and OpenAPI:

- no backend API route is added.
- OpenAPI path count remains `74`.
- operation IDs remain unique.

Not added:

- M18 Local Runtime Status + Manual Smoke Control Surface.
- runtime features.
- frontend features.
- backend API routes.
- dependencies.
- global tool installs.
- application behavior changes.
- runtime/model/provider calls.
- network calls.
- mobile/native/browser/computer-use functionality.
- plugin enablement.
- production capability.
