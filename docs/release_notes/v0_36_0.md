# v0.36.0 Release Notes

Status: active release notes.

Current active baseline: **v0.36.0**

v0.36.0 implements M32 - Safe Tool Runtime Expansion as one safe local
filesystem metadata tool.

Implemented:

- `tool:filesystem_metadata.v1` through the governed Tool Runtime Adapter.
- two-tool allowlist: deterministic no-op plus filesystem metadata only.
- server-owned safe-root refs.
- relative path validation.
- metadata-only result envelope.
- safe receipt plan.
- evaluator revalidation for model_copy-mutated raw/content/path fields.
- denial of absolute, traversal, hidden, secret-like, and glob paths.
- denial of caller-selected roots, symlink following, directory listing,
  recursive traversal, content preview, content hash, and filesystem mutation.
- authority-boundary denial for approval refs, approval_test_ refs, task plans,
  execution state, tool intents, context packs, memory, model/runtime/OpenWebUI
  output, and Control Center refs.
- static verifier and Foundation Gate coverage.
- active docs and release archive packet.

Safety boundaries:

- no arbitrary tool execution.
- no raw file content read.
- no text preview.
- no content hash.
- no directory listing.
- no recursive traversal.
- no symlink following.
- no file mutation.
- no shell/subprocess execution.
- no memory writes.
- no network calls.
- no model/provider calls.
- no browser/mobile/remote/plugin tools.
- no backend execution routes.
- no Control Center execute controls.
- no dependencies.
- no M33 work.
- no production authority.

OpenAPI path count remains `74`.

M33-M40 remain planned/provisional.
