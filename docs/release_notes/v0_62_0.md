# v0.62.0 Release Notes

v0.62.0 implements M58 Dry-Run Execution Audit Harness.

Added:
- deterministic local dry-run execution audit contracts.
- dry-run intent, request, report, entry, policy, and receipt-plan models.
- exact intent/ref binding and replay-key metadata.
- evaluator-side revalidation of safety-critical fields.
- documentation, documentation-integrity checks, static verification, tests,
  and Foundation Gate coverage.

Not added:
- real execution.
- tool execution.
- subprocess or shell execution.
- process spawn.
- file mutation.
- network access.
- model/provider calls.
- memory writes.
- context injection.
- browser/plugin/remote execution.
- backend routes.
- Control Center controls.
- dependencies.
- production authority.
- M59 work.
