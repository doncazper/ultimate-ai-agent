# Release Notes v0.7.1

v0.7.1 completes a post-M3 hardening pass and implements Milestone M3.5 (Secret Broker + Provider Registry foundation).

## Post-M3 Policy Hardening

- Tool Broker now enforces Execution Contract `allowed_tools` and `forbidden_tools`.
- Tool Broker now enforces Context Pack `tool_permissions`.
- High-risk and external mutation requests no longer become allowed from arbitrary `approval_ref` strings.
- Mutable idempotent tool requests require an `idempotency_key`.
- Capability Firewall fails closed for filesystem roots, network domains, and credential requests.
- M3 boundary models reject unexpected fields.
- `PermissionAction.any` deny semantics override allow grants.
- Execution Contract factory helpers populate concise redacted `request_summary` values.

## M3.5 Secret Broker Foundation

- Added `CredentialReference`, `CredentialMetadata`, `SecretHandle`, `RedactedSecretView`, `SecretAccessRequest`, `SecretAccessDecision`, and redaction report contracts.
- Added a local/dev in-memory `SecretBroker` for unit tests only.
- Secret decisions return opaque handles or redacted views, never raw secret values.
- Missing consent, revoked/disabled/expired credentials, wrong purpose, and scope mismatches are denied.

## M3.5 Provider Registry Foundation

- Added provider manifests, capability specs, terms/rate-limit/attribution/health metadata, and provider selection policy.
- Added deterministic `ProviderRegistry` and free-first `ProviderResolver`.
- Added provider result envelopes, provider errors, cost/freshness metadata, weather/news normalization contracts, and normalization reports.

## API Boundary

Added non-executing validation/evaluation endpoints:

```text
POST /secrets/credentials/validate
POST /secrets/access/evaluate
POST /providers/manifests/validate
POST /providers/resolve
POST /providers/results/validate
```

## Explicitly Not Implemented

No real provider calls, paid provider integrations, network calls, production secret vaults, OAuth flows, API clients, weather/news fetchers, model calls, scanners, real tool execution, real memory storage, or external SDK/A2A runtime delegation were added.
