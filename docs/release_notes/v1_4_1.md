# v1.4.1 Release Notes

v1.4.1 is the post-M100 full-repository review, hardening, and roadmap
reconciliation release.

It records the M100 Green baseline review, incorporates a local deep review and
read-only CodeRabbit advisory status, reconciles completed milestones through
M100, adds the planned/provisional M101-M150 roadmap, and strengthens
documentation-integrity, static verifier, test, and Foundation Gate coverage for
post-M100 currentness.

prompts, native permission requests, background collection, production
authority, broad unsandboxed autonomy, automatic context injection, raw file
export, unreviewed memory writes, backend routes, Control Center controls,
dependencies, or production authority.
