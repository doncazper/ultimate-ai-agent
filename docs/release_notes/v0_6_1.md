# Release Notes v0.6.1

Milestone M2.5 (Structured World State, Context Budget, Local Runtime Profiles, and SDK/A2A Adapter Boundaries) is fully implemented, verified, and tested.

## Key Changes

### 1. Structured World State
- Compact, serializable task/run state containing current phases, completed steps, open decisions, and event IDs.
- Prevents raw secret storage.
- References event IDs mapping to the Event Ledger for strict provenance.

### 2. Context Budget Manager
- Accounts for fixed costs and subtracts them dynamically to compute `available_history_tokens`.
- Fails closed when context limit is unknown.
- Dynamic token calibration factor (calibrates up on underestimate, never decreases).
- Enforces preservation of user instructions, contracts, context packs, world states, and safety constraints.
- Trims large raw tool outputs first.

### 3. Local Runtime manifests & profiles
- Support runtime types: `ollama`, `lm_studio`, `llama_cpp`, `vllm`, `sglang`, `openai_compatible_local`, `cloud_provider_placeholder`.
- Model profiles containing context windows, ram/vram required, and optimization capabilities (prefix caching, CUDA graphs, speculative decoding).
- Strict privacy routing policies (`local_only`, `hybrid_redacted`, `cloud_allowed`).

### 4. SDK / A2A Adapter boundaries
- Manifest and policies defining boundaries for OpenAI Agents SDK, Claude Agent SDK, Gemini CLI, MCP, and A2A Agent Cards.
- Boundary check validates that adapters cannot bypass core authority controls, nor can they be granted direct tool, memory, or secret access.

### 5. API validation routes
- `POST /world-state/validate`
- `POST /context-budget/validate`
- `POST /local-runtime/validate`
- `POST /adapter-manifest/validate`
