# Release Notes v0.17.0

Status: Historical release notes for M13.

v0.17.0 adds the M13 Web Control Center read-only frontend shell.

Added:

- `apps/control-center/` React/Vite/TypeScript shell.
- typed frontend API client for existing read-only/preview-only backend routes.
- mock fallback fixtures marked mock and non-authoritative.
- pages for dashboard, runtime readiness, Foundation Gate, API routes, approvals, remote workers, mobile planning, plugin governance, and action preview.
- frontend tests for safe rendering, mock fallback, action preview endpoint usage, and secret-like display redaction.
- docs for frontend shell, safety policy, and frontend route map.
- M13 verifier and Foundation Gate checks.

Unchanged:

- backend OpenAPI path count remains `74`.
- Control Center backend routes remain read-only/preview-only.
- Python Agent Core remains the brain.

Not added:

- production Control Center authority.
- public execution API.
- runtime/model/provider calls.
- remote dispatch.
- mobile/native app or sensor access.
- plugin enablement.
- Chrome authenticated profile control.
- Computer Use automation.
- iOS/macOS build workflow.
- analytics/auth/payment/SaaS SDKs.
- production persistence.
