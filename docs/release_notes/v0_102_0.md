# v0.102.0 Release Notes

v0.102.0 is the corrected pre-1.0 currentness baseline for the Operator
Runtime Excellence lane. It supersedes the prior v2.0.0 current-baseline label
as an internal mislabel while preserving all existing tags as immutable
historical records.

## Scope

- Set the active project baseline to v0.102.0 / 0.102.0.
- Preserve checkpoint-m168 as the latest accepted repository checkpoint.
- Preserve checkpoint-m166 and checkpoint-m167 as accepted local model lane
  checkpoints.
- Keep v0.100.0 and v0.101.0 as the existing pre-1.0 repair-lane tags.
- Treat v1.x and v2.0.0 tags as historical records, not current authority.
- Add a `VERSION` source-of-truth file containing `0.102.0`.
- Add draft release process and SemVer policy docs for future reviewed bumps.
- Add local dry-run-first release helper and version truth checker scripts.

## Non-Goals

v0.102.0 does not add public release, public beta, production authority,
external distribution, tag creation, remote repair, history rewrite,
force-push, dependency changes, backend route authority, Control Center
authority, model/provider calls, shell/subprocess execution, unrestricted
network/browser automation, plugin execution, mobile sensor runtime, memory
write, context injection, raw prompt export, raw provider payload export, or
raw private-content export.

## Verification Notes

The version repair must be verified through the local version truth checker,
current-baseline verifier, documentation-integrity verifier, Foundation Gate,
OpenAPI contract verifier, and the normal repo test lanes before any future tag
or release promotion is considered.
