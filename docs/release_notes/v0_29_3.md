# Release Notes v0.29.3

Status: Historical release notes.

## Summary

v0.29.3 reorganizes documentation structure and GitHub-facing repository
hygiene after v0.29.2.

## Changed

- Adds `docs/README.md` as the human-facing docs entrypoint.
- Adds archive indexes under `docs/archive/`, `docs/archive/releases/`,
  `docs/archive/roadmap_snapshots/`, and `docs/archive/retired_plans/`.
- Adds `docs/roadmap/README.md` and `docs/roadmap/archive/README.md`.
- Moves historical root release import and master-plan packets into
  `docs/archive/releases/vX_Y_Z/`.
- Moves miscellaneous historical root planning/review packets into
  `docs/archive/retired_plans/`.
- Keeps active release notes under `docs/release_notes/`.
- Keeps active implementation/Foundation Gate plans under `docs/implementation/`.
- Marks the legacy v0.17.5 roadmap sequence as historical while preserving its
  original path for verifier and Foundation Gate compatibility.
- Updates active indexes, canonical map, route inventory, test strategy,
  documentation checklist, and documentation-integrity checks so only active
  docs can claim current baseline status.

## Safety

v0.29.3 is documentation organization only. It adds no M26 Grounded Recall
Router, Context Pack Builder, backend routes, frontend features, runtime/model
provider calls, retrieval/RAG/vector/embedding functionality, memory writes,
tool execution, dependencies, security architecture changes, or production
authority.

OpenAPI path count remains `74`. M26 remains planned/provisional.
