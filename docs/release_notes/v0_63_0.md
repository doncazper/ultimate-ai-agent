# Release Notes v0.63.0

v0.63.0 implements M59 Public GitHub Readiness.

This release adds deterministic local review-only contracts for public GitHub
readiness. It records safe repository refs, baseline refs, checklist refs,
artifact refs, readiness reports, and no-effect receipt plans.

Safety boundaries:

- no GitHub push
- no GitHub release automation
- no wiki automation
- no artifact upload
- no external service calls
- no credential handling
- no network access
- no backend routes
- no Control Center controls
- no dependencies
- no production authority
- no M60 implementation

Validation coverage includes focused M59 tests, static verification,
documentation-integrity checks, OpenAPI route-boundary checks, and Foundation
Gate criteria.
