# Release Notes v0.25.1

Status: Historical release notes for v0.25.1 / M21 hardening.

v0.25.1 hardens M21 OpenWebUI Bridge + Chat Shell Integration Contract safety
while keeping M21 contract/planning/validation only.

Changed:

- clarified `raw_content_blocked` and `future_requires_contract` as blocked
  content modes, not valid content modes for refs or chat envelopes.
- kept `summary_only`, `ref_only`, and `redacted_preview` as the only valid
  M21 OpenWebUI ref/envelope content modes.
- hardened authority-claim validation so safe negated text such as
  "OpenWebUI is not the agent brain" and "OpenWebUI must not execute actions"
  remains valid while positive OpenWebUI authority claims are rejected.
- removed the OpenWebUI bridge package exemption from M21 runtime/config static
  scans.
- added recursive forbidden OpenWebUI config/path detection outside docs.
- refreshed tests, Foundation Gate coverage, static verifier coverage, route
  inventory notes, and active version metadata for v0.25.1.

Safety boundary:

- OpenWebUI is a supported local/dev conversational shell and compatibility
  surface.
- OpenWebUI is not the product cockpit or source of product state.
- OpenWebUI is not the agent brain.
- Python Agent Core remains authority.
- OpenWebUI refs are identifiers only and never authority.
- no OpenWebUI integration or live connection.
- no OpenWebUI deployment config or Docker config.
- no OpenWebUI plugin, function, pipeline, tool, admin, auth, cookie, API key,
  admin token, or browser profile workflow.
- no backend API route.
- no frontend feature.
- no runtime execution.
- no local LLM call.
- no model/provider call.
- no tool execution.
- no memory write.
- no file access.
- no remote execution.
- no browser automation.
- no Computer Use.
- no mobile sensor access.
- no plugin enablement.
- no dependency.
- no production authority.

OpenAPI path count remains `74`. M22 Local Model Runtime Activation Contract
and M23 First Real Local LLM Call remain planned/provisional.
