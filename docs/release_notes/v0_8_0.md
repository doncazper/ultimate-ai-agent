# Release Notes v0.8.0

v0.8.0 implements Milestone M4 (Memory Service + File Manager foundation).

## M4 Memory Service

- Added source-linked memory records, source references, scoped write/read requests, write/read decisions, and retrieval policy contracts.
- Added a local/dev in-memory `MemoryStore` for tests and foundation validation only.
- Added deterministic keyword/tag/metadata retrieval with scope, status, sensitivity, consent, deletion, and supersession filtering.
- Added correction, supersession, deletion, quarantine, idempotency, redaction, and secret-blocking behavior.
- Added future vector/embedding/reranker reference fields as contracts only.

## M4 File Manager

- Added safe file refs, file operation contracts, local/dev `LocalFileManager`, file policies, diffs, snapshots, and rollback plans.
- File operations stay inside an explicit workspace root and reject absolute paths, traversal, `.env`, private keys, and credential-like paths.
- Write proposals require idempotency keys, block secret-like content, check expected hashes, protect canonical/spec/ADR/schema/prompt/eval overwrites, and support strict contract update paths.
- Apply writes use temp-file replacement, produce change metadata, and attach rollback plans to in-memory snapshots for test/dev workspaces.

## API Boundary

Added validation/preview endpoints:

```text
POST /memory/records/validate
POST /memory/write/evaluate
POST /memory/query/preview
POST /files/refs/validate
POST /files/read/preview
POST /files/write/propose
POST /files/diff/preview
```

## Explicitly Not Implemented

No M4.5 Truth Source Router, M5 Minimum Lovable Kernel, production DB, pgvector migrations, embedding calls, model calls, scanners, companion proactivity, Skill Factory, self-improving code, autopilot workflows, real provider integrations, broad filesystem scanning, external file automation, shell execution, production persistence, OAuth flows, or production secret vaults were added.
