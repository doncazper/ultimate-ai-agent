# Release Notes v0.21.1

Status: Current release notes for M17 Evidence/File/Memory Viewer safety hardening.

v0.21.1 hardens the existing read-only Evidence/File/Memory Viewer surfaces in CCC Web.

Added:

- alternate safe mock evidence, file ref, and memory ref entries for `/evidence`, `/files`, and `/memory`.
- accessible selected-card state for M17 evidence, file ref, and memory summary lists.
- frontend test coverage for alternate metadata selection while remaining read-only and redacted summary-only.
- static frontend verifier checks for M17 hardening mock markers and selected-state markers.
- Foundation Gate criterion and evaluator coverage for M17 hardening.
- docs updates for browser smoke reviewability and v0.21.1 release alignment.

Safety:

- all M17 mock data remains visibly mock, non-authoritative, and redacted summary-only.
- raw prompts, raw secrets, raw file contents, raw memory contents, raw evidence payloads, raw credentials, and raw provider payloads remain absent.
- no file mutation, memory mutation, filesystem browsing, runtime execution, model/provider calls, remote execution, mobile sensor access, plugin enablement, auth, cookies, analytics, SaaS SDKs, dependencies, native build workflows, or production Control Center authority are added.

Backend and OpenAPI:

- no backend API route is added.
- OpenAPI path count remains `74`.
- `/evidence`, `/files`, and `/memory` remain frontend-only CCC Web routes.

Not added:

- M18 Local Runtime Status + Manual Smoke Control Surface.
- backend viewer routes.
- production telemetry export.
- external observability integration.
- embeddings, vector DB, pgvector, or memory provider implementation.
- raw file, raw memory, raw evidence, raw prompt, raw secret, raw credential, or raw provider payload display.
