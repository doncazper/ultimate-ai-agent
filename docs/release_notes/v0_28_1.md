# Release Notes v0.28.1

Status: Historical release notes.

## Summary

v0.28.1 repairs the M24 public memory request contract and hardens memory safety
tests/docs without expanding M24 authority.

## Fixed

- Package-root `MemoryWriteRequest` now aligns with the provider/store M24 write
  request used by `LocalMemoryStore`.
- The legacy content-bearing memory write request is exported explicitly as
  `LegacyMemoryWriteRequest`.
- `LocalMemoryStore.put_record()` rejects legacy/content-bearing request objects
  unless a future reviewed adapter path is added.
- In-memory `LocalMemoryStore.get_record()` and `list_records()` return
  defensive copies.
- M24 write validation messaging now states that `source_refs` are required and
  evidence/event/receipt refs are supplemental provenance.
- Foundation Gate M24 guard-field checks now fail clearly if a required guard
  field is renamed or removed.
- `docs/api/route_inventory.md` is current through v0.28.1.
- Minor memory docs/code polish: `Memory Non-Goals` heading and recall summary
  fallback cleanup.

## Safety

v0.28.1 adds no automatic memory writes, model-output writes, local LLM output
writes, OpenWebUI chat memory writes, Control Center mutation, mobile capture
writes, tool output writes, raw prompt/model/file/transcript content, secrets,
cloud memory providers, vector DB, embeddings, context injection, backend
mutation routes, dependencies, production persistence, or M25 work.

OpenAPI path count remains `74`.
