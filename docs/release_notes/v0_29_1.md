# Release Notes v0.29.1

Status: Current release notes.

## Summary

v0.29.1 hardens M25 Truth Source Router + Evidence Claim Checker safety by
rejecting unknown and arbitrary truth refs.

## Fixed

- Denies inferred unknown refs such as unrecognized `random:*` prefixes for
  `source_linked`, `evidence_supported`, and `verified_by_primary_source`
  outcomes.
- Denies explicit `TruthSourceKind.unknown` evidence refs for
  verification-success statuses.
- Keeps claim self-verification denied.
- Adds regression coverage for unknown refs, explicit unknown source kinds,
  random source refs, and valid canonical primary-source success.
- Strengthens Foundation Gate and static verifier coverage for
  arbitrary/unknown truth refs.

## Safety

v0.29.1 adds no web search, external verification, model/provider calls, local
LLM calls, retrieval/RAG/vector/embedding functionality, source crawling,
memory writes, evidence mutation, Event Ledger mutation, backend truth
verification routes, dependencies, Control Center mutation controls, M26
context-pack builder, or production authority.

OpenAPI path count remains `74`. M26 remains future.
