# v1.7.1 Release Notes

v1.7.1 repairs post-M103 roadmap versioning/currentness only.

It preserves already-pushed v1.0.0 through v1.7.0 tags as immutable historical
internal milestone tags, changes future M104-M149 conveyor snapshots to
incremental v1.7.x internal tags, and sets M150 as the public product target
v1.2.0-alpha. Beta begins only after the alpha UI and supporting
safety/product work are reviewed, accepted, and explicitly promoted by a later
roadmap patch.

It strengthens documentation-integrity checks, static verification, tests,
active roadmap docs, and release metadata so the stale fast-version projection
and M150 beta label cannot silently return.

It adds no capability implementation, M104 work, backend route, Control Center
control, dependency, execution, tool execution, shell execution, browser
automation, plugin execution, mobile sensor runtime, memory write, context
injection, model/provider call, broad autonomy, production authority, or M151
work.
