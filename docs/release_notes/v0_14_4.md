# Release Notes v0.14.4

## Mobile Companion and Device Capability Broker Roadmap Foundation

v0.14.4 updates the accepted v0.14.3 baseline with docs/planning only. It captures future Mobile Companion and Device Capability Broker work before any mobile or sensor runtime is implemented.

Changed:

- added canonical Mobile Companion and Device Capability Broker planning docs.
- added Mobile Device Registry and Sensor Permission Manifest planning docs.
- added mobile companion and device capability broker backlog docs.
- added prose schema placeholder docs for future mobile/device manifests.
- updated roadmap, Control Center, API, security, privacy, autonomy, TCB, classification, and redaction docs with future mobile guardrails.
- bumped active baseline metadata to v0.14.4.

Mobile appears after runtime readiness, API/control-center contract stabilization, and web Control Center foundation.
Device Capability Broker appears before any future mobile sensor integration.

No mobile app was added.
No iOS, Android, React Native, Expo, Flutter, Swift, Kotlin, Capacitor, Ionic, or native mobile package was added.
No camera, microphone, GPS/location, contacts, calendar, photos, NFC, Bluetooth, motion, biometrics, notification, share-sheet, mobile pairing, background service, network call, autonomous mobile action, or runtime Device Capability Broker was added.
