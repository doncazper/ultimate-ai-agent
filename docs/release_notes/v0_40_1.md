# v0.40.1 Release Notes

Status: current release notes.
Release: **v0.40.1 / M36 hardening - CCC File Review Surface Read-Only Safety**.

v0.40.1 hardens M36 CCC File Review Surface, Review-Only. It strengthens
safe-ref-only display boundaries, private/raw path drift checks, local
read-only packet selection and expansion guarantees, no-mutating-request
checks, frontend tests, static verification, documentation-integrity checks,
and Foundation Gate coverage.

## Fixed

- the `/files/review` surface now explicitly states that it displays safe refs
  only.
- packet selection and expansion are documented as local read-only UI state.
- the file review surface now explicitly states that no mutating request is
  made.
- M36 mock data carries `SAFE_REFS_ONLY` and `NO_MUTATING_REQUESTS` markers.
- frontend tests cover safe binding refs and private/raw path absence.
- static verification and Foundation Gate checks reject unsafe M36 ref prefixes,
  private path-shaped refs, raw path-shaped labels, traversal fragments, and
  mutating file-review requests.
- documentation integrity checks require the safe-ref-only and no-mutating
  request boundary.

## Preserved Boundaries

redacted-summary-only. This patch adds no approval capture, approval
persistence, backend review routes, raw file reads, raw file content display,
raw file content storage, full-file reads, file picker/browser/upload/root
selector, export/download/copy-raw controls, context proposal, context
injection, memory writes, execution/tool controls, file mutation, dependencies,
M37 work, M38 work, or production authority.
