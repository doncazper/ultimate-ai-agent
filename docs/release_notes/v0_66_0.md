# Release Notes v0.66.0

v0.66.0 implements M62 Scoped Autonomy Session Contracts.

This release adds contract-only and review-only scoped autonomy session models
with actor-bound, resource-bound, duration-bound, allowlist-bound, revocable,
auditable, and replayable scope records. It strengthens static verification,
documentation integrity checks, Foundation Gate coverage, and tests.

Safety boundaries:

- no session start
- no session activation
- no autonomous actions
- no background worker
- no execution
- no tool execution
- no shell execution
- no network tools
- no browser automation
- no plugin execution
- no mobile sensor access
- no remote execution
- no memory writes
- no context injection
- no model/provider authority
- no backend route
- no Control Center control
- no dependency
- no M63 work
- no production authority

M63 remains future.
