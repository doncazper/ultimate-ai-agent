# v0.35.0 Release Notes

Status: active release notes.

Current active baseline: **v0.35.0**

v0.35.0 implements M31 — Real Tool Runtime Adapter, Single Safe No-Op Tool.

Implemented:

- Tool Runtime Adapter contracts.
- one deterministic registered no-op tool: `tool:no_op.v1`.
- no-op invocation request, decision, result, and receipt-plan envelopes.
- runtime manifest and no-op-only policy flags.
- replay-key protection.
- evaluator revalidation for model_copy-mutated unsafe fields.
- authority-boundary denial for approval refs, tool intents, task plans,
  context packs, memory refs, model/runtime/OpenWebUI output, and arbitrary
  refs.
- static verifier and Foundation Gate coverage.
- active tool-runtime documentation and release packet archive docs.

Safety boundaries:

- no arbitrary tool execution.
- no side-effecting tools.
- no dynamic dispatch.
- no plugins.
- no shell/subprocess execution.
- no file mutation or file tools.
- no memory writes.
- no network calls or web search.
- no model/provider calls or local LLM calls.
- no browser/mobile/remote tools.
- no backend execute routes.
- no Control Center execute controls.
- no dependencies.
- no context injection.
- no production authority.

OpenAPI path count remains `74`.

M32-M40 remain planned/provisional.
