# v0.75.0 Release Notes

v0.75.0 implements M71 Network Tool Contract Review.

This release adds contract-only, review-only network tool contract models for
future network capability review. It records disabled-by-default policy,
request, decision, and receipt-plan contracts; allows an allowlisted read-only
HTTP fetch proposal to be marked as an M72 candidate only; keeps effectful
network capabilities future-only; and strengthens tests, documentation,
documentation-integrity checks, static verification, and Foundation Gate
coverage.

v0.75.0 adds no network call, no HTTP fetch, no unrestricted network tool, no
authenticated network action, no credentials or cookies, no request body, no
non-GET method, no download or export, no raw response body, no backend route,
no Control Center control, no dependency, no production authority, and no M72
implementation.

M72 remains future.
