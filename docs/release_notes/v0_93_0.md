# v0.93.0 Release Notes

v0.93.0 implements M89 Emergency Stop + Process Kill Safety.

This release adds contract-only, review-only, deterministic, local-only safety
contracts over exact M88 Mutating Command Proposal decisions. It validates safe
target process refs, safe emergency scope refs, safe reason refs, safe refs
only receipt plans, evaluator revalidation, documentation-integrity checks,
static verification, tests, and Foundation Gate coverage.

It adds no emergency stop execution, process kill, process signal, command
execution, subprocess execution, shell execution, process spawn, filesystem
mutation, network access, tool execution, browser automation, plugin execution,
remote execution, model call, memory write, context injection, background
worker, backend route, Control Center control, dependency, M90 work, or
production authority.
