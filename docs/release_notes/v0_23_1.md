# Release Notes v0.23.1

Status: Historical release notes for M19 Roadmap Status + Mobile Contract Safety Hardening.

v0.23.1 is a cleanup and hardening patch after v0.23.0 / M19.

- updated active roadmap docs so v0.23.0 / M19 is implemented/released as
  contract/API planning only.
- kept M20 and M21-M40 planned/provisional.

  metadata refs, external-send blocking, OS-permission integration blocking,
  and background-service blocking.

- versioned the project to `0.23.1`.
