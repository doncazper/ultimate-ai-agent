# Release Notes v0.17.1

Status: Current release notes for the Web Control Center safety polish patch.

v0.17.1 hardens the M13 Web Control Center read-only frontend shell.

Added:

- explicit preview-only action request language in the action preview form.
- typed frontend endpoint allowlist helpers.
- safe display of blocked preview decisions as non-executed results.
- disabled blocked-action UI option for execute-like action kinds.
- `scripts/verify_control_center_frontend.py`.
- `scripts/verify_all.py` integration for the frontend safety verifier.
- Foundation Gate criteria for sensitive browser API absence and frontend verifier success.
- frontend and Python regression tests for endpoint safety, dangerous action labels, blocked decisions, browser/storage/API restrictions, and safe mock fixtures.

Unchanged:

- backend OpenAPI path count remains `74`.
- Control Center backend routes remain read-only/preview-only.
- Python Agent Core remains the brain.
- Web Control Center remains a local shell and has no production authority.

Not added:

- production Control Center authority.
- public execution API.
- runtime/model/provider calls.
- remote dispatch.
- mobile/native app or sensor access.
- plugin enablement.
- Chrome authenticated profile control.
- Computer Use automation.
- iOS/macOS build workflow.
- analytics/auth/payment/SaaS SDKs.
- production persistence.
