# Release Notes v0.20.0

Status: Current release notes for M16 Event Timeline + Run/Receipt Trace Viewer.

v0.20.0 adds a read-only Event Timeline + Run/Receipt Trace Viewer to CCC Web.

Added:

- `/events/timeline` frontend route.
- `EventTimelineTracePanel` for redacted timeline summaries, selected trace detail, event relation refs, and Foundation Gate evidence summaries.
- safe mock M16 trace data with event refs, run refs, correlation refs, receipt refs, relation refs, and evidence refs.
- frontend tests for the M16 route and raw-content absence.
- static frontend safety verifier coverage for raw M16 trace fields, credential-like trace fields, export endpoints, dangerous action controls, and M16 boundary copy.
- Foundation Gate criterion `m16_event_timeline_trace_viewer_safe`.
- docs for Event Timeline UI, Run Receipt Trace Viewer, and Trace Redaction Policy.

Not added:

- M16 hardening follow-up work.
- backend API routes.
- OpenAPI path count changes.
- approval execution.
- approval grant/reject mutation.
- tool execution.
- model/provider calls.
- remote execution or remote worker dispatch.
- mobile app code or mobile sensor APIs.
- plugin enablement.
- Chrome authenticated profile control.
- Computer Use automation.
- iOS/macOS/native build workflows.
- production telemetry export.
- external observability integration.
- OpenTelemetry export.
- cloud traces.
- raw event payload dumps.
- raw secret, prompt, file, memory, credential, provider payload, or unreviewed tool argument display.
- scanner runtime, Skill Factory, self-improvement, production persistence, or external actions.
