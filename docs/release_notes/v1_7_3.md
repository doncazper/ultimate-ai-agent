# v1.7.3 Release Notes

v1.7.3 is a post-M150 local file-manager hardening baseline.

It hardens the local/dev file manager by:

- streaming file content hashes instead of reading whole files into memory.
- bounding read-preview file reads while preserving a small redaction lookahead.
- reporting full file size and content hash for previews without expanding the
  preview body beyond the requested byte cap.
- reusing atomic replacement for both apply-write and rollback paths.
- removing temporary write files when atomic replacement fails.

It adds regression tests for bounded preview metadata and failed atomic
replacement cleanup.

M150 remains the accepted Ultimate AI Agent v1.2.0-alpha target packet. This
baseline does not create a release tag, publish a release, build/upload/export
artifacts, begin beta, add dependencies, add backend routes, add Control Center
controls, add shell/subprocess execution, add network access, call
models/providers, write memory, inject context, add broad autonomy, add M151
work, or grant production authority.
