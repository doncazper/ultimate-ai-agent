# Release Notes v0.19.0

Status: Current release notes for M15 Approval Queue + Receipt/Event Viewer UI.

v0.19.0 implements M15 Approval Queue + Receipt/Event Viewer UI.

Added:

- read-only/preview-only Approval Queue UI in CCC Web.
- read-only/preview-only Receipt Viewer UI in CCC Web.
- read-only/preview-only Event Viewer UI in CCC Web.
- safe mock fallback data for approval, receipt, and event summaries.
- selected item detail panels for approval, receipt, and event records.
- frontend tests for M15 routes and safety copy.
- static frontend safety verifier checks for M15 mutation endpoints and dangerous controls.
- Foundation Gate criterion `m15_approval_receipt_event_ui_safe`.
- M15 Control Center docs:
  - `docs/control_center/APPROVAL_QUEUE_UI.md`.
  - `docs/control_center/RECEIPT_EVENT_VIEWER.md`.
  - `docs/control_center/APPROVAL_RECEIPT_UI_SAFETY.md`.

Not added:

- approval execution.
- approval grant/reject mutation.
- send, write, publish, run, deploy, enable, install, or mutation controls.
- backend API routes.
- OpenAPI path count changes.
- backend authority bypass.
- raw secret, prompt, file, memory, credential, or provider payload display.
- runtime execution.
- model/provider calls.
- remote execution or remote worker dispatch.
- mobile app code or mobile sensor APIs.
- plugin enablement.
- Chrome authenticated profile control.
- Computer Use automation.
- iOS/macOS/native build workflows.
- scanner runtime, Skill Factory, self-improvement, production persistence, or external actions.

OpenAPI remains unchanged except for version metadata. Backend path count remains `74`.
