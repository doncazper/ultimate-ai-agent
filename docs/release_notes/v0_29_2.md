# Release Notes v0.29.2

Status: historical release notes.

## Summary

v0.29.2 hardens local-dev API authority and raw preview safety before M26.

## Fixed

- Removes test-prefixed `approval_test_*` fallback authority from Tool
  Broker/kernel mutation paths.
- Keeps public `/kernel/tasks/run` local-dev mutation requests dry-run-only, so
  public API probes cannot create or update local files.
- Returns metadata-only file read preview API responses by default and marks raw
  content as omitted.
- Rejects secret-like file preview refs without echoing the hostile path or
  secret-like value.
- Replaces raw API exception-message echo patterns with sanitized safe messages.
- Makes direct truth authority helper calls fail closed for memory refs and
  model/runtime/OpenWebUI output refs.
- Updates shadow replay and kernel happy-path tests to use scoped
  `LocalApprovalAuthority` grants instead of compatibility approval prefixes.
- Adds Foundation Gate and static verifier coverage for the local-dev API
  authority and metadata-only preview boundaries.

## Safety

v0.29.2 adds no web search, external verification, model/provider calls, local
LLM calls, retrieval/RAG/vector/embedding functionality, source crawling,
memory writes, evidence mutation, Event Ledger mutation, backend truth
verification routes, backend route expansion, dependencies, Control Center
mutation controls, M26 Grounded Recall Router, M26 Context Pack Builder, or
production authority.

OpenAPI path count remains `74`. M26 remains future.
