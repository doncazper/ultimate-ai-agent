# v0.86.0 Release Notes

v0.86.0 implements M82 Command Proposal Contracts.

It adds deterministic local command proposal contracts for structured argv
preview metadata, safe command labels, safe purpose summaries, proposal-only
review decisions, safe summary only receipt plans, evaluator revalidation,
static verification, documentation-integrity checks, tests, and Foundation Gate
coverage.

It adds no shell string, command execution, subprocess execution, shell
execution, process spawn, filesystem mutation, network access, tool execution,
browser automation, plugin execution, remote execution, model call, memory
write, context injection, background worker, backend route, Control Center
control, dependency, M83 work, or production authority.
