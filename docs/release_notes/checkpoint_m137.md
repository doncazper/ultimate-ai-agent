# Checkpoint M137 Release Notes

Checkpoint M137 implements Autonomous Browser + Connector Combined Workflows.

It adds deterministic local contracts for reviewing combined browser and
connector workflow refs, with exact Mode 5, M136, M135, M134, M133, M132,
browser plan, connector plan, dependency order, approval bundle, human
checkpoint, audit, replay, revocation, kill-switch, and no-effect receipt
bindings.

M137 is contract-only, review-only, browser-connector-combined-workflow-only,
safe-ref-only, local-only, and route-free. It performs no browser action, no
connector action, no dependency execution, no tool execution, no shell/network
work, no model call, no memory write, no context injection, no backend route,
no Control Center control, no dependency addition, no beta release, and no
production authority.

M137 also records no account auth, no shell execution, no network access, and
no plugin execution. M138 remains future. M150 remains the v1.2.0-alpha target.
