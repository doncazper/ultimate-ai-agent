# v0.40.0 Release Notes

Status: historical release notes.
Release: **v0.40.0 / M36 - CCC File Review Surface, Review-Only**.

v0.40.0 implements M36 as a review-only Control Center file review surface. It
displays visibly mock and non-authoritative redacted review packets, redacted
preview text, redaction summaries, exact binding refs, review-only decision
status, approval gate contract status, and receipt plan metadata.

## Added

- `/files/review` Control Center route.
- `FileReviewSurfacePanel` frontend component.
- M36 mock file review packet data with exact safe binding refs.
- frontend tests for redacted preview display, redaction summary display,
  exact binding refs, review-only decision status, approval-gate contract
  status, receipt-plan metadata, and absence of mutation controls.
- M36 Control Center docs, release notes, archive packet, static verification,
  and Foundation Gate coverage.

## Preserved Boundaries

M36 adds no approval capture, approval persistence, backend review routes, raw
file reads, raw file content display, raw file content storage, full-file
reads, file picker/browser/upload/root selector, export/download/copy-raw
controls, context proposal, context injection, memory writes, execution/tool
controls, file mutation, dependencies, M37 work, M38 work, or production
authority.

M37 remains planned/provisional. M38 remains planned/provisional.
