# v0.33.1 Release Notes

Status: active release notes.

Current active baseline: **v0.33.1**

v0.33.1 hardens M29 — Agent Task Planning Engine.

This patch strengthens task plan dependency, risk, authority, evaluator
revalidation, and no-execution safety. It keeps M29 deterministic, local,
non-executing, non-authoritative, and valid for review only.

Hardening included:

- duplicate and missing step IDs remain denied
- self, direct, and indirect dependency cycles are denied
- dependency validation remains deterministic
- derived risk wins over caller-declared risk
- side effects cannot be hidden in safe-looking metadata
- plan risk equals the highest trusted derived step risk
- approval, context-pack, memory, tool-intent, OpenWebUI, Control Center, and model-output refs cannot authorize execution
- evaluator boundaries revalidate safety-critical fields before review decisions
- model_copy-mutated raw/secret/execution fields remain denied
- `execution_performed=False` remains invariant
- Foundation Gate and static verifier coverage are strengthened

Safety boundaries:

- no task execution
- no auto-run, scheduler runtime, background worker, or daemon
- no tool or action execution
- no shell/subprocess execution
- no file mutation
- no memory writes
- no network calls
- no model/provider calls
- no browser/mobile/remote/plugin execution
- no backend task/plan execution routes
- no Control Center execute controls
- no dependencies
- no context injection
- no production authority
- no M30 implementation

OpenAPI path count remains `74`.

M30-M40 remain planned/provisional.
