# Release Notes v0.10.1

v0.10.1 implements M6.1: Foundation Gate hardening, CI polish, warning cleanup, and release hygiene.

## Changed

- Replaced project-owned `datetime.utcnow()` runtime usage with timezone-aware UTC timestamps.
- Strengthened `scripts/verify_all.py` with an explicit sectioned scan summary.
- Updated baseline verification to reuse the shared static scan helper.
- Added `--output` JSON report support to `scripts/run_foundation_gate.py`.
- Stabilized Foundation Gate report result ordering for clearer reviews.
- Added CI for master verification, Foundation Gate execution, and Ruff.

## Tests

- Added regression coverage for tracked generated artifacts, runtime datetime hygiene, deterministic gate report ordering, and gate runner output.

## Still blocked

v0.10.1 does not implement scanners, companion proactivity, Skill Factory, self-improving code, autopilot workflows, real provider integrations, web fetching, real model calls, real tools/external actions, production memory storage, pgvector, embeddings, browser automation, real SDK/A2A runtime delegation, OAuth flows, production secret vaults, production truth connectors, or high-autonomy execution.
