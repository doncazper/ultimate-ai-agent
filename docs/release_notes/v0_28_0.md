# Release Notes v0.28.0

Status: Historical release notes.

## Summary

v0.28.0 implements M24 Memory Provider Abstraction + Local Memory Store.

## Added

- Governed MemoryProvider abstraction.
- Local in-memory/dev memory store.
- Explicit-path stdlib SQLite local store support.
- Reviewed-write-only validation.
- Memory taxonomy, source priority, provenance, trust/confidence metadata, retention/delete/export contracts, conflict/staleness metadata, dedup/decay/archive planning metadata, and recall-planning metadata.
- M24 memory docs, documentation integrity checks, static verifier coverage, tests, and Foundation Gate criterion.

## Safety

Memory is recall, not authority. Memory is not ground truth. Canonical files, evidence manifests, receipts, Event Ledger records, and user-reviewed sources outrank memory.

M24 blocks automatic writes, model-output writes, local LLM output writes, OpenWebUI chat memory writes, Control Center mutation, mobile capture writes, tool output writes, raw prompt/model/file/transcript content, secrets, cloud memory providers, vector DB, embeddings, context injection, backend mutation routes, dependencies, and production persistence.

OpenAPI path count remains `74`.

M25 remains future.
