# Release Notes v0.12.0

v0.12.0 implements M8, the Simulated Model Runtime Adapter Harness.

## Added

- Simulated model runtime adapter manifests.
- Model runtime request and response contracts.
- Deterministic simulated responses for text, JSON, structured, and refusal-style outputs.
- Model-router-to-runtime request conversion for selected routes only.
- Model runtime API routes for manifest validation, request validation, response validation, and simulation.
- Secret blocking for prompt summaries and runtime metadata.
- Event-compatible simulated runtime metadata.
- Foundation Gate criteria proving M8 is simulated-only.

## Still blocked

v0.12.0 does not implement real model calls, provider SDK calls, OpenAI-compatible endpoint calls, local runtime calls, tokenizer integrations, billing APIs, network calls, scanners, companion proactivity, Skill Factory, self-improving code, autopilot workflows, browser automation, production persistence, real SDK/A2A runtime delegation, production secret vaults, production truth connectors, or high-autonomy execution.
