# Release Notes v0.27.1

Status: Historical release notes for v0.27.1 / M23 Local LLM Call Safety
Hardening.

v0.27.1 hardens the existing M23 First Real Local LLM Call boundary while
keeping it manual/CLI-only, loopback-only, fixed-prompt-only, approval-gated,
non-tool, and non-authoritative.

Changed:

- strengthened endpoint tests for secret-like query keys and values,
  non-loopback IPv6, and safe endpoint-label redaction.
- strengthened response contract tests for raw response storage and
  secret-like safe summaries.
- strengthened approval boundary tests so forged allowed-looking approval
  decisions do not authorize transport calls.
- strengthened CLI tests and static verifier checks for forbidden prompt,
  auth, cookie, and output-file arguments.
- added granular M23 docs for fixed prompt policy, local call safety, receipts,
  non-authoritative output, manual CLI usage, and the M23-to-M24 boundary.
- strengthened Foundation Gate M23 criteria and documentation integrity checks.
- hardened Foundation Gate report writing so latest JSON reports are published
  with same-directory temp files and atomic `os.replace`.

The Foundation Gate report-write hardening is a small tooling/test hardening
item. It was not a v0.27.0 release blocker. The known FastAPI/Starlette
TestClient deprecation warning remains third-party, non-security, and
non-blocking.

Safety boundary:

- fixed prompt only: `m23_fixed_local_model_smoke_v1`.
- no arbitrary prompt, stdin prompt, file prompt, clipboard prompt, memory
  prompt, OpenWebUI transcript prompt, or user content.
- CLI defaults dry-run.
- real manual execution requires `--execute-local-call` and validated local
  approval evidence.
- loopback-only HTTP endpoints.
- responses are capped, redacted, and blocked if secret-like.
- raw responses are not stored.
- model output is non-authoritative and not trusted control input.
- tests and Foundation Gate use fake transport only.

This release adds no backend API route, no OpenAPI path count change, no runtime
activation, no endpoint probe, no provider SDK, no runtime package, no tokenizer,
no billing API, no OpenWebUI runtime bridge, no Control Center execution
control, no tool execution, no memory write, no file write, no remote execution,
no mobile sensor access, no plugin enablement, no dependency, and no production
authority.

OpenAPI path count remains `74`. M24 remains future.
