# Release Notes v0.26.1

Status: Historical release notes for v0.26.1 / M22 safety hardening.

v0.26.1 hardens M22 Local Model Runtime Activation Contract safety in response
to read-only advisory review findings.

Changed:

- tightened M22 forbidden-fragment scans to avoid false positives on harmless
  metadata access such as `dict.get(...)`.
- preserved blocking for qualified runtime/network/model client call patterns.
- validated metadata keys as well as values for M22 local runtime activation
  policy, request, and decision contracts.
- removed a brittle local unit-test route-count assertion while keeping
  canonical OpenAPI and Foundation Gate route-count checks.
- cleaned duplicate wording in the M22 activation contract docs.
- updated active version and release docs for v0.26.1.

Safety boundary:

- no model was called.
- no runtime was activated.
- no endpoint was contacted.
- no backend API route.
- no OpenAPI path count change; path count remains `74`.
- no runtime execution.
- no local LLM call.
- no provider call.
- no endpoint probe.
- no user prompt processing.
- no tool execution.
- no memory write.
- no file write.
- no OpenWebUI runtime behavior.
- no dependency.
- no production authority.

M23 First Real Local LLM Call remains planned/provisional.
