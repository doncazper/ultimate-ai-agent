# Release Notes v0.37.1

Status: active release notes.
Current active baseline: **v0.37.1**

v0.37.1 hardens M33 First Safe Local File Read Proposal, Redacted Preview Only.

## Hardened

- Redacted preview output contracts now reject unredacted secret-like preview
  text at result creation.
- Safe-root validation denies symlink safe roots before preview.
- Static verification and Foundation Gate now probe both hardening paths.
- Regression tests cover symlink safe-root denial and direct output-boundary
  secret-like preview denial.
- Active M33 docs now state that evaluator boundaries revalidate
  safety-critical fields and that constructor validation alone is not trusted.

## Safety Boundaries

M33 still returns no raw file content, stores no raw file content, exposes no
raw absolute path, computes no content hash, lists no directories, follows no
symlinks, mutates no files, performs no context injection, and adds no backend
raw-file/execute routes or Control Center raw-preview/execute controls.

M34 remains planned/provisional.
