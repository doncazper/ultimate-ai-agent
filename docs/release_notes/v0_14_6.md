# Release Notes v0.14.6

## Codex Plugin and External Build Tool Governance Inventory

v0.14.6 updates the accepted v0.14.5 baseline with a docs/governance patch only.

Changed:

- added `docs/tooling/CODEX_PLUGIN_CAPABILITY_INVENTORY.md`.
- added `docs/tooling/CODEX_PLUGIN_RISK_POLICY.md`.
- added `docs/canonical/66_external_tooling_and_codex_plugin_governance.md`.
- added `docs/backlog/codex_plugin_enablement_backlog.md`.
- kept `docs/maintenance/codex_plugin_capability_inventory.md` as a pointer to the active tooling inventory.
- updated the documentation integrity verifier with conservative Codex plugin governance checks.
- extended Foundation Gate documentation checks for Codex plugin governance docs.
- synchronized README, import docs, master plan, roadmap, API docs, mobile planning docs, documentation index, canonical map, release notes, and Foundation Gate plan.

Policy summary:

- Browser + Build Web Apps may be considered for future Web Control Center work with explicit approval.
- Chrome authenticated profile control remains disabled unless explicitly approved.
- Build iOS Apps / XcodeBuildMCP remains disabled until a dedicated Mobile Companion implementation milestone.
- Build macOS Apps remains disabled until a dedicated Desktop/macOS Companion milestone.
- CodeRabbit/GitHub read-only review can be used for release readiness with explicit review prompts.
- GitHub write/release actions require explicit approval or direct-push rules.
- Computer Use remains disabled except explicit last-resort manual QA approval.
- Hugging Face Jobs, uploads, training, and Spaces deployment remain disabled.
- Plugin/skill installers remain disabled due to supply-chain risk.
- Shell/exec commands remain narrowly scoped to verifier, test, grep, git, and approved implementation workflows.

No plugin enablement, plugin install, mobile app code, desktop app code, native build workflow, Xcode workflow, simulator/device workflow, keychain/signing/provisioning access, App Store Connect access, browser authenticated-profile control, Computer Use automation, cloud training/upload, dependency, network call, runtime feature, scanner, Skill Factory, self-improving code, production persistence, or external action was added.
