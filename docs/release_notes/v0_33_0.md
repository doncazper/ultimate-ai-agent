# v0.33.0 Release Notes

Status: active release notes.

Current active baseline: **v0.33.0**

v0.33.0 implements M29 — Agent Task Planning Engine.

This release adds deterministic, local, non-executing task planning contracts for safe task goals, steps, dependency graphs, input boundaries, risk/authority checks, decision envelopes, and receipt plans. Safe plans may be marked valid for review only.

Safety boundaries:

- no task execution
- no auto-run or scheduler runtime
- no tool or action execution
- no shell/subprocess execution
- no file mutation
- no memory writes
- no network calls
- no model/provider calls
- no browser/mobile/remote/plugin execution
- no backend task/plan execution routes
- no Control Center execute controls
- no dependencies
- no context injection
- no production authority
- no M30 implementation

OpenAPI path count remains `74`.

M30-M40 remain planned/provisional.
