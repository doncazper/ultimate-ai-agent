# v1.4.0 Release Notes

v1.4.0 implements M100 Mobile Permission Model v1.

It defines a contract-only mobile permission taxonomy, consent model,
revocation model, privacy copy requirements, permission audit contracts,
documentation-integrity checks, static verification, tests, and Foundation Gate
coverage.

It adds no mobile sensors, location/camera/photos/microphone access, runtime
permission prompts, native permission requests, background collection, push
execution, backend route, dependency, M101 work, or production authority.
