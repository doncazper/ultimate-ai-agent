# v0.49.0 Release Notes

Status: Released M45 baseline candidate.

v0.49.0 implements M45 - CCC iOS Local Read-Only Connection. It adds Python
contracts, validators, Swift source-only status models, documentation, static
verification, and Foundation Gate coverage for a local-only, loopback-only,
read-only CCC iOS connection surface.

The release adds no runtime network call, backend route, mobile API route
runtime, approval capture, approval execution, raw data, context injection,
memory write, file mutation, execution, background collection, mobile sensor
access, credential handling, cookie handling, Xcode project, Swift package,
signing workflow, TestFlight pipeline, dependency, production authority, or M46
implementation.

M46 remains future.
