# Release Notes v0.21.0

Status: Historical release notes for M17 Evidence/File/Memory Viewer.

v0.21.0 implements read-only Evidence/File/Memory Viewer surfaces in CCC Web.

Added:

- `/evidence` frontend route for redacted evidence ref summaries.
- `/files` frontend route for safe file ref metadata summaries.
- `/memory` frontend route for recall-only memory ref summaries.
- safe mock M17 knowledge data marked mock, non-authoritative, read-only, preview-only, and redacted summary-only.
- frontend tests for M17 route headings, redaction safety, no raw sensitive display, and no mutation controls.
- static frontend verifier checks for M17 raw knowledge fields, credential-like fields, private path fragments, mutation endpoints, and required boundary copy.
- Foundation Gate criterion and evaluator coverage for M17 UI, docs, verifier, and unchanged OpenAPI path count.
- Control Center docs for evidence, file refs, memory, and combined M17 safety policy.

Not added:

- backend API routes.
- OpenAPI path count changes.
- file mutation, file browsing, or raw file display.
- memory mutation, memory provider implementation, vector DB, embeddings, learn/forget/edit/delete controls, or raw memory display.
- raw evidence payload display.
- approval execution.
- tool execution.
- model/provider calls.
- remote execution or remote worker dispatch.
- mobile app code or mobile sensor APIs.
- plugin enablement.
- Chrome authenticated profile control.
- Computer Use automation.
- iOS/macOS/native build workflows.
- production telemetry export.
- external observability integration.
- raw secret, prompt, credential, provider payload, or unreviewed tool argument display.
- scanner runtime, Skill Factory, self-improvement, production persistence, or external actions.

OpenAPI remains unchanged except for version metadata. Backend path count remains `74`.
