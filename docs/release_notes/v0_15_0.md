# Release Notes v0.15.0

Status: Active M11 release baseline.

v0.15.0 implements M11 Runtime Foundation Readiness Gate and Manual Smoke Report Validation on top of accepted v0.14.6.

Added:

- runtime readiness package under `src/ultimate_ai_agent/core/runtime_readiness/`.
- deterministic runtime capability matrix contracts.
- typed runtime readiness reports.
- manual smoke report validation for safe summaries only.
- API status/validation routes:
  - `GET /runtime/readiness`
  - `GET /runtime/capability-matrix`
  - `POST /runtime/smoke-reports/validate`
- Foundation Gate criteria proving M11 adds no runtime execution capability.
- runtime readiness documentation.

Not added:

- no runtime execution.
- no cloud/provider/model calls.
- no provider SDKs.
- no tokenizer or billing integrations.
- no remote execution.
- no live private mesh/tailnet, Headscale, Tailscale, or WireGuard calls.
- no mobile sensor access.
- no plugin/tool enablement.
- no native builds.
- no production persistence.
- no production readiness claim.

Manual smoke reports are validation artifacts only. Model output remains non-authoritative.
