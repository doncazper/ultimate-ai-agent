# Release Notes v0.13.1

## M9 Loopback Policy Hardening Patch

v0.13.1 is a targeted patch release for the M9 Local Loopback Model Runtime Adapter.

Fixed:

- non-loopback hosts are denied unconditionally by the local loopback adapter
- caller-supplied `allowed_hosts` cannot authorize remote or private LAN hosts
- `deny_non_loopback=false` cannot disable the loopback guard
- API endpoint validation returns explicit denial reason codes for hostile policy override payloads
- Foundation Gate now includes a criterion for the exact policy override bypass

Guardrails preserved:

- no cloud model calls
- no provider SDKs
- no API keys or secret reads
- no tokenizers or billing APIs
- no real network/model calls in tests, CI, `verify_all.py`, or Foundation Gate
- no production auth, OAuth, persistence, scanners, browser automation, SDK/A2A runtime delegation, or external actions

The model remains non-authoritative. Local loopback responses and simulated fallback responses are marked as not truth authority.
