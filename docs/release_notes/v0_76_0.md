# v0.76.0 Release Notes

v0.76.0 implements M72 Read-Only HTTP Fetch Tool, Allowlisted.

This release adds a bounded allowlisted read-only HTTP fetch tool through the
governed tool runtime adapter. It validates explicit host allowlists, HTTPS,
GET-only requests, no credentials or cookies, no request body, no request
headers, no query strings, bounded response bytes, redaction before return,
redacted preview outputs, safe receipt metadata, tests, documentation,
documentation-integrity checks, static verification, and Foundation Gate
coverage.

The M72 tool requires an explicit reviewed transport object. Tests and
Foundation Gate coverage use fake transport only. The core tool contracts add no
embedded broad HTTP client and no backend route.

v0.76.0 adds no unrestricted network tool, authenticated network action,
credentials or cookies, request body, non-GET method, raw response body, raw
headers, download or export, context injection, memory write, model call,
browser automation, backend route, Control Center control, dependency,
production authority, or M73 work.

M73 remains future.
