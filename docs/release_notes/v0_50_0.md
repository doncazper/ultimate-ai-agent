# v0.50.0 Release Notes

Status: Released M46 baseline candidate.

v0.50.0 implements M46 - iOS Review/Receipt Read-Only Surfaces. It adds Python
contracts, validators, Swift source-only review/receipt display models,
documentation, static verification, and Foundation Gate coverage for read-only,
redacted summary iOS review and receipt surfaces.

The release adds no runtime network call, backend route, mobile API route
runtime, approval capture, approval execution, raw data, context injection,
memory write, file mutation, export, execution, background collection, mobile
sensor access, credential handling, cookie handling, Xcode project, Swift
package, signing workflow, TestFlight pipeline, dependency, production
authority, or M47 implementation.

M47 remains future.
