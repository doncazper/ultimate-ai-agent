# v0.34.1 Release Notes

Status: active release notes.

Current active baseline: **v0.34.1**

v0.34.1 hardens M30 — Multi-Step Execution Framework.

This release strengthens deterministic, local, side-effect-safe execution
state-machine contracts. It keeps M30 state-machine-only and no-effect while
closing transition, replay, dependency, and hidden-side-effect gaps.

Implemented:

- ready-only no-effect step completion.
- run finalization denial while pending, blocked, or future-real-execution
  steps remain.
- transition-id replay protection in addition to replay-key protection.
- blocked, paused, denied, skipped, and completed-step completion denial.
- hidden side-effect metadata denial.
- `side_effect_execution_enabled=True` evaluator-boundary denial.
- evaluator-side revalidation for model_copy-mutated safety-critical fields.
- static verifier and Foundation Gate coverage for M30 hardening probes.
- documentation-integrity checks for the new M30 hardening boundaries.

Safety boundaries:

- no real task execution.
- no action execution.
- no tool execution.
- no scheduler/background worker or autonomous loop.
- no shell execution.
- no file mutation.
- no memory writes or Event Ledger mutation.
- no network calls.
- no model/provider calls.
- no browser/mobile/remote/plugin execution.
- no backend execution routes.
- no Control Center execute controls.
- no dependencies.
- no context injection.
- no production authority.
- no M31 implementation.

OpenAPI path count remains `74`.

M31-M40 remain planned/provisional.
