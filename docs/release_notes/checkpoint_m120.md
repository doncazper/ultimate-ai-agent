# Checkpoint M120 Release Notes

Checkpoint M120 adds Production Authority Readiness Review while the current
product baseline remains v1.7.2. It uses the checkpoint-m120 tag and keeps M150
as the planned v1.0.0-alpha target.

The checkpoint adds contract-only, review-only production authority readiness
records bound to the M119 Production Red-Team Harness. The records use safe
refs for readiness checks, launch blockers, rollback readiness, audit, replay,
accepted checkpoints, and no-effect receipt plans.

M120 adds no production authority, no production runtime, no go-live, no
production deployment, no external distribution, no traffic routing, no network
access, no credential handling, no account action, no model call, no memory
write, no context injection, no execution, no tool execution, no shell
execution, no browser automation, no plugin execution, no mobile sensor access,
no backend routes, no Control Center controls, no dependencies, no M121 work,
no beta release, and no production authority.

M121 remains future. M150 remains the planned v1.0.0-alpha target.
