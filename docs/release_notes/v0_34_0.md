# v0.34.0 Release Notes

Status: active release notes.

Current active baseline: **v0.34.0**

v0.34.0 implements M30 — Multi-Step Execution Framework.

This release adds deterministic, local, side-effect-safe execution-state-machine
contracts. It models execution runs, execution steps, transition requests,
transition decisions, replay keys, dependency-aware no-effect progression, and
non-authoritative receipt plans.

Implemented:

- `src/ultimate_ai_agent/core/execution/` contracts and state-machine helpers.
- dependency validation for duplicate, missing, self, direct-cycle, and
  indirect-cycle step refs.
- replay-key denial.
- no-effect transition decisions with `execution_authorized=False` and
  `execution_performed=False`.
- evaluator-side revalidation for raw/secret and execution-request fields.
- denial of model, runtime, OpenWebUI, memory, context-pack, tool-intent,
  approval, approval-decision, Control Center preview, and unknown refs as
  execution authority.
- static verifier and Foundation Gate coverage.
- M30 documentation and release archive packet.

Safety boundaries:

- no real task execution.
- no action execution.
- no tool execution.
- no scheduler/background worker or autonomous loop.
- no shell execution.
- no file mutation.
- no memory writes or Event Ledger mutation.
- no network calls.
- no model/provider calls.
- no browser/mobile/remote/plugin execution.
- no backend execution routes.
- no Control Center execute controls.
- no dependencies.
- no context injection.
- no production authority.
- no M31 implementation.

OpenAPI path count remains `74`.

M31-M40 remain planned/provisional.
