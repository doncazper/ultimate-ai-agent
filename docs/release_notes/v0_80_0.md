# Release Notes v0.80.0

v0.80.0 implements M76 OpenWebUI Runtime Bridge v1.

This release adds deterministic review-only OpenWebUI runtime bridge envelopes
over safe refs only. It adds policy validation, request validation, receipt
plans, stable reason codes, tests, static verification,
documentation-integrity checks, and Foundation Gate coverage.

The bridge is not a live OpenWebUI runtime integration. It performs no live
OpenWebUI connection, OpenWebUI runtime call, OpenWebUI handoff execution,
provider call, model call, model authority, tool execution, memory write,
context injection, network call, credential or cookie access, raw prompt
exposure, raw provider payload exposure, raw content exposure, backend route,
Control Center control, dependency, M77 work, or production authority.

M77 remains future.
