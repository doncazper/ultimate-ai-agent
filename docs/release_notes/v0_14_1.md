# Release Notes v0.14.1

## M10.5 Remote Worker and Tailnet Transport Foundation

v0.14.1 adds REMOTE-01 as a foundation-only milestone after the accepted v0.14.0 baseline.

Added:

- disabled-by-default remote worker schemas
- planned tailnet/LAN transport metadata
- mock/local-only node and transport registries
- remote job envelope and result contracts
- dry-run-only remote job validation
- remote worker API validation, status, and dry-run routes
- Foundation Gate checks for inert remote worker behavior

No live networking exists in this milestone.
No job dispatch exists in this milestone.
No remote approvals exist in this milestone.

It also adds no listener, network call, private transport call, job dispatch, remote subagent launch, remote tool execution, sandbox execution, personal-data access, write/send action, background service, production persistence, provider SDK, tokenizer, billing API, secret-store integration, or safety bypass.

Remote worker output remains untrusted and non-authoritative.
