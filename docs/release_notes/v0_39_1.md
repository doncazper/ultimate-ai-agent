# v0.39.1 Release Notes

Status: current release notes.
Release: **v0.39.1 / M35 hardening - File Review Exact File/Path Binding**.

v0.39.1 hardens M35 Safe File Review Workflow Contracts. It strengthens exact
approval binding so a review approval must match the reviewed actor, review
packet, preview result, redaction summary, `file_ref`, and `safe_path_ref`
before a review-only decision can be allowed.

## Fixed

- approval contracts now carry `file_ref` and `safe_path_ref`.
- gate contracts now carry expected `file_ref` and `safe_path_ref`.
- evaluator revalidation denies missing or mutated file/path refs.
- `model_copy` mutations to packet `file_ref` or `safe_path_ref` are denied.
- static verification and Foundation Gate probes cover exact file/path binding.
- documentation integrity checks require active docs to describe exact file/path
  binding and deny `review_packet_ref`-alone authority.

## Preserved Boundaries

M35 remains review-only and non-authoritative. This patch adds no Control
Center file review UI, approval capture, approval persistence, context
proposal, context injection, memory writes, export, execution, raw file access,
full-file reads, unredacted previews, file mutation, backend routes,
dependencies, M36 work, M37 work, M38 work, or production authority.

M36 remains planned/provisional. M37 remains planned/provisional. M38 remains
planned/provisional.
