# v0.61.0 Release Notes

v0.61.0 implements M57 Runtime Sandbox Architecture Review.

Added:

- deterministic local runtime sandbox architecture review contracts.
- architecture policy, request, decision, and receipt-plan models.
- validation for sandbox runtime, subprocess execution, shell execution,
  process spawn, file mutation, network access, tool execution, browser
  automation, plugin execution, remote execution, model call, memory write,
  context injection, side-effect, dependency, route, M58 dry-run harness, and
  production authority denial.
- tests, documentation-integrity checks, static verification, and Foundation
  Gate coverage.

Not added:

- sandbox execution.
- subprocess execution.
- shell execution.
- process spawn.
- file mutation.
- network access.
- tool execution.
- browser automation.
- plugin execution.
- remote execution.
- model/provider calls.
- memory writes.
- context injection.
- backend routes.
- Control Center controls.
- dependencies.
- production authority.
- M58 implementation.

M58 remains future.
