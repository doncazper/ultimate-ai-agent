# Release Notes v0.11.1

v0.11.1 hardens M7 policy correctness for the Model Router and Cost/Resource Governor foundation.

## Fixed

- Arbitrary approval refs no longer satisfy cloud approval for sensitive, regulated, or TCB-protected route requests.
- Context budget available-history checks are enforced before a model profile can be selected.
- Soft budget overages allow with warning instead of denying.
- Hard budget overages still deny routes.
- Model route decisions preserve soft-budget warning reason codes.
- Foundation Gate now covers these M7 policy semantics.

## Still blocked

v0.11.1 does not implement real model calls, provider API calls, tokenizer API calls, billing API calls, network calls, scanners, companion proactivity, Skill Factory, self-improving code, autopilot workflows, web fetching, real tools/external actions, production memory storage, pgvector, embeddings, browser automation, real SDK/A2A runtime delegation, OAuth flows, production secret vaults, production truth connectors, or high-autonomy execution.
