# Release Notes v0.17.4

Status: Historical release notes for the Web Control Center local browser smoke polish patch.

v0.17.4 polishes the existing v0.17.x Web Control Center shell and adds safe local browser smoke reporting documentation. It is not M14.

Changed:

- active version metadata now points to `0.17.4`.
- README, documentation index, canonical map, import docs, master plan, and Foundation Gate plan point to v0.17.4.
- `docs/control_center/LOCAL_BROWSER_SMOKE_REPORTING.md` defines a safe local-only browser smoke report format.
- Web Control Center pages now expose clearer route-level headings for local browser smoke review.
- loading and empty states now use accessible status semantics and read-only wording.
- action preview now shows risk level as preview metadata only.
- frontend tests cover route headings, state copy, risk metadata, and redacted backend preview errors.
- browser smoke readiness verification now checks the smoke reporting doc.

Unchanged:

- backend OpenAPI path count remains `74`.
- Control Center backend routes remain read-only/preview-only.
- Web Control Center remains a local shell.
- Python Agent Core remains the brain.
- Browser smoke remains manual, local-only, unauthenticated-profile-free, and non-authoritative.

Not added:

- production Control Center authority.
- public execution API.
- backend route or dependency.
- runtime/model/provider calls.
- remote dispatch.
- mobile/native app or sensor access.
- plugin enablement.
- Chrome authenticated profile control.
- Computer Use automation.
- iOS/macOS build workflow.
- analytics/auth/payment/SaaS SDKs.
- production persistence.
