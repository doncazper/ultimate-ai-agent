# Release Notes v0.22.0

Status: Current release notes for M18 Local Runtime Status + Manual Smoke Control Surface.

v0.22.0 implements M18 in CCC Web only.

Added:

- `/runtime/local` read-only local runtime status page.
- `/runtime/manual-smoke` validation-only manual smoke report surface.
- safe M18 mock data for local runtime surfaces and manual smoke validation summaries.
- M18 frontend tests.
- M18 static frontend verifier coverage.
- M18 Foundation Gate criterion and OpenAPI route guard.
- docs for local runtime status UI, manual smoke control surface, and runtime smoke UI safety.

Safety:

- No backend route is added.
- OpenAPI path count remains `74`.
- M18 surfaces are visibly mock, non-authoritative, and redacted summary-only when using fallback data.
- manual smoke reports show safe refs, fixed prompt hash, reason codes, and validation status only.
- no raw smoke report, no raw prompts, no raw response bodies, no credentials, and no provider payloads are displayed.

Not added:

- runtime execution.
- manual smoke execution.
- model/provider calls.
- remote execution or remote worker dispatch.
- mobile sensor access.
- plugin enablement.
- OpenWebUI integration or configuration.
- scanner runtime.
- Skill Factory or self-improvement.
- production persistence.
- local runtime provider integrations.
- dependencies.
- backend API routes.
- production Control Center authority.
