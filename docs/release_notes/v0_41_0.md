# v0.41.0 Release Notes

Status: historical release notes.
Release: **v0.41.0 / M37 - Review Approval Capture, Review-Only Persistence**.

v0.41.0 implements M37. It adds review-only approval and denial capture for
already-redacted file review packets, exact binding validation, safe-ref-only
approval records, idempotency/replay protection, one backend capture route,
Control Center review-only capture controls, tests, static verification,
documentation-integrity checks, and Foundation Gate coverage.

## Added

- `FileReviewApprovalCaptureRequest`, `FileReviewApprovalRecord`, capture
  decision, receipt plan, and safe approval store contracts.
- `POST /files/review/approvals/capture` as the only M37 backend mutation
  route.
- Control Center `Approve review-only` and `Deny review-only` controls for safe
  mock/non-authoritative review data.
- M37 docs, tests, verifier coverage, and Foundation Gate criteria.

## Preserved Boundaries

M37 adds no raw file reads, raw file output/storage, full-file reads,
unredacted preview, file export/download, context proposal, context injection,
memory writes, execution/tool controls, file mutation outside the review
approval store, dependencies, M38 work, or production authority.

M38 remains planned/provisional.
