# M90 to M91 Boundary

M90 implements Shell/Subprocess Hardening Freeze as contract-only, review-only,
freeze-only validation over exact M89 Emergency Stop + Process Kill Safety
decisions.

M90 may record safe hardening refs, stable reason codes, exact M89 binding
refs, safe summary only receipt plans, and deterministic freeze status.

M90 does not add command execution, shell execution, subprocess execution,
process spawn, emergency stop execution, process kill, process signal,
filesystem mutation, network access, tool execution, browser automation,
plugin execution, remote execution, model call, memory write, context
injection, background worker, backend route, Control Center control,
dependency, or production authority.

M91 remains future and may introduce Autonomous Tool Execution Contract work
only after M90 is accepted Green. M91 must not use M90 as execution authority.
