# M84 to M85 Boundary

M84 implements only the sandboxed echo/no-op command contract. It is in-process
only, deterministic, local-only, and safe summary only over an M83 shell dry-run
classifier no-effect decision.

M84 adds no read-only command allowlist, command execution, subprocess execution,
shell execution, process spawn, filesystem mutation, network access, tool
execution, browser automation, plugin execution, remote execution, model call,
memory write, context injection, background worker, backend route, Control
Center control, dependency, or production authority.

M85 remains future and is the first place a read-only command allowlist may be
reviewed. M84 does not implement M85.
