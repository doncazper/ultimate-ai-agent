# Mutating Command Proposal Non-Goals

M88 does not implement:

- command execution.
- subprocess execution.
- shell execution.
- process spawn.
- filesystem mutation.
- command retry.
- command runner.
- sandbox runner.
- network access.
- tool execution.
- browser automation.
- plugin execution.
- remote execution.
- model call.
- memory write.
- context injection.
- background worker.
- backend route.
- Control Center control.
- dependency.
- production authority.
- shell string storage.
- raw command storage.
- raw output storage.
- raw prompt storage.
- raw provider payload storage.
- secret-like content storage.

M88 is a mutating command proposal review milestone only. M89 remains future.
