# Shell Approval Gate Non-Goals

M86 does not implement:

- shell string storage
- raw command storage
- raw output storage
- command execution
- subprocess execution
- shell execution
- process spawn
- filesystem mutation
- network access
- tool execution
- browser automation
- plugin execution
- remote execution
- model call
- memory write
- context injection
- background worker
- backend route
- Control Center control
- dependency
- production authority
- M87 implementation

M86 is a review-only shell approval gate contract. Approval refs are identifiers
only, scoped approval bundle refs are non-authoritative, and M87 remains future.
