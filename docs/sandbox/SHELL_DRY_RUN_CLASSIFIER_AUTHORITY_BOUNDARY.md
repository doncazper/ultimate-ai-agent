# Shell Dry-Run Classifier Authority Boundary

M83 Shell Dry-Run Classifier decisions are non-authoritative. A classification
does not authorize a command, shell, subprocess, process spawn, dry-run
execution, file mutation, network access, tool execution, browser automation,
plugin execution, remote execution, model call, memory write, context
injection, backend route, Control Center control, dependency, or production
authority.

Approval refs, model output, runtime output, memory refs, context refs, tool
intents, and task plans are not authority for M83.

M83 requires an M82 command proposal and keeps the result classifier-only,
review-only, deterministic, and local-only. Evaluator boundaries revalidate
safety-critical fields.

M84 remains future.
