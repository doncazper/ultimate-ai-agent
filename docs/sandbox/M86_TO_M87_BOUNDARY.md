# M86 to M87 Boundary

M86 implements Shell Approval Gate v1 as contract-only, review-only validation
over exact M85 Read-Only Command Allowlist decisions and exact scoped approval
bundles.

M86 may record safe refs only, stable reason codes, safe summary only receipt
plans, and review-only approval validity for exact shell approval gate scope.

M86 does not add shell strings, raw commands, raw output, command execution,
subprocess execution, shell execution, process spawn, filesystem mutation,
network access, tool execution, browser automation, plugin execution, remote
execution, model call, memory write, context injection, background worker,
backend route, Control Center control, dependency, or production authority.

M87 remains future and may review sandboxed command audit replay only after M86
is accepted Green.
