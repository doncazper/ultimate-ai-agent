# Execution Non-Goals

Status: active M30 source-of-truth documentation.

M30 intentionally does not add:

- real task execution.
- action execution.
- tool execution.
- shell execution.
- file mutation.
- memory writes.
- Event Ledger mutation.
- network calls or web search.
- model/provider calls or local LLM calls.
- browser automation.
- mobile/device access.
- remote execution.
- plugin enablement.
- scheduler runtime.
- background worker or daemon.
- autonomous loops.
- context injection runtime.
- vector search, embeddings, semantic search, or RAG.
- backend execution routes.
- Control Center execute controls.
- dependencies.
- production authority.
- M31 implementation.

M30 is a state-machine contract layer only.

M31 is implemented/released by v0.35.0 as Real Tool Runtime Adapter, Single Safe No-Op Tool. M32-M40 remain planned/provisional.
