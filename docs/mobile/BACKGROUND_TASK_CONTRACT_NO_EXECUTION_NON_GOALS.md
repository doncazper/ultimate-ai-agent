- background task execution
- background worker runtime
- scheduler runtime
- daemon runtime
- OS background permission prompt
- push trigger
- device token handling
- external service integration
- raw task payload storage
- backend route
- Control Center control
- dependency change
- memory write
- context injection
- execution
- M106 work
- broad autonomy
- production authority

M106 remains future.
