# M102 Location Receipt Plan

M102 receipt plans are safe-summary only. They may include:

- location policy ref.
- location scope ref.
- actor ref.
- device ref.
- purpose ref.
- reason codes.
- off-by-default status.
- consent, revocation, and audit requirement status.

Receipt plans must not store raw coordinates, location history, geofence data,
device sensor payloads, raw private content, secrets, credentials, raw paths,
memory content, context content, or execution output.
