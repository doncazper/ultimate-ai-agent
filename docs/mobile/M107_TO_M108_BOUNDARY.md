# M107 To M108 Boundary

M107 is Mobile Approval Renewal UX. It is contract-only, review-only, and
safe-ref-only.

M108 remains future as Mobile Kill Switch + Revocation. M107 must not implement
kill switch execution, revocation execution, approval capture, approval
persistence, approval renewal execution, runtime prompts, native mobile UI,
notification delivery, push triggers, background workers, schedulers, daemons,
device token handling, external services, network sync, raw approval payloads,
backend routes, Control Center controls, dependencies, memory writes, context
injection, execution, broad autonomy, or production authority.
