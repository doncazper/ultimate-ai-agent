# M106 To M107 Boundary

M106 is Mobile Background Read-Only Status Sync. It is contract-only,
read-only, and safe-ref-only.

M107 remains future as Mobile Approval Renewal UX. M106 must not implement
approval renewal UX, approval capture, background collection, background
execution, background workers, scheduler runtime, daemon runtime, OS background
fetch, OS background permission prompts, push triggers, device token handling,
external services, network sync, raw status payloads, backend routes, Control
Center controls, dependencies, memory writes, context injection, execution,
broad autonomy, or production authority.
