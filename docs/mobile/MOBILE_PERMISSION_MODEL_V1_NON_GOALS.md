# Mobile Permission Model v1 Non-Goals

M100 is not a mobile runtime implementation.

Non-goals:

- no mobile sensors.
- no location access.
- no camera access.
- no photos access.
- no microphone access.
- no contacts/calendar/Bluetooth/NFC/biometric/clipboard/local-network/motion
  access.
- no background collection.
- no push execution.
- no runtime permission prompts.
- no native permission request.
- no mobile permission grant route.
- no backend route.
- no dependency.
- no memory write.
- no context injection.
- no execution.
- no raw prompt/provider payload exposure.
- no raw file export.
- no full-file read.
- no credential or cookie handling.
- no production authority.
- no M101 work.

M100 implemented/released Mobile Permission Model v1 as contract-only planning.
Do not start M101 from this milestone.
