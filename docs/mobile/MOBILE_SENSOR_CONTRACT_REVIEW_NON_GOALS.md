# M101 Mobile Sensor Contract Review Non-Goals

M101 does not implement:

- runtime sensor access
- location access
- camera access
- photos access
- microphone access
- motion, Bluetooth, NFC, biometric, clipboard, or local-network access
- native permission prompt
- OS permission request
- background collection
- raw sensor payload
- mobile sensor runtime route
- backend route
- Control Center control
- dependency
- memory write
- context injection
- execution
- production authority
- M102

M101 only defines contract-only review boundaries for future mobile sensor work.
Sensors default off and unknown sensor denied.
