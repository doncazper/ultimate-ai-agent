# M105 To M106 Boundary

M105 is Background Task Contract, No Execution. It is contract-only and
planning-only.

M106 remains future as Mobile Background Read-Only Status Sync. M105 must not
implement M106 status sync, background workers, scheduler runtime, daemon
runtime, OS background permission prompts, push triggers, device token handling,
external services, raw task payloads, backend routes, Control Center controls,
dependencies, memory writes, context injection, execution, broad autonomy, or
production authority.
