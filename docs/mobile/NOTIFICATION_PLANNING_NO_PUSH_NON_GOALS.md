# Notification Planning Non-Goals

M104 does not implement runtime notification capability.

Non-goals:

- no push delivery.
- no notification permission prompt.
- no notification scheduling.
- no background task execution.
- no device token handling.
- no external push provider.
- no raw notification body.
- no backend route.
- no Control Center control.
- no dependency.
- no memory write.
- no context injection.
- no execution.
- no mobile sensor runtime.
- no production authority.
- no M105 implementation.

M104 is a checkpoint milestone, not a product SemVer release. M150 remains the
v1.0.0-alpha target, and beta begins only after later reviewed alpha UI and
product work.
