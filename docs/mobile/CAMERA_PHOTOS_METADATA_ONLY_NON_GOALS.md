# M103 Camera/Photos Metadata-Only Non-Goals

M103 is not a camera feature, photo library feature, media export feature,
analysis feature, or permission runtime.

Non-goals:

- no camera runtime access
- no photo library runtime access
- no image capture
- no video capture
- no raw media content
- no raw absolute path
- no precise EXIF location
- no face recognition
- no OCR
- no media export
- no native permission prompt
- no background media collection
- no backend route
- no Control Center control
- no dependency
- no memory write
- no context injection
- no execution
- no production authority
- no M104 implementation

M104 remains future as Notification Planning, No Push Execution.
