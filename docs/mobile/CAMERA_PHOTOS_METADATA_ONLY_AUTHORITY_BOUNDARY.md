# M103 Camera/Photos Metadata-Only Authority Boundary

M103 does not grant camera/photos authority. It is a contract-only,
metadata-only boundary for future review, with camera and photos remaining off
by default.

The following are not authority:

- approval refs
- approval_test_* refs
- context refs
- memory refs
- model output
- runtime output
- safe media refs
- safe metadata refs
- Control Center refs

M103 adds no camera runtime access, no photo library runtime access, no image
capture, no video capture, no raw media content, no precise EXIF location, no
face recognition, no OCR, no media export, no native permission prompt, no
background media collection, no backend route, no Control Center control, no
dependency, no memory write, no context injection, no execution, and no
production authority. M104 remains future.
