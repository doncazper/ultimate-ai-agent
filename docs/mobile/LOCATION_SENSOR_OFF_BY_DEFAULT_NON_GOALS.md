# M102 Non-Goals

M102 does not implement:

- runtime location access.
- native permission prompt.
- background location.
- raw coordinates.
- location history.
- geofence behavior.
- location export.
- mobile sensor runtime.
- backend route.
- Control Center control.
- dependency.
- memory write.
- context injection.
- execution.
- production authority.
- M103 Camera/Photos Metadata-Only Contract.
