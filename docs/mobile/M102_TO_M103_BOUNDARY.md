# M102 to M103 Boundary

M102 implements Location Sensor, Off by Default as contract-only mobile location
governance. It keeps location disabled by default and defines exact scope,
foreground-only review, consent, revocation, audit, and separate precise-location
approval requirements.

M103 remains future as Camera/Photos Metadata-Only Contract. M102 does not add
camera access, photo access, media reads, raw media export, metadata extraction,
native permission prompts, background collection, backend routes, Control Center
controls, dependencies, execution, or production authority.
