# Mobile Approval Renewal UX Policy

M107 Mobile Approval Renewal UX is contract-only, review-only, and
safe-ref-only. Approval renewal UX records are policy artifacts for future
review, not runtime authority.

The policy requires safe renewal refs, safe renewal copy refs, safe renewal
window refs, safe expiration refs, consent refs, revocation refs, and audit
refs.

The policy denies:

- no approval capture.
- no approval persistence.
- no approval renewal execution.
- no runtime prompt.
- no native mobile UI.
- no backend route.
- no Control Center control.
- no notification delivery.
- no push trigger.
- no background worker.
- no scheduler.
- no daemon.
- no device token handling.
- no external service.
- no network sync.
- no raw approval payload.
- no dependency.
- no memory write.
- no context injection.
- no execution.
- no kill switch execution.
- no production authority.

M108 remains future.
