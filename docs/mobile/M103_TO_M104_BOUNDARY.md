# M103 to M104 Boundary

M103 implements Camera/Photos Metadata-Only Contract as contract-only mobile
media governance. Camera and photos remain off by default. The milestone defines
safe metadata refs, exact scope, consent, revocation, audit, and raw media
denial requirements.

M104 remains future as Notification Planning, No Push Execution. M103 does not
add notification planning, push execution, notification permission prompts,
camera runtime access, photo library runtime access, image capture, video
capture, raw media content, precise EXIF location, face recognition, OCR, media
export, native permission prompts, background media collection, backend routes,
Control Center controls, dependencies, memory writes, context injection,
execution, or production authority.
