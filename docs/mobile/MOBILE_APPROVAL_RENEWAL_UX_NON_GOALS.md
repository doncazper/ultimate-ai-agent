# Mobile Approval Renewal UX Non-Goals

M107 does not implement runtime renewal behavior. It is contract-only,
review-only, and safe-ref-only.

Non-goals:

- no approval capture.
- no approval persistence.
- no approval renewal execution.
- no runtime prompt.
- no native mobile UI.
- no backend route.
- no Control Center control.
- no notification delivery.
- no push trigger.
- no background worker.
- no scheduler.
- no daemon.
- no device token handling.
- no external service.
- no network sync.
- no raw approval payload.
- no dependency.
- no memory write.
- no context injection.
- no execution.
- no kill switch execution.
- no broad autonomy.
- no production authority.

M107 records safe renewal refs, safe renewal copy refs, safe renewal window
refs, safe expiration refs, consent refs, revocation refs, and audit refs only.

M108 remains future.
