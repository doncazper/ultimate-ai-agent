# Mobile Permission Model v1 Privacy Copy

M100 requires privacy copy for every mobile permission taxonomy entry.

Privacy copy must explain the future user-facing reason for a permission without
claiming runtime access. It must stay safe, redacted, and non-authoritative.

Privacy copy requirements:

- describe the permission category.
- state that M100 is contract-only.
- state that sensors remain off.
- state no background collection.
- state no runtime permission prompts.
- state no native permission request.
- avoid secrets, credentials, cookies, raw paths, raw prompts, or raw payloads.

Privacy copy is not consent, not approval authority, not a permission prompt,
and not production authority.

M100 implemented/released privacy-copy requirements only. Do not start M101 from
privacy copy.
