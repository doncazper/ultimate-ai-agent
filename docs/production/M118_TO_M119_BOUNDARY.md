# M118 to M119 Boundary

M118 implements the Deployment Mode Matrix as contract-only, review-only
planning. It may define safe refs and no-effect receipt plans for future
deployment-mode review.

M119 Production Red-Team Harness remains future. M118 must not add red-team
harness runtime, scanner runtime, exploit execution, attack simulation,
deployment execution, release automation, external distribution, infrastructure
provisioning, CI/CD execution, signing or notarization, backend routes, Control
Center controls, dependencies, beta release, or production authority.

The product baseline remains v1.7.2. M118 uses the checkpoint-m118 tag rather
than a product SemVer tag. M150 remains the planned v1.0.0-alpha target.
