# Production Threat Model Non-Goals

Status: Checkpoint M111 non-goals.

M111 is not production authority. It is not a production runtime. It is not
deployment, external distribution, credential handling, network access, model
call authority, memory write authority, context injection authority, execution
authority, tool execution, shell execution, browser automation, plugin
execution, mobile sensor access, background worker activation, remote
execution, backend route work, Control Center control work, dependency work, or
beta release work.

M111 does not add raw prompt exposure, raw provider payload exposure, raw file
export, full-file reads, arbitrary filesystem browsing, credential/cookie
handling, authenticated network action, production persistence, or production
authority.

M112 remains future.
