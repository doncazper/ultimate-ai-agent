# Role-Based Authority Non-Goals

Checkpoint M116 does not implement runtime RBAC or permission enforcement. It
does not create users, accounts, sessions, OAuth flows, tokens, credentials,
account connectors, account actions, role assignment APIs, backend routes, or
Control Center controls.

M116 explicitly excludes production authority, production runtime, authority
runtime, role enforcement, permission enforcement, auth runtime, login, session
cookie handling, OAuth flow, token exchange, credential handling, account
action, network access, model call, memory write, context injection, execution,
tool execution, shell execution, browser automation, plugin execution, mobile
sensor access, background workers, remote execution, dependencies, beta
release, and M117 implementation.

M117 remains future as Remote Agent Coordination Contract. M150 remains the
planned v1.0.0-alpha target, and beta begins only after alpha UI and supporting
safety/product work are reviewed and promoted.
