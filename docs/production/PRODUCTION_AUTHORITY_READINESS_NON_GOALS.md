# Production Authority Readiness Non-Goals

M120 is not a production launch milestone. It is not production authority,
production runtime, go-live, production deployment, external distribution,
traffic routing, credential handling, network access, account action, model
call, memory write, context injection, execution, tool execution, shell
execution, browser automation, plugin execution, mobile sensor access, backend
route work, Control Center control work, dependency work, beta release work, or
production authority.

M120 does not approve deployment, route traffic, execute rollback, collect
credentials, call providers, call models, run scanners, run external probes,
write memory, inject context, export data, add routes, add controls, add
dependencies, or implement M121.

All references remain safe refs. The Production Authority Readiness Review is
actor-bound, baseline-bound, source-production-red-team-harness-bound,
user-bound, workspace-bound, audit-bound, replay-bound, and no-effect receipt
plan-bound.

M121 remains future. M150 remains the planned v1.2.0-alpha target.
