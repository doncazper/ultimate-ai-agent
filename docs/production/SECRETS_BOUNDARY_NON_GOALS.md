# M113 Secrets Boundary Non-Goals

M113 does not implement a credential vault. It does not implement auth,
accounts, sessions, credential handling, credential storage, credential read,
credential write, secret material access, secret export, vault runtime, account
connectors, production runtime, production authority, network access, model
calls, memory writes, context injection, execution, tool execution, shell
execution, browser automation, plugin execution, mobile sensors, background
workers, remote execution, backend routes, Control Center controls,
dependencies, beta release, or broad autonomy.

M113 does not implement M114. Account Connector Contract Review remains future.
M150 remains v1.0.0-alpha.
