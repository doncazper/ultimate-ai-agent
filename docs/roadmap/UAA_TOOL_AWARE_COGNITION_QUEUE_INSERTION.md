  final candidate.

## Authority Boundary

model call, provider call, web fetch, browser action, connector write, shell
execution, plugin/skill activation, credential change, spending, production
authority, or policy/approval bypass.

The local model remains UAA's language and reasoning engine. The program adds
governed context selection, calibrated evidence, and evaluation around it; it
does not replace or retrain it.
