# Authless Network Tool Expansion Non-Goals

M95 Network Tool Expansion, Authless Only does not implement unrestricted network tools, authenticated network access, credentials, cookies, credential headers, request body, POST, PUT, PATCH, DELETE, account action, private network, download, export, browser form, provider model call, shell execution, plugin execution, memory write, context injection, backend route, Control Center control, dependency, production authority, recurring automation, external plugin execution, mobile permission runtime, or broad autonomy.

M95 does not create a production network runtime and does not make network output authoritative. It does not add a browser form flow, account mutation, provider call, or public network API.

M96 remains future.
