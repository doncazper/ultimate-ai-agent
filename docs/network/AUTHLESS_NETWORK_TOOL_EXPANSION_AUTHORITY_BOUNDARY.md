# Authless Network Tool Expansion Authority Boundary

M95 adds Network Tool Expansion, Authless Only as a bounded proposal contract. Approval refs remain identifiers only; approval_test_* is never runtime authority. Model, memory, context, tool-intent, task-plan, runtime, and OpenWebUI refs cannot authorize network authority.

The only allowed shape is exact scope, authless, read-only, allowlisted domain, HTTPS, GET only, redirect controls, bounded output, redaction, audit, revocation, and transport injection. Evaluator boundaries revalidate safety-critical fields, including model_copy-mutated fields.

Review or approval metadata does not grant credentials, cookies, credential headers, request body, POST, PUT, PATCH, DELETE, account action, private network, download, export, browser form, provider model call, shell execution, plugin execution, memory write, context injection, backend route, Control Center control, dependency, production authority, or broad autonomy. M96 remains future.
