# Cross-Tool Dependency Execution Non-Goals

M136 is not a tool executor, dependency runner, workflow runtime, connector
runtime, browser runtime, scheduler, background worker, or recovery executor.

Non-goals include dependency execution, dependency resolver runtime, cross-tool
runtime, parallel tool execution, tool state handoff, tool output routing,
browser action, connector write, account auth, recovery execution, supervisor
runtime, checkpoint scheduling, prompt delivery, scheduler startup, background
worker startup, shell execution, network access, plugin execution, model call,
memory write, context injection, backend routes, Control Center controls,
dependency changes, beta release, production authority, and M137 work.
