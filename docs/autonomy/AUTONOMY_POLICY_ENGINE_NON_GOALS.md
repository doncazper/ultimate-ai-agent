# Autonomy Policy Engine Non-Goals

M63 does not activate autonomy policy. M63 does not start sessions. M63 does not
enable autonomous actions, background worker behavior, execution, tool
execution, shell execution, network tools, browser automation, plugin
execution, mobile sensor access, remote execution, memory writes, context
injection, model/provider calls as authority, backend route additions, Control
Center controls, dependencies, or production authority.

M63 review decisions are safe summaries and reason codes only. Approval refs
are identifiers, not authority. Policy rules are contract-only, review-only,
actor-bound, resource-bound, capability-bound, allowlist-bound, risk-ceiling
bounded, duration-ceiling bounded, revocable, and audit/replay backed.

Skill Package Security Rule remains in force. M64 remains future.
