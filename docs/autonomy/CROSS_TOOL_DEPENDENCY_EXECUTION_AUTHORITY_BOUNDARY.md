# Cross-Tool Dependency Execution Authority Boundary

M136 can validate declared safe dependency refs, acyclic dependency edge refs,
and deterministic dependency order refs for review.

M136 cannot execute dependencies, run tools, start a dependency resolver, start
a cross-tool runtime, perform parallel tool execution, hand off tool state, route
tool output, perform recovery, start a supervisor, schedule checkpoints, prompt
humans, start schedulers or background workers, mutate files, access networks,
automate browsers, execute plugins, run connectors, authenticate accounts, use
mobile sensors, perform remote execution, call models or providers, write
memory, inject context, add backend routes, add Control Center controls, add
dependencies, release beta, grant production authority, or implement M137.
