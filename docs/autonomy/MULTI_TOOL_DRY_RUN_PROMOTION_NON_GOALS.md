# Multi-Tool Dry-Run Promotion Non-Goals

M93 does not implement real-run execution. It does not implement broad autonomous tool execution, recurring automation, arbitrary shell, unrestricted network, browser forms, browser purchases, browser downloads, authentication, external plugins, credential handling, raw file export, full-file reads, automatic context injection, memory writes, or production authority.

M93 does not add backend routes, Control Center controls, dependencies, runtime workers, or background workers.

M93 does not make approval refs authority. Exact promotion approval is required, approval_test_ is denied, and wildcard approval denied remains part of the contract.

M94 remains future and may address Autonomous Browser Clicks, Low-Risk Only only after M93 is reviewed Green.
