# Autonomous Plan Simulator Non-Goals

M64 is not an autonomous execution milestone.

M64 does not add:

- policy activation.
- session start.
- autonomous actions.
- background worker.
- execution.
- tool execution.
- shell execution.
- network tools.
- browser automation.
- plugin execution.
- mobile sensor access.
- remote execution.
- context injection.
- memory write.
- model/provider calls as authority.
- backend route.
- Control Center control.
- dependency.
- production authority.
- M65 implementation.

The simulator is contract-only, review-only, dry-run-only, and deterministic.
It validates a safe dependency graph and produces safe review records only.
M65 remains future.
