# M62 To M63 Boundary

Status: M62 / v0.66.0 implemented-released boundary.

M62 implements Scoped Autonomy Session Contracts as contract-only review
records. The contracts capture actor, scope, resource, capability, allowlist,
duration, risk, revocation, audit, and replay refs. They are disabled by
default and dry-run first.

M62 does not start or activate autonomy sessions. M62 adds no autonomous
actions, no background worker, no execution, no tool execution, no shell
execution, no network tools, no browser automation, no plugin execution, no
mobile sensor access, no remote execution, no memory write, no context
injection, no model/provider authority, no backend route, no Control Center
control, no dependency, and no production authority.

M63 remains future and may define Autonomy Policy Engine v1 only after M62 is
accepted Green.
