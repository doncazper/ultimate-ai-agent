# Autonomy v1 Safety Freeze Non-Goals

M99 does not add broad unsandboxed autonomy.

M99 does not add a global autonomy switch.

M99 does not add production authority.

M99 does not add shell execution, arbitrary shell commands, broader subprocess
execution, browser action, browser form submission, network mutation, plugin
execution, scheduler behavior, background worker behavior, mobile sensor
behavior, memory write behavior, context injection, raw prompt/provider payload
exposure, raw file export, full-file read, backend route, Control Center
control, dependency, or M100 work.

M99 is freeze-only and review-only. M100 remains future.
