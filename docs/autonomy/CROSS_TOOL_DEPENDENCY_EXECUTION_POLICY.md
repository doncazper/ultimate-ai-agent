scope, Mode 5, M135 recovery planner, M134 human checkpoint, M133 supervisor,

tool refs, dry-run plan, human checkpoint, audit, replay, revocation,
kill-switch, and no-effect receipt bindings.

runtime, parallel tool execution, tool state handoff, tool output routing,
recovery execution, supervisor runtime, checkpoint scheduler, prompt runtime,
schedulers, background workers, autonomous actions, execution, tool execution,
shell execution, network access, browser automation, plugin execution,
connector runtime, account auth, model call, memory write, context injection,
backend route, Control Center control, dependency, beta release, and production
authority.
