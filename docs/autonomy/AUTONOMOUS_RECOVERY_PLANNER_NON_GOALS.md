# Autonomous Recovery Planner Non-Goals

M135 is not a recovery runtime. It does not execute recovery steps, retry failed
work, resume sessions, roll back changes, start a supervisor runtime, schedule
checkpoints, prompt humans, deliver notifications, run schedulers, or start
background workers.

M135 also does not add autonomous actions, execution, tool execution, shell
execution, command execution, subprocess execution, filesystem mutation, network
access, browser automation, plugin execution, connector runtime, account auth,
mobile sensor runtime, remote execution, model calls, memory writes, context
injection, backend routes, Control Center controls, dependencies, beta release,
or production authority.

M136 remains future Cross-Tool Dependency Execution work.
