# M139 Authority Boundary

M139 may validate declared safe refs for abuse signals, loop signals, pattern
policies, threshold policies, intervention plans, escalation plans, human
checkpoints, risk decisions, audit, replay, revocation, kill-switch, and
no-effect receipts.

M139 cannot start an abuse detection runtime, start a loop detection runtime,
start a loop monitor, start detector runtime, perform loop intervention,
execute recovery, execute retry, execute rollback, execute resume, execute
dependencies, perform browser actions, perform connector actions, perform
connector writes, authenticate accounts, run tools, execute shell commands,
access networks, execute plugins, call models, write memory, inject context,
add backend routes, add Control Center controls, add dependencies, release
beta, or grant production authority.

Any request for those capabilities must be denied and deferred to a later
reviewed milestone.
