# M137 to M138 Boundary

M137 ends at deterministic, local, safe-ref-only combined browser and connector
workflow review contracts. It may declare browser plan refs, connector plan
refs, dependency order refs, approval bundle refs, audit refs, replay refs,
revocation refs, kill-switch refs, and no-effect receipt refs.

M138 remains future Autonomous Error Handling Guardrails work. M137 does not
add error handling guardrail runtime, autonomous recovery execution, retry
execution, rollback execution, browser action execution, connector action
execution, tool execution, scheduler, background worker, backend route, Control
Center control, dependency, beta release, or production authority.
