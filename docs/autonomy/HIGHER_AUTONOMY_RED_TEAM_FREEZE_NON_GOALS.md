# M140 Non-Goals

M140 does not implement:

- red-team runtime
- red-team harness execution
- adversarial test execution
- autonomous execution
- broad autonomy or a global autonomy switch
- tool, shell, browser, connector, network, plugin, model, memory, or context authority
- background workers, schedulers, mobile sensors, or remote execution
- raw prompt or provider payload exposure
- credential or cookie access
- backend routes or Control Center controls
- dependencies, alpha release, beta release, or production authority

M141 remains future Multi-User Product Boundary work.
