# Trusted Recurring Workflow Non-Goals

M132 does not implement a recurring workflow runtime.

M132 does not implement M133, Long-Running Task Supervisor, schedulers,
background workers, daemons, OS background tasks, workflow start, recurrence
activation, autonomous actions, execution, tool execution, shell execution,
network access, browser automation, plugin execution, connector runtime,
account auth, mobile sensor access, remote execution, model calls, memory
writes, context injection, backend routes, Control Center controls,
dependencies, beta release, or production authority.
