# M140 Authority Boundary

M140 may validate declared safe refs for accepted M131-M139 checkpoints,
red-team checklists, audit, replay, revocation, kill-switch, and no-effect
receipts.

M140 cannot start a red-team runtime, execute a red-team harness, run
adversarial tests, execute autonomous work, grant broad autonomy, enable a
global autonomy switch, execute tools, execute shell commands, perform browser
actions, perform connector actions, access networks, execute plugins, start
background workers, start schedulers, access mobile sensors, perform remote
execution, call models, write memory, inject context, expose raw prompt or
provider payloads, access credentials or cookies, add backend routes, add
Control Center controls, add dependencies, release alpha, release beta, or
grant production authority.

Any request for those capabilities must be denied and deferred to a later
reviewed milestone.
