# Autonomy Foundation Freeze Non-Goals

M70 does not add:

- policy activation
- session start
- low-risk dry-run execution
- autonomous actions
- background worker
- execution
- tool execution
- shell execution
- network tool
- browser automation
- plugin execution
- mobile sensor access
- remote execution
- memory write
- context injection
- model/provider call
- backend route
- Control Center control
- dependency
- production authority
- M71 implementation

The Autonomy Foundation Freeze is contract-only, review-only, freeze-only, and
deterministic. It is an auditable safety checkpoint for M61-M69, not a runtime
autonomy switch.

M71 remains future.
