# Autonomy Mode 4 Scoped Work Session Non-Goals

M131 does not add runtime autonomy. It does not start sessions, activate scoped
autonomy windows, execute tools, execute shell or subprocesses, perform network
access, control browsers, submit forms, use authenticated browser profiles,
download or upload files, execute plugins, run connector runtime actions, access
accounts, use mobile sensors, perform remote execution, run background workers,
schedule jobs, call models, write memory, inject context, add backend routes,
add Control Center controls, add dependencies, release beta, or grant production
authority.

M131 does not implement M132, Autonomy Mode 5, trusted recurring workflows,
long-running supervision, recurring automation runtime, broader autonomy, or
production authority.
