# M138 Authority Boundary

M138 may validate declared safe refs for error signals, guardrail policies,
retry policies, fallback policies, escalation policies, recovery plans,
rollback plans, resume plans, human checkpoints, risk decisions, audit, replay,
revocation, kill-switch, and no-effect receipts.

M138 cannot start an error handling runtime, start an error guardrail runtime,
execute recovery, execute a retry, execute rollback, execute resume, perform a
fallback action, perform an escalation action, perform loop recovery, execute
dependencies, perform browser actions, perform connector actions, perform
connector writes, authenticate accounts, run tools, execute shell commands,
access networks, execute plugins, call models, write memory, inject context,
add backend routes, add Control Center controls, add dependencies, release
beta, or grant production authority.

Any request for those capabilities must be denied and deferred to a later
reviewed milestone.
