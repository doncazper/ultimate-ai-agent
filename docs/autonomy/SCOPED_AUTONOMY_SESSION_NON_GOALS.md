# Scoped Autonomy Session Non-Goals

Status: M62 / v0.66.0 implemented-released non-goals.

M62 does not implement runtime autonomy. It does not start sessions, activate
sessions, execute actions, execute tools, run shell commands, use network tools,
automate browsers, enable plugins, access mobile sensors, perform remote
execution, run background workers, write memory, inject context, call
model/providers as authority, add backend routes, add Control Center controls,
add dependencies, or grant production authority.

M62 does not implement M63 Autonomy Policy Engine v1.
