# Low-Risk Tool Autonomy Single-Session Non-Goals

M92 is not a runtime autonomy feature. It is a contract/review milestone only.

M92 explicitly does not add:

- real tool execution
- autonomous execution
- session start
- additional session
- multi-tool real runs
- command execution
- shell execution
- subprocess execution
- filesystem mutation
- network access
- browser automation
- plugin execution
- remote execution
- model call
- memory write
- context injection
- background worker
- backend route
- Control Center control
- dependency
- production authority
- raw tool payload storage
- raw provider payload storage

M93 remains future and must not be inferred from M92 metadata.
