# Autonomy Mode 4 Scoped Work Session Policy

The M131 policy requires:

- contract-only review
- review-only decisions
- scoped-work-session-only records
- deterministic local validation
- safe-ref-only and safe-summary-only data
- exact scope, actor, resource, capability, allowlist, and duration bindings
- policy decision refs, approval bundle refs, and risk decision refs
- audit refs, replay refs, revocation refs, and kill-switch refs
- no-effect receipt plan refs
- M132 remains future

The policy denies session start, active scoped autonomy windows, autonomous
actions, execution, tool execution, shell execution, command execution,
subprocess execution, filesystem mutation, network access, browser automation,
browser forms, authenticated browser access, download, upload, plugin
execution, connector runtime, account auth, mobile sensor access, remote
execution, background workers, schedulers, model calls, memory writes, context
injection, backend routes, Control Center controls, dependencies, beta release,
production authority, and trusted recurring workflows.
