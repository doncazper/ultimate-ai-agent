plan refs, failure signal refs, recovery trigger refs, recovery strategy refs,
recovery step refs, rollback plan refs, resume plan refs, human checkpoint refs,
audit refs, replay refs, revocation refs, kill-switch refs, and no-effect
receipt refs.

M136 remains future Cross-Tool Dependency Execution work. M135 must not add
cross-tool dependency execution, cross-tool runtime coordination, recovery
execution, retry execution, resume execution, rollback execution, autonomous
actions, tool execution, shell execution, browser automation, connector
runtime, backend routes, Control Center controls, dependencies, beta release,
or production authority.
