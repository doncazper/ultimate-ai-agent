# M137 Authority Boundary

M137 may validate declared safe browser refs, safe connector refs, safe
workflow step refs, safe dependency graph refs, safe dependency order refs,
safe handoff refs, approval bundle refs, human checkpoint refs, audit refs,
replay refs, revocation refs, kill-switch refs, and no-effect receipt refs.

M137 cannot start a combined workflow runtime, navigate a browser, click a
browser page, submit a browser form, download, upload, use an authenticated
browser profile, start connector runtime, perform connector reads, perform
connector writes, send connector messages, delete connector records, authorize
accounts, execute dependencies, run tools, execute shell commands, access
networks, execute plugins, call models, write memory, inject context, add
backend routes, add Control Center controls, add dependencies, release beta, or
grant production authority.

Any request for those capabilities must be denied and deferred to a later
reviewed milestone.
