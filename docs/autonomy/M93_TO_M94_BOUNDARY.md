# M93 to M94 Boundary

M93 implements Multi-Tool Dry-Run to Real Run Promotion as review-only contracts. It requires dry-run and real-run equivalence, plan hash binding, exact promotion approval, exact M92 binding, safe refs only, safe summary only, and evaluator boundaries revalidate safety-critical fields.

M93 adds no unapproved real execution, no real-run execution, no tool execution, no autonomous execution, no session start, no command execution, no shell execution, no subprocess execution, no filesystem mutation, no network access, no browser click, no browser form, no plugin execution, no remote execution, no model call, no memory write, no context injection, no background worker, no backend route, no Control Center control, no dependency, and no production authority.

M94 remains future. M94 may define low-risk autonomous browser clicks only after M93 is accepted Green, and it must keep forms, typing, purchases, downloads, auth, account changes, destructive actions, credentials, and cookies blocked.
