# M140 Policy

The M140 policy is contract-only, review-only, freeze-only, deterministic,
local-only, safe-ref-only, and higher-autonomy-red-team-freeze-only. It
requires exact M131-M139 coverage, red-team checklist refs, audit, replay,
revocation, kill-switch, and no-effect receipt bindings.

The policy denies red-team runtime, red-team harness execution, adversarial
test execution, autonomous execution, broad autonomy, global autonomy switch,
execution, tool execution, shell execution, browser action, connector action,
network access, plugin execution, background worker, scheduler, mobile sensor,
remote execution, model call, memory write, context injection, raw prompt or
provider payload exposure, credential or cookie access, backend route, Control
Center control, dependency, alpha release, beta release, and production
authority.

M141 remains future.
