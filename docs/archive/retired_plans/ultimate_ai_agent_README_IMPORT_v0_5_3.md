# Import Guide v0.5.3

Status: Active pre-coding baseline after Claude review cleanup.

## What changed from v0.5.2

v0.5.3 resolves verified review issues without expanding into feature implementation.

It adds:

- Verified Task Completion Framework.
- Durable execution decision: custom event ledger + deterministic state machine first.
- Event-level cost attribution.
- Credentials, Secret Broker, Provider Registry, and normalized provider envelopes.
- Memory retrieval V1 with pgvector + full-text + reranking.
- Autonomy levels and standing approvals.
- Minimum Lovable Kernel.
- Provisional contract versioning policy.
- Trusted Computing Base.
- Filled-out foundation docs that were previously template-like.
