# Checkpoint M135 Import Notes

Checkpoint M135 implements Autonomous Recovery Planner as a pre-alpha
checkpoint milestone. It is not a product SemVer tag.

Import scope is limited to contract files, tests, docs, verifier wiring, and
Foundation Gate criteria for safe recovery planning records.

No runtime recovery, retry, resume, rollback, scheduler, background worker,
tool, shell, browser, network, plugin, connector, mobile, remote, model,
memory, context, backend, Control Center, dependency, beta, or production
authority is imported by this checkpoint.
