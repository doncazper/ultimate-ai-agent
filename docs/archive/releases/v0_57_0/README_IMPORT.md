# v0.57.0 README Import

v0.57.0 implements M53 Controlled Tool Expansion Review.

The release adds deterministic local review-only contracts for future tool
expansion candidates. Safe metadata review candidates can become review-ready;
effectful candidates are classified as requiring a future reviewed milestone;
unknown candidates are denied. Receipt plans record no execution, no tool
enablement, and no side effects.

It adds no shell/subprocess execution, unrestricted network tool, provider
model call, browser automation execution, plugin enablement, mobile sensor
access, remote execution, raw file browsing/export, full-file read, file
mutation, memory write, context injection, credentials/cookie handling runtime,
external SaaS/analytics SDK, backend route, Control Center control, dependency,
production authority, or M54 implementation.

M54 remains future.
