# v0.34.0 README Import

Status: historical release artifact.

v0.34.0 implements M30 — Multi-Step Execution Framework.

It adds deterministic local execution-state-machine contracts for no-effect
run and step advancement, dependency-aware progression, replay protection,
evaluator revalidation, transition decisions, and non-authoritative receipt
plans.

It adds no real task execution, action execution, tool execution,
scheduler/background worker, autonomous loop, shell execution, file mutation,
memory write, Event Ledger mutation, network call, model/provider call,
browser/mobile/remote/plugin execution, backend execution route, Control Center
execute control, dependency, context injection, production authority, or M31
implementation.

M31-M40 remain planned/provisional.
