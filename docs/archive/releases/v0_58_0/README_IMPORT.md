# v0.58.0 README Import

v0.58.0 implements M54 Safe Media Metadata Inspector.

The release adds metadata-only contracts for declared safe media metadata,
policy validation, request/decision/receipt-plan models, tests, docs,
documentation-integrity checks, static verification, and Foundation Gate
coverage.

It adds no raw media export, raw media storage, full-file reads, file mutation,
original overwrite, OCIO transform, AI gamut expansion, model/provider calls,
context injection, memory writes, backend routes, Control Center controls,
dependencies, production authority, or M55 implementation.

M55 remains future.
