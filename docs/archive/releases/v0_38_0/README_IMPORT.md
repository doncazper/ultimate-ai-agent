## Summary

v0.38.0 implements M34 Broader File Capability Review as planning,
architecture review, documentation, verifier, and Foundation Gate work only. It
adds the active file capability review docs, boundary matrix, risk register,
decision record, M35 readiness guidance, M34-to-M35 boundary, documentation
integrity checks, static verifier checks, and Foundation Gate coverage.

It adds no runtime file capability, raw file reads, file review UI, approval
persistence, context proposal, context injection, memory writes, export,
execution, backend routes, dependencies, M35 implementation, or production
authority.
