# README Import - v0.67.0

v0.67.0 implements M63 Autonomy Policy Engine v1.

This release adds contract-only and review-only autonomy policy engine
contracts. Policy rules are actor-bound, resource-bound, capability-bound,
allowlist-bound, risk ceiling bounded, duration ceiling bounded, revocation
aware, and audit/replay backed.

Approval refs are identifiers and do not grant authority. v0.67.0 adds no
policy activation, no session start, no autonomous actions, no background
worker, no execution, no tool execution, no shell execution, no network tools,
no browser automation, no backend route, no dependency, and no production
authority. M64 remains future.

Skill Package Security Rule remains in force.
