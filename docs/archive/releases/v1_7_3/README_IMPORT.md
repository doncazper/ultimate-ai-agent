# v1.7.3 README Import

v1.7.3 is a maintenance-only hardening baseline over the accepted M150 tree.

It updates the local/dev file manager to use streaming content hashes, bounded
preview reads with redaction lookahead, atomic rollback writes, and cleanup for
temporary write files when replacement fails.

M150 remains the Ultimate AI Agent v1.0.0-alpha target acceptance packet.
Already-pushed tags remain immutable historical internal milestone tags. Beta
begins only after the alpha UI and supporting safety/product work are reviewed,
accepted, and explicitly promoted by a later roadmap patch.

This release adds no capability implementation, M151 work, backend route,
Control Center control, dependency, shell/subprocess execution, network access,
model/provider call, runtime tool/browser/plugin/mobile/remote authority,
memory write, context injection, broad autonomy, beta release, or production
authority.
