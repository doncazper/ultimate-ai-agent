# v1.2.0 README Import

v1.2.0 implements M98 Scoped Recurring Low-Risk Automation as scoped low-risk
read-only recurrence contracts.

M98 requires strict cadence, approval renewal required, renewal expiry, stop
conditions required, audit trail, revocation, kill switch, safe refs only, no
secret access, evaluator revalidation, tests, static verification, and
Foundation Gate coverage.

It adds no scheduler, background worker, recurring execution runtime, mutating
tasks, credential or account actions, shell write, network write, browser write,
silent background collection, memory write, context injection, export, backend
route, dependency, M99 work, broad autonomy, or production authority.

M99 remains future.
