Current active baseline: **v0.85.0**

deterministic, local-only runtime sandbox spec contracts with prior milestone
refs, boundary refs, threat model refs, audit requirement refs, stable reason
codes, documentation-integrity checks, static verification, tests, and
Foundation Gate coverage.

subprocess execution, shell execution, process spawn, filesystem mutation,
network access, tool execution, browser automation, plugin execution, remote
execution, model call, memory write, context injection, background worker,
backend route, Control Center control, dependency, M82 work, or production
authority.
