# v0.34.1 README Import

Status: historical release artifact.

v0.34.1 hardens M30 — Multi-Step Execution Framework.

It strengthens deterministic local execution-state-machine contracts for
no-effect run and step advancement. It requires ready-only no-effect step
completion, denies incomplete run finalization, blocks replay-key and
transition-id reuse, rejects hidden side-effect metadata, revalidates
safety-critical transition fields at evaluator boundaries, and preserves
non-authoritative receipt plans.

It adds no real task execution, action execution, tool execution,
scheduler/background worker, autonomous loop, shell execution, file mutation,
memory write, Event Ledger mutation, network call, model/provider call,
browser/mobile/remote/plugin execution, backend execution route, Control Center
execute control, dependency, context injection, production authority, or M31
implementation.

M31-M40 remain planned/provisional.
