# v1.7.0 Master Plan

Milestone: M103 Camera/Photos Metadata-Only Contract.

Scope:

- Add contract-only camera/photos metadata-only policy and metadata contracts.
- Keep camera and photos off by default.
- Require safe media refs, safe metadata refs, raw-media denial, consent,
  revocation, and audit.
- Add tests, docs, static verification, documentation-integrity checks, and
  Foundation Gate coverage.

Non-goals:

- no camera runtime access.
- no photo library runtime access.
- no image capture.
- no video capture.
- no raw media content.
- no precise EXIF location.
- no face recognition.
- no OCR.
- no media export.
- no native permission prompt.
- no background media collection.
- no backend route.
- no Control Center control.
- no dependency.
- no memory write.
- no context injection.
- no execution.
- no M104 work.
- no production authority.
