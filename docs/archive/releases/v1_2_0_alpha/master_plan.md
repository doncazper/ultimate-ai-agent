# v1.2.0-alpha Master Plan

Release: v1.2.0-alpha / M150 - Ultimate AI Agent Alpha and Orchestration
Efficiency Layer.

The active package baseline and alpha target are aligned at v1.2.0-alpha.

This packet adds the contract-only Orchestration Efficiency Layer:

- strict Pydantic contracts and JSON Schemas for route optimization, cache
  planning, fallback planning, preview decisions, and redacted metric summaries.
- deterministic no-effect preview scoring after existing hard Model Router,
  Cost Governor, Context Budget, privacy, approval, and capability filters.
- compatibility metadata for cost mode, fallback, verifier, trace/correlation,
  cache, runtime, and observability estimates.
- focused tests for scoring, hard-filter precedence, cache invalidation,
  fallback planning, unknown-cost approval, critical verifier planning, schema
  closure, redaction, and static no-runtime-import safety.

No runtime orchestration dependency, provider/model call, network access,
browser automation, shell/subprocess execution, backend route, Control Center
control, runtime tool authority, memory write, context injection, beta release,
or production authority is added.
