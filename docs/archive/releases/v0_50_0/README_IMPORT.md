# v0.50.0 README Import

Status: Archived release packet for v0.50.0.

v0.50.0 implements M46 - iOS Review/Receipt Read-Only Surfaces.

It adds source-only, read-only, redacted summary CCC iOS review/receipt
surfaces for mock non-authoritative review packet and receipt data. The surfaces
display review/receipt summaries and authority-boundary copy only.

It adds no runtime network call, backend route, approval capture, approval
execution, raw data, context injection, memory write, file mutation, export,
execution, background collection, mobile sensor access, credential handling,
cookie handling, Xcode project, Swift package, signing workflow, TestFlight
pipeline, dependency, production authority, or M47 implementation.

M47 remains future.
