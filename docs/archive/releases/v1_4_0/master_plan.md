# v1.4.0 Master Plan

Release: v1.4.0 / M100 - Mobile Permission Model v1.

Scope:

- contract-only mobile permission taxonomy.
- consent model.
- revocation model.
- privacy copy.
- permission audit.
- docs, tests, static verifier, documentation verifier, and Foundation Gate
  coverage.

Non-goals:

- no mobile sensors.
- no runtime permission prompts.
- no native permission request.
- no background collection.
- no push execution.
- no backend route.
- no dependency.
- no production authority.
- no M101 work.

M100 is the final milestone in the active M61-M100 conveyor. Do not start M101.
