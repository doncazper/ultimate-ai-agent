# v1.4.0 README Import

v1.4.0 implements M100 Mobile Permission Model v1 as contract-only mobile
permission planning.

M100 defines a permission taxonomy, consent and revocation model, privacy copy,
permission audit contracts, tests, documentation-integrity checks, static
verification, and Foundation Gate coverage.

It keeps sensors off and adds no runtime permission prompts, no native
permission request, no mobile sensor access, no background collection, no push
execution, no backend route, no dependency, no M101 work, and no production
authority.

Do not start M101 from v1.4.0. Post-M100 roadmap promotion requires a separate
reviewed prompt.
