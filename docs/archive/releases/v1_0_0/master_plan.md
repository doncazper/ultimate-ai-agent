# v1.0.0 Master Plan

Milestone: M96 — Plugin Execution Sandbox, No External Plugins.

Scope:

- built-in test plugin sandbox contract
- exact plugin/action/permission binding
- prior plugin review binding
- manifest permission checks
- audit receipt
- revocation binding
- deterministic safe output ref
- tests, docs, static verifier, documentation verifier, and Foundation Gate coverage

Non-goals:

- no external plugin loading
- no marketplace plugin
- no arbitrary plugin code
- no runtime import
- no networked plugin fetch
- no plugin secret access
- no raw plugin payload
- no shell execution
- no network access
- no browser automation
- no filesystem mutation
- no model provider call
- no memory write
- no context injection
- no backend route
- no Control Center control
- no dependency
- no recurring automation
- no M97 work
- no production authority
