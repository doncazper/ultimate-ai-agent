# v1.0.0 README Import

v1.0.0 implements M96 Plugin Execution Sandbox, No External Plugins.

The release adds the first sandboxed plugin execution contract for a built-in test plugin only. It remains safe refs only, manifest-permission enforced, audit-receipted, revocation-bound, deterministic, route-free, dependency-free, and production-authority-free.

M97 remains future.
