# README Import - v1.5.0

Current active baseline: **v1.5.0**

v1.5.0 implements M101 - Mobile Sensor Contract Review. It defines contract-only
sensor capability classes, permission-state contracts, sensor risk
classification, consent, revocation, and audit requirements.

Sensors default off and unknown sensor classes are denied. M102 remains future.

This release adds no runtime sensor access, no native permission prompt, no
background collection, no raw sensor payload, no backend route, no Control
Center control, no dependency, no memory write, no context injection, no
execution, no M102 implementation, and no production authority.
