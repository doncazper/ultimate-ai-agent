# v0.60.0 README Import

v0.60.0 implements M56 Agent Eval Regression Harness.

The release adds deterministic, contract-only, local eval regression models,
policy validation, safe case/suite/observation/report generation, no-effect
receipt plans, tests, docs, documentation-integrity checks, static verification,
and Foundation Gate coverage.

It adds no model/provider calls, tool execution, shell execution, browser
automation, network access, memory writes, context injection, raw prompt
capture, raw provider payload capture, external dataset fetch, backend routes,
Control Center controls, dependencies, production authority, or M57
implementation.

M57 remains future.
