# v1.1.0 README Import

v1.1.0 implements M97 Recurring Automation Contracts as contract-only,
disabled-by-default planning metadata.

M97 requires approval renewal, expiration, stop conditions, audit, revocation,
safe refs, evaluator revalidation, tests, static verification, documentation,
and Foundation Gate coverage.

It adds no recurrence runtime, background execution, cron, daemon, scheduler,
side effects, backend route, dependency, broad autonomy, production authority,
or M98 work.

M98 remains future.
