# v0.52.0 README Import

v0.52.0 implements M48 First Internal TestFlight Build.

The release adds a reviewed internal-only, review-only TestFlight build
candidate contract. It records safe refs for the build candidate, M47 pipeline
manifest, source snapshot, and redacted audit receipt plan without committing
build artifacts, storing signing material, calling App Store Connect, or
uploading to TestFlight.

No committed build artifact, IPA, Xcode archive, signing material, App Store
Connect API call, TestFlight upload, Fastlane lane, CI upload workflow,
external beta, public distribution, mobile approval capture, approval
execution, mobile sensor access, background collection, context injection,
memory write, raw data export, export, execution, dependency, production
authority, or M49 implementation is added.

M49 remains future.
