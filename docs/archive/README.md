# Documentation Archive

Status: active archive index
Current through: v0.29.5
Purpose: Explain where historical docs live and how to interpret them.

Historical docs live here. Archive docs are not the current source of truth and
must not be used as the active roadmap or active baseline.

Use these active docs for current work:

```text
docs/README.md
docs/DOCUMENTATION_INDEX.md
docs/canonical/09_roadmap.md
docs/canonical/CANONICAL_DOC_MAP.md
```

Git tags and release history preserve exact historical snapshots. Archive files
may contain old baseline labels because they are historical artifacts captured
at earlier releases.

