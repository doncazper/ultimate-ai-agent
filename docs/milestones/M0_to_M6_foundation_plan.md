# M0-M6 Foundation Plan

Status: Active, v0.4.1

## Goal

Build the stable foundation required before higher-order modules can be implemented.

## Milestones

```text
M0 Project Foundation
M1 Kernel Contracts and Event Ledger V1
M2 Consent, Permissions, and User Control Shell V1
M3 Memory and File Foundation V1
M4 Tool Broker and Capability Registry V1
M5 Orchestrator and Spec SDLC Engine V1
M6 Contract Tests, Shadow Mode, and Eval Baseline V1
```

## Foundation Gate exit criteria

- [ ] Execution Contract schema tested.
- [ ] Context Pack schema tested.
- [ ] Run/Event Ledger records traceable events.
- [ ] Memory Service writes and recalls source-linked memories.
- [ ] File Manager creates diffs and patches safely.
- [ ] Consent Ledger enforces deny-by-default.
- [ ] Tool Broker logs all tool calls and risk levels.
- [ ] Capability Registry blocks advanced modules correctly.
- [ ] Contract tests pass.
- [ ] Shadow replay passes golden traces.
- [ ] Rollback primitives exist.
- [ ] QA/eval baseline passes.
