# Ultimate AI Agent Version

Current active baseline: **v0.18.3**

v0.18.3 clarifies OpenWebUI and CCC Client Strategy documentation. It defines OpenWebUI as the preferred conversational web shell, CCC as Control Center Clients across CCC Web, CCC iOS, CCC Android, and CCC macOS, and Open Design as governance for custom CCC surfaces rather than a replacement for OpenWebUI. It adds no OpenWebUI integration, OpenWebUI deployment config, backend API routes, frontend features, native CCC implementation, Android app, iOS app, macOS app, native build workflow, mobile sensor access, OS permission integration, signing/keystore/provisioning/App Store/Play Store workflow, dependencies, runtime execution, model/provider calls, network calls, remote execution, plugin enablement, or production authority.
