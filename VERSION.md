Current active baseline: **v0.10.0**

v0.10.0 implements Milestone M6 (Contract Tests, Shadow Replay, and Foundation Gate evaluation), including typed gate criteria/results/reports, validation-only API routes, M5 shadow replay with receipt and rollback verification, cross-contract compatibility tests, generated-report ignore rules, sample gate reports, and a local gate runner script.
