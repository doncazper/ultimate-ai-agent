v0.19.0 implements M15 Approval Queue + Receipt/Event Viewer UI in CCC Web. It adds read-only/preview-only frontend inspection panels for approval summaries, receipt summaries, and event summaries, with safe mock fallback data and static safety verification.

This release adds no backend API route, no approval execution, no approval grant/reject mutation, no send/write/run/deploy/enable controls, no raw secret/prompt/file/memory display, no runtime execution, no model/provider call, no remote dispatch, no mobile sensor access, no plugin enablement, no native build workflow, and no production Control Center authority.
