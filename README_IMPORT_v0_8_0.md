## v0.8.0 change

v0.8.0 implements M4 as local/dev foundation infrastructure. Memory records are source-linked, scoped, redaction-safe, supersedable, correctable, and searchable through deterministic local retrieval. File operations are constrained to explicit dev/test workspace roots with safe path validation, previews, write proposals, deterministic diffs, atomic writes, snapshots, and rollback metadata.
