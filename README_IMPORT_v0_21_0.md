v0.21.0 implements M17 Evidence/File/Memory Viewer in CCC Web only. It adds read-only, summary-only, redacted frontend routes for evidence refs, file refs, and memory refs using visibly mock non-authoritative data.

This release adds no backend API route, no OpenAPI path count change, no file mutation, no memory mutation, no filesystem browsing, no runtime execution, no model/provider call, no remote execution, no mobile sensor access, no plugin enablement, no raw prompt display, no raw secret display, no raw file display, no raw memory display, no raw evidence payload display, no raw credential display, no raw provider payload display, no dependency, no native build workflow, and no production Control Center authority.
