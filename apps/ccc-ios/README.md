# CCC iOS Skeleton

Status: Source-only M44 skeleton for v0.48.0.

This directory contains the first CCC iOS skeleton source files. It is a
review-only, read-only, mock-only client shell for future mobile work.

M44 intentionally adds no Xcode project, Swift package manifest, Info.plist,
entitlements, signing workflow, store workflow, background mode, mobile sensor
access, OS permission integration, network call, approval capture, approval
execution, context injection, memory write, file mutation, credential storage,
or production authority.

The Swift files are static UI source for future native-client review. Python
Agent Core remains the authority boundary.
