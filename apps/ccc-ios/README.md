# CCC iOS Skeleton

Status: Source-only M45 local read-only connection surface for v0.49.0.

This directory contains the first CCC iOS skeleton source files plus the M45
local read-only connection status model. It is a review-only, read-only,
mock-only client shell for future mobile work.

M45 adds local-only and loopback-only connection metadata display with no
runtime network call. It remains redacted summary only and non-authoritative.

This directory intentionally adds no Xcode project, Swift package manifest,
Info.plist, entitlements, signing workflow, store workflow, TestFlight pipeline,
background mode, mobile sensor access, OS permission integration, network call,
approval capture, approval execution, raw data, context injection, memory write,
file mutation, credential storage, cookie handling, execution, or production
authority.

The Swift files are static UI source for future native-client review. Python
Agent Core remains the authority boundary.
