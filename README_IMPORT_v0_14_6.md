v0.14.6 is a docs/governance patch to the accepted v0.14.5 baseline. It does not start M11.

The patch adds Codex plugin and external tooling governance docs, an active tooling inventory, a risk policy, and a plugin enablement backlog. It records that Browser + Build Web Apps may be considered for future Web Control Center work with approval, while iOS/macOS build plugins, Chrome authenticated profile control, Computer Use, Hugging Face Jobs/uploads/training, and plugin/skill installers remain disabled unless future milestones explicitly approve them.

No plugin is enabled in this patch.
No mobile app code, desktop app code, native build workflow, Xcode workflow, simulator/device workflow, keychain/signing/provisioning access, App Store Connect access, dependency, network call, cloud job, plugin installer, browser authenticated-profile control, Computer Use automation, or runtime capability exists in this patch.
