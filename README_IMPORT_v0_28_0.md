# README Import v0.28.0

Active baseline: v0.28.0.

v0.28.0 implements M24 Memory Provider Abstraction + Local Memory Store. It adds governed local memory provider contracts, reviewed-write validation, local in-memory and explicit-path stdlib SQLite store support, source/provenance/evidence/event/receipt refs, safe redacted summaries, trust/confidence metadata, retention/delete/export contracts, and Foundation Gate/verifier coverage.

Memory is recall, not authority. Memory is not ground truth. Canonical files, evidence manifests, receipts, Event Ledger records, and user-reviewed sources outrank memory.

M24 adds no automatic writes, model-output writes, local LLM output writes, OpenWebUI chat memory writes, Control Center mutation, mobile capture writes, tool output writes, vector DB, embeddings, cloud memory provider, raw session history, context injection, backend mutation routes, dependencies, production persistence, or M25 claim verification.
