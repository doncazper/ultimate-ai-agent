This release adds no backend API route, no OpenAPI path count change, no approval execution, no tool execution, no model/provider call, no remote execution, no mobile sensor access, no plugin enablement, no raw prompt display, no raw secret display, no raw file display, no raw memory display, no raw credential display, no raw provider payload display, no external telemetry export, no dependency, no native build workflow, and no production Control Center authority.
